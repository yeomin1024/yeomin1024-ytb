- 이 사람은 **가상 인물**이다. 실제 사람이 아니다. 설명란에 "개미 투자자 평균 통계로 만든 가상 인물, 이야기는 각색"이라고 밝힌다 (`stock/guides/story_script.md` 1-2).
- 나이·직장·소득·가족·투자 경력·투자 습관은 **평균 통계에 맞췄다** (8번 근거).
  - **잃은 돈의 크기만 평균보다 훨씬 크다.** 사용자가 정한 이야기 전제가 '전재산의 절반 이상'이기 때문이다. 손실 중인 40대 계좌의 평균 손실은 929만 원이다 (NH투자증권 2025-10-30).
- 영상의 숫자는 이 파일의 값만 쓴다. 새 사건이 필요하면 **5번 연표에 먼저 더한다** (영상끼리 어긋나지 않게).
- 시장 사건은 실제 기사로 확인한 것이다. 주인공 계좌의 숫자는 각색이다. 실제 지수·주가 숫자를 대본에 쓸 때는 코드나 원문으로 다시 확인한다 (story_script 3-1).

## 3. 돈 — 지금 (2026-10-21 기준, 가상)

| 항목 | 금액 |
|---|---|
| 6년 반 동안 넣은 내 돈 (투자 원금) | **2억 4,000만 원** = 시작 예금 5,000만 + 월급에서 모은 돈 약 7,000만 + 전세를 반전세로 바꿔 뺀 보증금 1억 2,000만 |
| 빌린 돈 (지금) | 마이너스 통장 **4,000만 원** (증권사 신용 6,000만 원은 2026년 7월 반대매매로 강제로 갚아짐) |
| 주식 계좌 평가액 (지금) | **1억 1,000만 원** → 빚을 빼면 7,000만 원 |
| 투자 손익 | 7,000만 − 2억 4,000만 = **−1억 7,000만 원 (원금의 −70.8%)** |
| 전재산 (투자를 안 했다면) | 보증금 8,000만 + 넣은 돈 2억 4,000만 = 3억 2,000만 원 |
| 전재산 (지금) | 보증금 8,000만 + 계좌 순 7,000만 = **1억 5,000만 원 → 전재산의 53.1%를 잃음** |
| 원금 회복까지 | 계좌 순 7,000만 → 2억 4,000만: **약 3.4배**가 되어야 함 |

- 계산: 1억 7,000만 ÷ 3억 2,000만 = 53.1%. 2억 4,000만 ÷ 7,000만 = 3.43배.
- 영상에서 금액을 말할 때는 어림 한 단위로 말한다 ('약 1억 7천만 원'). 화면에는 정확한 값을 쓴다 (`₩170,000,000`).

### 5-1. 재기 일지 — 시리즈에서 바뀌는 것 (`stock/story/series.md`, 1화 = 2026년 10월 넷째 주, 한 주에 한 화)

| 화 | 주인공이 정한 것 (다음 화부터 그대로 이어짐) |
|---|---|
| 1 | 주식을 떠나지 않음 · **매매를 멈추고 매매 일지 시작** · 공부 순서 = 교과서(나눠 담기·정해진 날 정해진 금액·비용·오래 들고 있기) · 문제 6가지(몰빵·물타기·빚투·리딩방·잦은 매매·레버리지) · 매주 하나씩 고침 |
| 2 | 목표 = '더 잃지 않기' · **매달 100만 원은 마이너스 통장 4,000만 원을 다 갚을 때까지 빚 갚기에** · 레버리지·'한 방' 안 함 · 회복 시간표 = 가운데 값 11.2년 (52세 파이어는 다시 계산) |
| 3 | 일지 첫 장: 원금을 넘으면 절반은 안전한 곳으로 · 주식 비중 70% 넘지 않기(리밸런싱) · **증권 앱 알림 끔, 계좌는 월급날에만** · 앱은 휴대폰 맨 뒤 폴더 · 매매하고 싶으면 하루 기다리고 이유 세 줄 |
| 4 | 일지에서 남의 수익률 칸 지움 — 내 칸(갚은 빚·지킨 규칙·참은 매매) · 포모 때 세 질문(빌린 돈인가·한 업종에 너무 많은가·반토막 나도 버틸 돈인가 — 휴대폰 잠금 화면) · 빚을 다 갚으면 월급날 다음 날 자동 매수 · **지난 4주 매매 0번, 마이너스 통장 갚기 시작** |

- 아직 그대로인 것: 아내는 반전세 이사까지만 안다 (신용·마이너스 통장·손실 크기는 모름) → 2부 첫 이야기 후보 '아내에게 털어놓는 날' (4화 예고 — 사용자 확인 전).
- 남은 돈을 어디에 어떻게 넣을지는 아직 정하지 않았다 (1화). 2부 '방법 편'에서 정한다.

## 8. 그림 — 종이인형극 (영어 설명은 그림 프롬프트에 그대로)
