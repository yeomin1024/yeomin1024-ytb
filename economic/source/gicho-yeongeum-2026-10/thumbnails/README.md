## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「기초연금 못 받는 줄 알고 신청 안 하면, 집 한 채·국민연금 부부 월 41만 원씩 1년 500만 원 손해」 (59자)
- 뺀 말:
  - '못 받는 줄 알고' — 그림의 꼬리표·판('집 한 채'·'국민연금' = 못 받는 줄 아는 이유)이 보여 준다.
  - '집 한 채·국민연금' — 하단 글자에서 빼고 **그림 속 낱말**로 옮겼다 (댓글 니즈 낱말, 3-3).
  - '월 41만 원씩' — 덧붙인 숫자 (eunte 의 '월 15만 원씩'을 뺀 것과 같은 규칙, 피드백 6).
- 둔 말: '부부' — 500만 원은 부부 합계다. 사람이 없는 실험안 ②에서도 숫자의 뜻이 맞게 글자로 둔다.
- **더한 말: '60·70대'** (시청자층, 피드백 13):
  - 기초연금 영상 댓글에서 나이를 밝힌 142개: 50대 2% · **60대 54% · 70대 35%** · 80대 9% (2026-10-16 셈, 3-3).
  - 기초연금은 65세 이상만 받는다. 그래서 다른 영상의 '50·60대' 대신 '60·70대'로 넓혔다 ('60대' 하나만 맨 앞에 두면 약했다 −3).
  - '어르신·노인'은 쓰지 않는다.
- 결과: '60·70대 기초연금 신청 안 하면' (띄어쓰기 포함 19자, 한글 약 14.3자 너비 — eunte 1줄과 같은 너비) / '부부 1년 500만 원 손해' (15자, 10.6자 너비). Noto Sans KR Black 로 잰 값.
- 사실 확인 (대본 `gicho-yeongeum-2026-10.txt` v1.0.1, `calc/calc.py` v1.0):
  - '1년 500만 원' = 예시 부부가 받는 기초연금 **최소** 월 41만 9,640원 × 12 = 503만 5,680원 (문장 4·7·75 "12개월이면 약 500만 원을 놓칩니다").
  - '손해' = 신청하지 않으면 놓치는 돈. 기초연금은 신청한 달부터 나오고 지나간 달은 돌려받지 못한다 (기초연금법 제14조①, 문장 7·56·57).
  - '집 한 채'·'국민연금' = 예시 부부의 조건 (서울 공시가격 5억 원 아파트, 국민연금 둘이 170만 원 — 문장 2·3·16~20).
- 인물 나이: 대본 예시는 67세 부부다. 썸네일은 '젊어 보이는 60대 후반'으로 했다 (사용자 지시 '되도록 젊게', 대상 65세 이상).

## 4. 색
- 노랑 #FFD400 = 중요한 것 ('기초연금 신청')
- 빨강 #FF2A2A = 나쁜 상황 ('1년 500만 원 손해', 빨강 화살표)
- 흰색 = 나머지 글자, 꼬리표·판은 **흰 바탕에 검정 글자** — '집 한 채'·'국민연금'은 손해 자체가 아니라 '못 받는 줄 아는 이유'라서 빨강으로 쓰지 않는다 (색 = 뜻).
- 영상 색과 같다: 영상도 빨강 = 손해, 노랑 = 기준이다 (`guides/video_guide.md` v4.0).

## 5. ChatGPT로 이미지 만들기
- **기본 — 남은 재테크 썸네일 전부를 한 번에** (`guides/thumbnail_guide.md` v3.3 9번): ChatGPT 새 대화에 이것만 보낸다. 장마다 번호 + 저장 경로가 붙는다.
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 썸네일을 1번부터 차례로 모두 만들어서 장마다 적힌 저장 경로에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/thumbnails_chatgpt.md
```
- 이 영상만 만들 때는 ChatGPT 새 대화에 이것만 보낸다:
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 대로 썸네일을 만들어서 저장소에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/source/gicho-yeongeum-2026-10/thumbnails/chatgpt.md
```
- 한 장 만들고 멈추면 `계속`이라고 보낸다.
- 이 계정의 ChatGPT는 저장소에 못 쓴다 (2026-10-15) → ChatGPT가 'Claude 대화창에 붙여 넣어 주세요'로 끝내면 그림을 **번호 순서대로** Claude 대화에 붙인다 → Claude가 검수(`guides/thumbnail_guide.md` 10번)하고 통과한 것만 `thumbnail_N.<확장자>`로 올린다.
- 직접 올릴 때: https://github.com/yeomin1024/yeomin1024-ytb/upload/main/economic/source/gicho-yeongeum-2026-10/thumbnails
- 한글이 틀리면 같은 대화에서: `thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.` — 두세 번 틀리면 [B]로 그림만 만들고 글자를 얹는다.
- `chatgpt.md`는 `python tools/make_summary.py --chatgpt economic gicho-yeongeum-2026-10`이 `thumbnail_N.md`에서 만든다 (직접 고치지 않음).
- 업로드 도구는 본안(`thumbnail_1`)을 기본 썸네일로 올린다. 공개 뒤 스튜디오 '테스트 및 비교'에 3장을 넣는다 (시청 시간 비율로 이긴 것을 고름).
