## 3. 예시 부부와 가정
| 항목 | 값 |
|---|---|
| 나이 | 65세 동갑 |
| 국민연금 | 남편 110만 원, 아내 40만 원 (월) |
| 생활비 | 월 300만 원 → 모자라는 150만 원 × 12 = 1년 1,800만 원 |
| 재산 | 5억 원 = 남편 퇴직금 2억 + 연금저축 1억(남편 6천만·아내 4천만) + 예금 2억(한 사람 1억씩) |
| 금리·물가 | 3.5% (같다고 봄 = 실질 기준) |
| A 부부 | 퇴직금을 한 번에 받아 남편 예금에, 생활비는 남편 연금저축부터 |
| B 부부 | 퇴직금은 IRP, 순서: 예금(+IRP 100) → IRP 퇴직금 → 연금저축(남편 1,000·아내 800) |
| 넣지 않은 것 | 퇴직소득세(근속연수마다 다름)·건보료(재산마다 다름) |
