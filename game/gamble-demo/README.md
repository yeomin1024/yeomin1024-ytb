## 1. 해 보기 (PC)

1. Godot 4.7 이상(표준판, .NET 아님)을 받습니다 — https://godotengine.org/download
2. Godot 를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **실행(F5)**
3. 글자가 □ 로 보이면: 프로젝트 설정 → GUI → 테마 → 사용자 지정 글꼴에 한글 글꼴(예: Noto Sans KR)을 넣습니다

### 화면에서 하는 것
| 버튼 | 뜻 |
|---|---|
| 내 시선: 상대 손 / 얼굴 | 손을 보면 상대 속임수 단서가 잘 보이고, 얼굴을 보면 표정(합법 블러핑)이 보임. **다음 턴부터** 적용 |
| 내 패 | 카드를 냄 (당신이 먼저 내고, AI 는 정해 둔 카드로 답함) |
| 엿보기 (3번) | 상대가 고른 카드를 봄. 증거(거울)는 **다음 턴까지** 남음 |
| 뒷면 표시 (1번) | 상대 특수 카드에 표시 → **다음 턴부터** 턴마다 60% 확률로 특수 카드인지 보임. 증거는 **매치 끝까지** |
| 가짜 동작 (3번) | 속이는 척만 함 — 상대가 고발하면 헛고발 (블러핑) |
| 손기술 막대 | 속임수를 누르면 막대가 움직임. 가운데에서 누를수록 단서가 작음. 2.5초 안에 안 누르면 단서 최대 |
| 잡았다! (고발) | 지금 상대 증거가 남아 있으면 적중 |
| 다음 ▶ | 공개 뒤 다음 턴/판 |

### 규칙 한 장
- 왕 > 시민 > 암살자 > 왕, 시민끼리는 비김. 패 = 시민 4 + 특수 카드 1. 판마다 진영을 바꿈.
- 판 점수: 왕 측 승 +1 · 암살자 측 승 +4 (둘 다 무작위로 두면 기대 점수가 같음). 6판, 동점이면 연장 최대 2판(진영은 동전).
- **경고 2개 = 즉시 패배.** 들킴은 자동이 아니라 상대가 고발해야 하고, 그 순간 증거가 남아 있어야 적중.
- 적중: 경고 +1 · 증거 몰수 · 그 판 몰수(고발한 쪽 진영 점수) · 벌금 1점.
- 헛고발: 고발 토큰 −1(매치당 3개) · 벌금 1점을 상대에게.
- 판이 끝나면 **리플레이**로 놓친 상대 속임수와 그때 당신이 어디를 보고 있었는지 알려 줌.

## 2. 시험·시뮬레이션 (화면 없이)

저장소 맨 위에서 (Godot 실행 파일 이름이 `godot` 가 아니면 그 이름으로):

```bash
godot --headless --path game/gamble-demo --script res://tests/run_tests.gd
```

```bash
godot --headless --path game/gamble-demo --script res://tools/simulate.gd -- --matches=2000 --seed=42
```

- `run_tests.gd`: 15묶음 — 규칙표 · 공정 확률(해석 + 몬테카를로) · 단서 공식 · '5번 속이면 2번 이상 들킬 확률 47.2%' · 고발 적중/만료/헛고발/토큰 · 경고 2개 패배 · 뒷면 표시 지속·몰수 · **AI 가 숨은 카드를 몰래 읽지 않음** · AI 엿보기 최선 응답 · 의심 갱신(베이즈) · 같은 시드 = 같은 매치 · 연장 · 300 매치 상태 점검. 실패가 있으면 종료 코드 1.
- `simulate.gd`: AI 성격 조합별 승률 · 두 번 들켜 진 비율 · 속임수 1회당 적발률 · 고발 정확도 · 평균 점수 · 걸린 시간.

## 3. 구조

```
core/            규칙 — 노드에 의존하지 않음 (시험·나중 서버 공용)
  rank_cards.gd    카드 규칙 · 공정 플레이 기준 확률
  cheat_rules.gd   속임수 정의표 · 단서 공식 · 알아챌 확률 · 이항 확률 · 벌금·토큰 값
  ai_brain.gd      AI 성격값 · 시선 · 카드 선택 · 속임수 결정 · 의심(로그 오즈) · 고발 결정
  match.gd         매치 흐름 · 고발 판정 · 이벤트 기록
  game_log.gd      [STAGE] [t=…ms] key=value 로그, 수준 조절
scenes/main.gd   화면 (코드로 만듦, 규칙 없음)
tests/run_tests.gd  tools/simulate.gd
```

튜닝은 `core/cheat_rules.gd`(속임수 표·벌금·토큰) · `core/ai_brain.gd`(성격 묶음·문턱·시선) 값만 바꾸고 `simulate.gd` 로 확인합니다.

### 로그 (Godot 출력 창)
`[DEAL]` 패 배분 → `[TURN]` 턴·시선 → `[AI_CARD]`(DEBUG)/`[AI_LATE]` AI 카드 → `[CHEAT]` 속임수·단서(qte·watched·prior_uses·tell) → `[NOTICE]` 알아챔(전·후 의심) → `[SUSPECT]` 결과로 의심 갱신 → `[ACCUSE]` 판정 → `[REVEAL]` 공개 → `[ROUND]` 판 결과 → `[MATCH]` 설정(시드)·끝. 규칙상 거절된 행동은 `[REFUSE]`(WARNING).

## 4. AI 의 공정성 규칙
- AI 함수는 상대의 숨은 카드를 받지 않습니다. 엿보기·뒷면 표시를 했을 때만 `info["opp_card"]` 로 들어옵니다 (`tests` 의 `ai_ignores_hidden_card` 가 확인).
- 의심은 공개 정보로만 고칩니다: 알아챈 단서, 판 결과(가능도 비 = '가끔 다 아는 사람' 대 '공정한 사람'), 상대 시선.
- 같은 시드면 같은 매치 (시드는 `[MATCH] event=setup seed=…` 로그와 화면 첫 줄에).
