## 1. 해 보기 (PC)

1. Godot 4.7 이상(표준판, .NET 아님)을 받습니다 — https://godotengine.org/download
2. Godot 를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **실행(F5)**
3. 글자가 □ 로 보이면: 프로젝트 설정 → GUI → 테마 → 사용자 지정 글꼴에 한글 글꼴(예: Noto Sans KR)을 넣습니다

### 조작 (마우스 = 시선이라 행동은 키보드)
| 조작 | 뜻 |
|---|---|
| **마우스 위치 = 내 시선** | 가리키는 곳이 '보는 곳'. 시야 제한을 켜면 그 주변만 밝게 보임 |
| 카드 클릭 | 그 카드를 냄 |
| **1** | 라이터 놓기 — 속임수 판에서 판마다 한 번 (뚜껑 안 작은 반사경 = 실제 카드 사기의 '샤이너') |
| **2** | 협력자 부르기 — 매치 2번, 2.5초 뒤 상대 오른쪽 뒤에 섬 |
| **C** | 카드 덮개 — 감시 판에서 내 카드 위에 칩 → 그 턴 상대 반사경에 안 비침 (매치 2번) |
| **B** | 블러핑(여유 부리기) — 내 고르는 시간 +5초 · 상대 고민 시간 −2초 (지금 흐르는 쪽은 바로, 아니면 다음 차례) · 매치 3번 |
| **스페이스** | 잡았다! (감시 판에서 상대가 고민할 때) |
| Enter | 공개 뒤 다음 턴 |
| 상대 시선 보조선 | 연습용 — 상대가 어디를 보는지 점선 |

### 판마다 역할 (진영이 판마다 바뀌므로 번갈아 옴)
| 판 | 누가 먼저 | 할 일 |
|---|---|---|
| **노예(암살자) 측 판 = 속임수 판** | 상대(왕)가 매 턴 먼저 엎어 놓음 | 속임수는 **준비 동작이 먼저**: **1** 라이터를 놓고 왼쪽 라이터 반사경을 **1.8초** 보거나, **2** 협력자를 불러 상대 뒤 사람의 손 신호를 **1.2초** 보면 상대 카드. 반사경은 상대가 **내 얼굴**을 볼 때, 협력자는 상대가 **뒤를 돌아볼 때** 크게 위험. 상대가 카드에 **칩(덮개)** 을 올리면 반사경엔 안 비침 → 협력자로 |
| **왕 측 판 = 감시 판** | 당신이 매 턴 먼저 냄 | 상대(노예)가 라이터를 놓았으면 엿보려는 것 → **C** 덮개로 막거나, 상대가 5~7초 고민하는 동안 눈을 지켜보다가 오른쪽 라이터로 가면 **스페이스** (보는 중이거나 0.6초 안이면 적중, 아니면 헛고발) · **B** 로 상대 고민 시간 줄이기 |

- 준비 동작을 상대가 보면(라이터를 놓을 때 손·얼굴을 보고 있음, 부를 때 얼굴을 보고 있음, 뒤돌아보다 협력자를 봄) **의심이 커짐** — 경고는 아니지만 더 자주 당신을 봄
- 들키면: 반사경 = 라이터 몰수(그 판) · 협력자 = 매치에서 쫓겨남
- 속임수는 노예 측만 (v0.3.0): 엿보기는 왕 측에 더 유리했음 — 왕 측은 한 번 보면 그 턴에 이기지만, 노예 측은 왕이 나오는 턴을 맞혀야 함
- 상대가 고개를 돌리는 0.4초 동안은 들키지 않음 · 눈썹이 찌푸려질수록 의심이 큰 상태
- 턴이 끝나면 **리플레이**: 반사경·신호를 본 시간과 그동안 상대가 당신을 본 시간, 감시 판엔 상대가 반사경을 몇 번·몇 초 봤는지

### 규칙 한 장
- 왕 > 시민 > 암살자 > 왕, 시민끼리는 비김. 패 = 시민 4 + 특수 카드 1. 판마다 진영을 바꿈.
- 판 점수: 왕 측 승 +1 · 암살자 측 승 +4. 6판, 동점이면 연장 최대 2판(진영은 동전).
- 들키면: 경고 +1 · 벌금 1점 · 그 판 몰수(잡은 쪽 진영 점수). **경고 2개 = 즉시 패배.**
- 헛고발: 고발 토큰 −1(매치당 3개) · 벌금 1점을 상대에게.
- 먼저 내는 사람은 15초 안에 내야 함 (블러핑으로 ±5초 · 넘으면 남은 카드 중 아무거나).

## 2. 시험·시뮬레이션 (화면 없이)

저장소 맨 위에서 (Godot 실행 파일 이름이 `godot` 가 아니면 그 이름으로):

```bash
godot --headless --path game/gamble-demo --script res://tests/run_tests.gd
```

```bash
godot --headless --path game/gamble-demo --script res://tools/simulate.gd -- --matches=1000 --seed=42
```

- `run_tests.gd` 17묶음: 규칙표 · 위험률 공식 · 판 진영별 턴 종류 (왕 측은 라이터·엿보기 없음) · **라이터를 놓기 전엔 못 엿봄 → 1.8초면 비침** · 상대가 얼굴을 보면 거의 들킴 / 딴 곳이면 잘 안 들킴 · **준비 동작을 보면 의심만 오름** · **협력자: 걸어옴 → 신호 1.2초 → 뒤돌아보면 들켜 쫓겨남** · **덮개: 상대 덮개면 반사경 X·협력자 O / 내 덮개면 상대가 못 엿봄** · **블러핑 시간 ±** · 감시 판 고발 · AI 최선 응답 · AI 가 숨은 카드를 몰래 읽지 않음 · 경고 2개 패배 · 시간 초과 · 연장 · 같은 시드 = 같은 매치 · 100 매치 상태 점검.
- `simulate.gd`: 자리 0 = 사람 대신 정책(상대 시선을 0.25~0.4초 늦게 보고 반응), 자리 1 = AI. 조합마다 승률 · 엿보기 시도·성공률 · 시도당 들킴 · 두 번 들켜 진 비율 · 고발 정확도.

## 3. 구조

```
core/            규칙 — 노드에 의존하지 않음 (시험·나중 서버 공용)
  rank_cards.gd    카드 규칙 · 공정 플레이 기준 확률
  cheat_rules.gd   반사경·신호 읽기 시간 · 시선별 위험률(반사경/신호) · 준비 동작 의심 · 덮개·블러핑·벌칙 값
  ai_brain.gd      AI 성격 · 지켜보기(뒤돌아보기 포함)/엿보기 시선 · 라이터·덮개·블러핑 결정 · 카드 선택 · 의심 · (시뮬레이션용 사람 정책 p0_*)
  match.gd         실시간 매치: tick(dt, 사람 시선) · place_lighter · call_accomplice · cover_card · bluff · commit · accuse · next · 이벤트
  game_log.gd      [STAGE] [t=…ms] key=value 로그, 수준 조절
scenes/main.gd        화면 연결 · 안내 · 기록 · 시야 제한 셰이더
scenes/table_view.gd  테이블 장면 그리기 (상대·눈동자·라이터·협력자·칩·카드) + 시선 영역
tests/run_tests.gd  tools/simulate.gd
```

튜닝: `core/cheat_rules.gd`(엿보기 시간·위험률·벌칙) · `core/ai_brain.gd`(성격 묶음·시선 시간) 값만 바꾸고 `simulate.gd` 로 확인.

### 로그 (Godot 출력 창)
`[DEAL]` → `[TURN]`(종류·제한 시간) → `[SETUP]`(라이터·협력자, 상대가 봤나) · `[COVER]` · `[BLUFF]` · `[ACCOMPLICE]` → `[COMMIT]` → `[AI_THINK]`(고민 시간·엿볼지·필요 시간) → `[PEEK]`(엿보기 끝) → `[NOTICE]`(상대가 알아챔: 시선·위험률·잔 본 시간) → `[ACCUSE]` → `[AI_COMMIT]` → `[REVEAL]` → `[ROUND]` → `[MATCH]`. `[GAZE]`(시선 바뀜)는 DEBUG. 거절된 행동은 `[REFUSE]`, 시간 초과는 `[TIMEOUT]`(WARNING).

## 4. AI 의 공정성 규칙
- AI 는 상대 카드를 잔 엿보기를 끝냈을 때만 압니다 (`info["opp_card"]`, 시험 `ai_ignores_hidden_card`).
- AI 가 보는 것 = 공개 정보뿐: 당신의 시선(마우스가 가리키는 곳)·판 결과.
- 같은 시드면 같은 매치 (시드는 `[MATCH] event=setup seed=…` 와 기록 첫 줄).
