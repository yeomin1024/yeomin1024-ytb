## 2. 왜 이 순서인가 (⚖️)

**① 가장 넓었던 제국 — 1순위**
- 우리 도구가 가장 잘하는 것(지도 위 애니메이션 + 코드로 계산한 숫자)이 그대로 '증명'이 된다. 남들은 AI 그림 + 낭독이 대부분이다 (`data_insights.md` 9번).
- 자료를 **지금 이 환경에서 바로 구할 수 있는 유일한 후보**다 (연도별 국경 GeoJSON 54개 시점 — 조선 사료 사이트는 막힘).
- 제목에 비교(vs)가 들어가는 꼴 — 비교 집단 57% vs 32%, 같은 채널 안에서도 +8%p. 질문 제목 +18%p.
- 그림만으로도 이해되는 영상이라 나중에 주식 채널처럼 전 세계용(자막 없이·제목 여러 언어)으로 넓힐 수 있다.
- 위험: 자료 README 가 "work in progress — 다른 자료와 대조할 것"이라 한다 → 넓이는 문헌값과 같이 보이고, 차이가 크면 문헌값을 쓴다. GPL-3.0 → 설명란에 출처.
  - 미리 계산해 보니 (`data_insights.md` 12번) 로마·몽골은 한 이름으로 바로 잡히지만, **1920년 대영제국은 자료의 '지배국' 칸에 캐나다·호주·남아공·나이지리아가 영국으로 묶여 있지 않다** → 영토 목록을 손으로 만들어야 해서 이 영상의 일이 가장 많다 (자치령을 넣을지도 기준으로 화면에 밝힘).

**② 조선 백성의 겨울 — 2순위 (공개 시기: 11~12월)**
- 조선은 왕실보다 **평범한 사람들의 삶**이 작은 채널에서 더 잘 됐다: 평민 58%·주막 58%·결혼 56%·백성 38% vs 왕 24%·왕비 16%·세자 4%.
- 같은 채널 짝에서도 주막·과거길·군인 일기 같은 생활 이야기가 그림·왕 업적 영상보다 수백 배 (×498·×821·×73).
- 겨울 이야기의 큰 성공 셋이 12~2월에 올라왔다 → 지금 준비하면 시기가 맞는다.
- 위험: 이미 큰 영상이 4개다 → '얼마나 추웠나·무엇을 태웠나'를 기록과 숫자로 보여 주는 각도로. 사실 확인에 실록·연구가 필요한데 이 환경에서 막혀 있다 (3번 '정할 것' 2).

**③ 조선 백성의 밥상 — 3순위**
- 작은 채널 성공 비율이 높고(37%) 큰 성공이 여러 채널에 고르게 있다 — 수요가 한 채널 덕이 아니다.
- '산처럼 먹었다'는 이야기를 계산으로 확인하는 영상 — 근거를 묻는 댓글(👍5·👍7)에 맞는다.
- 위험: 가장 붐비는 주제(41개). 제목이 단정하지 않게 (계산 결과를 본 뒤 정함).

**④ 이슬람의 확산 — 실험**
- 숫자는 가장 좋지만(6/6·하루 4,439) 표본이 작고 종교 댓글 다툼이 잦다 (반박 2.1%·정치·사회 5.9% — 가장 많은 갈래).
- 신학이 아니라 **'어디로·얼마나 빨리'**(지도·넓이)만 다루고, 지금 중동 정치와 엮지 않는다.

## 4. 모든 영상 공통 (데이터)

- **길이 15~20분** — 성공 사례 중앙값 18.4분, 15~25분에서 성공 사례 25개(가장 많음).
- **제목** — 질문으로 끝냄(+18%p) · '어떻게'(+28%p) · 비교(vs, +25%p) · 숫자. 길이는 짧게(25자 미만 60%, 표본 15) 또는 45자 이상(40%) — 25~44자는 25~27%. '진실'은 쓰지 않음.
- **도입** — 서론 짧게 ("서론이 너무 길어서 숏츠 보려고 나간다" 👍40). 대본 근거(도입부 유형)는 아직 없음.
- **근거를 보여 줌** — 원문 기록·자료를 화면에 띄우고 설명란에 출처 ("문서자료가 있을까요?" 👍7 · "어떤 기록을 근거로" 👍1).
- **AI 티** — 잘 만들면 받아들임 ("AI영상이지만 잘 만든 것 같습니다 … AI를 이용하는 영상과 AI에 의지하는 영상은 극과 극" 👍346 · "AI목소리가 듣기 좋아요" 👍88). 자막 오탈자는 비판 받음 (👍20).
- **썸네일** — 성공 사례 공통은 '그림 + 큰 한글 2줄'. 잘된 영상과 평소 영상의 모양이 같아 차이를 만드는 것은 아님 → 우리는 지도·숫자 그림으로 (#4·#8·#20 지도형 성공 사례 있음).
- **타임라인(챕터)** — 성공 사례 54%가 있음 (중앙값 10개).

## 5. 정할 것 (사용자)

1. **채널 방향** — 추천: 두 갈래를 첫 4편으로 시험한 뒤 조회수·시청 지속 시간·구독 전환으로 좁힘. (한 갈래만 하겠다면: 지금 도구·자료가 되는 A 세계사·지도.)
2. **조선 사실 확인 길** — 이 클라우드 환경 Network access 에 `sillok.history.go.kr`(조선왕조실록)·`db.history.go.kr`(국사편찬위원회)·`encykorea.aks.ac.kr`(한국민족문화대백과)·`ko.wikipedia.org`·`en.wikipedia.org` 를 더하면 ②③을 이 환경에서 확인할 수 있다.
3. **세계사 검색어 보강** — 지금 검색어 40개는 한국사 쪽(조선 14 · 세계사 2)이라 갈래 A 근거가 얇다. 세계사 낱말(예: 로마·몽골제국·중국사·세계 역사)을 더할지. 예약 작업은 사용자가 말하기 전에는 검색어를 바꾸지 않는다.
4. **언어** — 한국어로 시작 (권장). ①④는 나중에 전 세계용(자막 없이·제목 여러 언어)도 가능.
