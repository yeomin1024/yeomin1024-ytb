## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「노후 연금 꺼내는 순서 모르면, 은퇴 부부 월 15만 원씩 평생 2천만 원 손해」 (44자)
- 뺀 말:
  - '월 15만 원씩' — 사용자 지시
  - '은퇴 부부' — 그림이 사람을 보여 주고, 시청자층은 '50·60대'가 더 바로 말한다
- **더한 말: '50·60대'** · **둔 말: '노후'** (v5.0 — 사용자 지시 "그냥 연금이 아니라 50,60대 노후 연금처럼 주요 시청자층에 맞는 핵심 단어들 … 사용하도록")
  - v4.x는 첫 줄을 짧게 하려고 '노후'까지 빼서 '그냥 연금'이 됐다 — 잘못이다.
  - 근거: 댓글에서 나이를 밝힌 시청자 50대 21% · 60대 29% (50대 이상 73%) · 제목 낱말 '노후' 맨 앞 +14, '50~70대·N세' +15 (`economic/guides/data_insights.md`). '60대'를 맨 앞에 둔 제목은 −3이라 '50·60대'로 넓혔다. '어르신·노인'은 쓰지 않는다 (댓글 '노인 취급' 반발 👍45).
- 결과: '50·60대 노후 연금 꺼내는 순서'(띄어쓰기 포함 19자, 숫자가 좁아 한글 약 14자 너비) / '모르면 평생 2천만 원 손해'(띄어쓰기 포함 15자).
- 댓글 니즈 낱말 '세금'·'건보료'는 **그림 안에 낱말 그대로** 넣었다 (사용자 지시: 물건으로 표현하지 않음).
- 사실 확인 (대본 `eunte-kkeonaeseugi-2026-10.txt` v1.2):
  - '평생 2천만 원'은 평생 세금 차이다 — 문장 7(약 0:26~0:33), 문장 75 '약 2,100만 원'.
  - 이 숫자에 건보료는 들어 있지 않다 (문장 76). 건보료 손해(한 부부만 5년 동안 피부양자에서 빠짐, 문장 8·77)는 여기에 더해진다.
  - → 그림의 '세금'·'건보료'와 '2천만 원 손해'를 함께 써도 부풀린 말이 아니다.
  - 건보료 금액은 대본이 계산하지 않았으므로 어디에도 쓰지 않는다.
- 인물 나이: 사용자 지시대로 50대(젊어 보이게)로 했다. 대본 사례는 65세 부부라서, 썸네일 인물은 사례 주인공이 아니라 시청자 대표다.

- 표본이 3개라 방향만 읽는다: 성공 2개는 세금·건보료를 **손해·걱정 낱말**과 함께 썼고, 기준 밖 1개는 물음과 vs로 썼다.
- → 이번 시안은 '세금'·'건보료'를 빨강(나쁜 것)으로, '손해'와 함께 쓴다. vs는 쓰지 않는다.
- 제목 분석에서 '세금' 낱말은 −7(n=14), '건보료·건강보험'은 +8(n=7)이었다. 둘 다 표본이 적고, **제목**에 대한 결과다.

## 4. 색
- 노랑 #FFD400 = 중요한 것 (방법: '노후 연금 꺼내는 순서')
- 빨강 #FF2A2A = 나쁜 상황 ('2천만 원 손해', 손해를 만드는 '세금'·'건보료')
- 흰색 = 나머지 글자
- 근거: 노랑·빨강 비율이 성공 사례 안에서 배수와 +0.21·+0.19 (3-1), 빨강 글자 48% vs 32% (3-2).
- **영상 색과 다르다:** 로컬에서 렌더한 영상은 빨강을 '아끼는 B 부부' 색으로 썼다. 영상을 다시 렌더할 때 A 부부(손해) = 빨강으로 바꾸면 썸네일과 뜻이 같아진다.

## 5. ChatGPT로 이미지 만들기
### 5-1. 주소 하나만 주기 — 만들고 저장소에 올리기까지 (v4.3)
- 저장소가 공개라서 ChatGPT가 파일 주소를 바로 연다 (2026-10-15 확인).
- `chatgpt.md`에 다 들어 있다:
  - ChatGPT가 할 일: 차례로 모두, 묻지 않기, 프롬프트 그대로, 장마다 다른 그림, 한글 획을 확대해서 문구표와 맞춰 보기
  - **저장소에 올리기**: GitHub 앱(쓰기)이 연결돼 있으면 이 폴더에 `thumbnail_N.png`로 커밋. 못 하면 `thumbnail_N.png`로 내려받게 하고 업로드 링크를 알려 줌
  - 시안마다 문구표와 [A] 프롬프트
- **이미지가 이미 있는 시안은 빠진다.** v5.0에서 문구가 바뀌어 지금은 세 장 모두 들어 있다.
- 크기·한글·가상 인물 규칙은 [A] 프롬프트 안에도 있다.
- `chatgpt.md`는 `thumbnail_N.md`에서 자동으로 만든다: `python tools/make_summary.py --chatgpt economic eunte-kkeonaeseugi-2026-10`
- ChatGPT 새 대화에 이것만 보낸다:
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 대로 썸네일을 만들어서 저장소에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/source/eunte-kkeonaeseugi-2026-10/thumbnails/chatgpt.md
```
- 한 장 만들고 멈추면 `계속`이라고 보낸다.
- ChatGPT가 저장소에 못 올리면 내려받아 이 화면에 끌어다 놓고 'Commit changes'를 누른다: https://github.com/yeomin1024/yeomin1024-ytb/upload/main/economic/source/eunte-kkeonaeseugi-2026-10/thumbnails
  - ChatGPT가 GitHub에 쓸 수 있는지는 계정의 ChatGPT 설정 → 앱(GitHub) 권한에 따라 다르다. 2026-10 기준 공개 자료는 '읽기만'과 '커밋 가능'이 엇갈린다.
- 올라오면 Claude가 검수한다 (6번 검수표 → 통과면 그대로, 틀리면 프롬프트를 고치고 `chatgpt.md`를 다시 만든다).
- 주소를 못 연다고 하면 GitHub 화면 주소를 준다: `https://github.com/yeomin1024/yeomin1024-ytb/blob/main/economic/source/eunte-kkeonaeseugi-2026-10/thumbnails/chatgpt.md`

### 5-2. 고칠 때 (같은 대화에서, 한 번에 하나씩)
- 한글이 틀렸을 때: `thumbnail_1의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.` (번호만 바꿔서)
  - 두세 번 해도 틀리면 `thumbnail_N.md`의 [B](글자 없는 프롬프트)로 그림만 만들고, 캔바·미리캔버스에서 문구표대로 글자를 얹는다.
- 다듬기:
  - 나이: `thumbnail_1의 남자를 50대 초반으로 더 젊어 보이게 해 줘. 다른 건 그대로.`
  - 작은 화면: `아래 2줄 글자를 더 크고 굵게 해 줘. 오른쪽 아래 구석은 비워 둬.`
  - 실험안 ②의 지폐: `지폐에 실제 화폐 그림이나 숫자가 보이지 않게 해 줘.`

### 5-3. 다 만든 뒤 (저장 · 유튜브 '테스트 및 비교')
- PNG로 내려받아 `thumbnail_1.png`·`thumbnail_2.png`·`thumbnail_3.png`로 이름을 바꿔 이 폴더(`economic/source/eunte-kkeonaeseugi-2026-10/thumbnails/`)에 올린다.
  - 크기는 맞추지 않아도 된다. 업로드 도구(`tools/youtube_upload.py`)가 가운데 기준 16:9로 잘라 1280×720·2MB 이하 JPG로 바꾼다.
  - ChatGPT가 16:9가 아닌 가로형(흔히 3:2)으로 만들면 위아래가 약 8%씩 잘린다. 그래서 프롬프트에 '글자·얼굴은 가운데 16:9 안, 위아래 8% 비움'이 있다.
- 업로드 도구는 본안(`thumbnail_1`)을 기본 썸네일로 올린다 (`titles.md`에 채택 표시 [x]가 없으면 1번).
- 스튜디오(컴퓨터)에서 영상 세부정보 → 썸네일 → **'테스트 및 비교'**에 3장을 모두 넣는다.
  - 이 기능은 **시청 시간 비율**로 이긴 것을 고른다. 클릭률만 높고 끝까지 안 보면 본안이 질 수도 있다.
- 결과가 나오면 각 `thumbnail_N.md`의 '결과' 칸과 `titles.md` 결과 칸에 적는다.
