## 1. 시청자

- 우주 뉴스·영상을 즐겨 보지만 전문 지식은 없는 성인. 쇼츠와 자극적인 제목으로 우주 소식을 처음 접하는 사람이 많다.
- 시청자가 실제로 쓰는 말로 부른다. (예: "소행성 뉴스에 놀란", "첫 실패만 본", "낚시 영상 믿은", "우주 쇼츠만 본")

## 5. 기준 제목

아직 확정작이 없다. 첫 영상 3개의 채택 제목(T1, Claude 선택)은 4번 제작 현황에 있다 — 사용자 피드백이나 업로드 성과가 나오면 그중에서 기준 제목을 정한다. 그때까지는 공통 2번 주식 기준 제목의 구조(문제 행동 + 숫자 반전. 대상 + 결말 장치)를 따른다.

## 6. 숫자 기준값 (공통 4-10)

- **숫자 반전 = 실제 발표 숫자의 반전.** 주식의 금액 대신 아래 숫자를 쓴다. 제목 숫자 = 사연 숫자 (공통 4-4).
  - 확률: "3.1% → 0.004%" (발표값 그대로, 기관 하나로 통일)
  - 횟수: "첫 실패 1번 → 4번 연속 성공"
  - 시간: "46초 모자란 실패", "다섯 달 만에 복구"
  - 거리: "빛으로 하루 거리", "259억 km"
- **제목 안 숫자는 두 개까지** (반전 숫자 한 쌍). 분석: 숫자 포함 제목 0.51배, 롱폼 0.38배 (`data_insights.md` 3번).
- 사연 속 돈은 1천만 원 이하 (`script_rules.md` 1번). 돈은 제목에 넣지 않아도 된다.
- 손실은 공통 4-9처럼 '크기'로 보여 주되, 우주 숫자(확률·횟수·거리)는 %·횟수 그대로 쓴다.

## 8. 분석 결과 반영 (근거: `data_insights.md` 3·4번)

1. **제목 길이는 60자 이하.** 61자 이상 37.5%(n=32, 롱폼 39.3% n=28) vs 51~60자 50.0%(n=12). 30~60자는 비슷하다. (공통 4-1의 50~65자보다 짧게)
2. **결말 장치: 공통 4개 + 호기심형 "진짜 이유" / "결국 ~".** 호기심 단어(이유·진짜·결국)가 롱폼에서 3.32배, 성공 72.0% vs 48.8% (n=25, p=0.026)로 가장 뚜렷했다. **영상별 제목 3개 중 1개 이상**에 넣는다.
3. **물음표는 금지하지 않는다** (롱폼 1.57배, n=38 — 주식과 반대). 단 기본은 마침표 두 구절이고, 물음표 제목은 3개 중 1개까지 시험으로만 쓴다.
4. **쓰지 않는 요소:** 긴급성(지금·당장·속보) 0.19배, 괄호·대괄호 0.29배, 제목 안 해시태그 0.40배, 따옴표 0.52배, 공포/경고 단어(멸망·종말·위기·절대) 0.59배. 느낌표는 데이터가 약해(p=0.80) 채널 톤대로 쓰지 않는다.
5. 영상별 제목 3개 중 1개(T3)는 **30~45자의 짧은 변형**으로 만든다 (공통 11-3). 31~40자 성공 51.5%(n=33).
6. 사용자가 제목 선택을 맡기면 Claude가 가장 강한 것을 골라 `titles.md`에 `[x]`·"채택"으로 표시하고 이유를 한 줄 남긴다 (주식 규칙과 같음).

## 10. 사실·신뢰 (공통 8번에 더해)

- **금지 표현:** "인류 멸망", "지구 종말", "나사가 숨긴", "충격 폭로", "지금 당장", "속보", 실존 우주비행사·과학자 이름을 내세운 제목, 기관 이름을 사칭하는 표현("나사 공식 발표" 같은 제목 머리말)
- 실제 발표보다 위험을 크게 보이게 하는 제목은 만들지 않는다 (예: 0.004%가 된 뒤에 "충돌 확률 3%"만 쓰기).
- 제목의 "~됐습니다" 단정형은 사연 파트가 있을 때만 쓴다 (공통 8번).
