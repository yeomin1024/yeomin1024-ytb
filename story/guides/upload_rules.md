# 사연을 통한 교훈 — 업로드 전용 규칙

버전: v1.2 — 2026-10-12 — `data_insights.md` v2.0 반영(사용자 지시: 작은 채널 성공 사례·댓글 중심으로 다시 분석): **광고 체험담 댓글 숨김**, 고정 댓글 질문 예("여러분이라면 그때 어떻게"), 현실성 댓글·태그·수익 정책 근거 갱신 (v1.1 — 2026-10-11 — 분석 결과(v1.0) 반영: 재구성·고지 문구를 `[장면]` 카드와 같게, 태그 후보, 법률 질문 댓글 응대, 업로드 시간 참고; v1.0: 최초 작성)

공통 규칙 `guides/upload_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

## 1. 설명란에 꼭 넣는 것

- **재구성 사연 문구** (`[장면]` 카드 1번 줄과 같은 뜻):
  > 이 영상의 사연은 실제 법과 통계를 바탕으로 재구성한 이야기이며, 등장인물은 실존 인물이 아닙니다.
- **고지**: 대본 TXT `[장면]` 카드 문구 4줄을 그대로 (`script_rules.md` 2번 — 법률 자문 아님, 사정마다 다름 → 변호사·대한법률구조공단 132, 기준일).
- **출처**: README "출처" 표의 법 조문(국가법령정보센터)·판례·헌재 결정·공식 통계 링크. 법이 바뀐 내용은 날짜와 함께("2026.3.17. 개정 민법 제1004조의2").
- 설명란 첫 2줄: 사연의 반전 + 영상이 알려 주는 법·방법 (예: "8년 모신 시아버지의 집, 며느리 몫은 0원이었습니다. 며느리는 왜 상속인이 아닌지, 간병한 가족이 지금 남겨야 할 기록과 서류를 정리했습니다.")
- 개별 사건 판단처럼 읽히는 말("이렇게 하면 돌려받습니다")은 쓰지 않는다.

## 2. 태그 후보 (분석 결과의 성공 태그·검색어)

영상마다 아래에서 10~15개를 고르고, 그 영상의 법·제도 이름(대본에 나온 것만)을 더한다. 순서 = 핵심 검색어 → 넓은 주제어 → 법·제도 이름.
- **성공 태그 (리포트 10장, 성공 수/영상 수):** 노후사연(13/14), 인생사연(10/13), 시니어사연(11/15), 인생조언(6/8), 인간관계(6/9), 고부갈등(9/15) — 사연에 맞을 때만
- **검색어(키워드):** 시아버지 며느리 사연, 고부갈등 사연, 시니어 사연, 돈 빌려주고 못받을때, 인간관계 정리 / (미수집이지만 설정에 있는 것) 유산상속 분쟁, 형제간 재산 다툼, 떼인 돈 받기
- **법·제도 이름:** 상속, 유언, 기여분, 유류분, 증여, 효도계약, 상속권 상실, 차용증, 소멸시효, 지급명령, 소액소송, 대한법률구조공단
- **쓰지 않는 태그:** 사이다사연·참교육·반전사연·실화사연·시월드·레전드사연(분석기 성공 3/85·3/44·4/81·5/51·2/43·1/39 — 이 태그가 붙은 영상의 79~100%가 대형 채널 두 곳(깡냉이톡썰·사연튜브)의 대량 생산 영상이라, 태그 탓이라기보다 그 채널들 탓이다. 그래도 재구성 사연·법 정보 채널과 맞지 않아 쓰지 않는다), 불륜사연·외도사연(쓰지 않는 소재), 오디오북·사연라디오(이 채널 포맷이 아님 — 오해 유도. 작은 채널 성공 사례 제목 18개 중 7개에 "오디오북"이 있지만 30분 넘는 낭독 영상이다 — `data_insights.md` v2.0 2-1)

해시태그 3개: 사연 1개 + 법·제도 1개 + 대상 1개 (예: `#노후사연 #상속 #며느리`, `#인간관계 #차용증 #빌려준돈`). 제목에는 해시태그를 넣지 않는다 (`title_rules.md` 8-2).

## 3. 고정 댓글

- 질문은 시청자의 경험을 묻는다. 금액·실명·가족 관계의 세부를 공개하라고 요구하지 않는다. (예: "가족이나 친구와 돈 문제로 서류를 남겨 두신 적 있나요?")
- 사연 속 그 순간의 선택을 묻는 질문도 쓸 수 있다 (예: "여러분이라면 그때 차용증 얘기를 꺼내셨을까요?"). 사연 영상 시청자는 원래 "나라면 이렇게 했다"는 댓글을 많이 단다 (행동 조언·답답함 댓글 좋아요 20% — `data_insights.md` v2.0 3-4). 다른 채널의 같은 질문에는 답글이 없었으니(0개) 효과는 업로드 뒤 확인한다.
- 마지막에 이 줄을 붙인다:
  > ※ 개별 사건은 변호사나 대한법률구조공단(국번 없이 132)과 상담해 주세요. 댓글에 실명·연락처·계좌·주소는 쓰지 마세요.

## 4. 댓글 응대·관리

- **법률 질문 댓글:** 개별 사건에 답하지 않는다. 영상에서 말한 일반 내용(조문·제도 이름)까지만 짧게 답하고 "사정마다 결과가 달라 132나 변호사 상담을 권합니다"로 끝낸다.
- **개인정보:** 실명·연락처·계좌·주소·사건번호가 든 댓글은 숨기거나 삭제한다 (본인 것이라도).
- **특정인 비난·혐오 댓글**(시어머니·며느리 등 집단 비하, 욕설)은 숨긴다. 사연 속 인물은 가상 인물이라는 점을 필요하면 답글로 한 번 알린다.
- **광고 체험담 댓글은 숨긴다:** 나이·이름을 밝히며 건강용품·화장품·책의 효과를 말하는 댓글, 링크·"프로필을 누르면" 댓글. 근거: 작은 채널 성공 사례(다른 채널) 3개 영상에 이런 댓글이 있었고(좋아요 183), 한 영상은 맨 위 댓글(좋아요 98)이었다 — 같은 문장에 이름·나이만 바꾼 것도 있었다 (`data_insights.md` v2.0 3-7). 50~70대 시청자를 노리는 광고로 보인다.
- **"현실성 없다" 댓글**은 다음 대본 검산에 반영할 점으로 `upload.md` 결과 칸에 적는다. 특히 숫자·나이·날짜가 안 맞는다는 지적은 바로 확인한다 (다른 채널 사연에서 현실성 비판 23개·나이 계산 지적 21개 — `data_insights.md` v2.0 3-6).
- 차단 단어(스튜디오 → 설정 → 커뮤니티): 대출 문의, 급전, 채권추심 대행, 카톡 상담, 텔레그램, 오픈채팅, 수임료 할인

## 5. 업로드 설정

- 카테고리: 교육 (법·제도 해설이 있으므로)
- 업로드 시간(참고만): 분석상 화·금, 오전 9~11시 성공 비율이 높았다 (화 40%·금 39%, 09~11시 65% n=20 — 효과가 작고 섞인 요인이 많음). 예약 공개 시각을 고를 수 있으면 이 시간대를 먼저 검토한다.
- **YouTube 수익 정책 주의:** 같은 틀의 사연을 AI 음성으로 찍어 내는 것처럼 보이지 않게, 영상마다 다른 법·통계 근거와 해설을 넣는다. 시청자도 알아챈다: "Ai로만든 이런 영상엔 항상 갑부가 상처 투성이로 나오고…"(좋아요 6), "같은 얘기 반복만"(7) — AI 티·반복을 지적한 댓글 14개 (`data_insights.md` v2.0 3-6·3-7). "변경되거나 합성된 콘텐츠"는 공통 규칙(`guides/upload_guide.md` 6번)을 따른다.
