# 건강 — 업로드 전용 규칙

버전: v1.0 — 2026-10-10 — 최초 작성

공통 `guides/upload_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

1. 설명란에 꼭 넣는 것
   - 재구성 사연 문구: "이 영상의 사연은 실제 진단 기준과 통계를 바탕으로 재구성한 이야기입니다."
   - 고지: 화면 카드 4줄 그대로 (`script_rules.md` 2번)
   - 출처: 영상에 나온 통계·연구마다 링크 (공공기관·논문)
2. 태그: 질환·검사 이름(예: 당뇨 전단계, 공복혈당, 당화혈색소) + 나이대(50대 건강검진) + 넓은 주제(건강, 건강검진). 약·제품 이름은 넣지 않는다.
3. 고정 댓글 끝에 붙이는 줄: "※ 개인 증상·약에 대한 질문은 진료하는 의사와 상담해 주세요. 영상은 진단을 대신하지 않습니다."
4. 댓글 차단 단어(스튜디오 설정): 영양제 판매·상담 유도 — "카톡 상담", "구매 링크", "100% 완치", "특효약", "문의 주세요"
5. 카테고리: 교육 (또는 "인물/블로그"가 아닌 "교육"으로 통일)
6. YouTube 건강 정보 정책: 공공기관 출처와 다른 주장을 하지 않는다. 의학적 효과를 단정하지 않는다.
