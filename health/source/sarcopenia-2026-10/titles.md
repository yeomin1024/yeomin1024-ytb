## ✅ 채택 제목
> **만 보만 걸으면 된다고 믿다가 2년 만에 악력 17kg, 근감소증이 됐습니다. 걷기만 하는 사람들의 공통점**

채택 이유:
- 검사 숫자(악력 17kg)와 반전(만 보 → 근감소증)이 앞 구절 안에 있다 — 롱폼 숫자 제목 54.5% vs 18.2% (`data_insights.md` 3번, 보정 뒤에도 유의한 유일한 요소), 공통 4-14.
- 속마음 훅 "걸으면 된다고 믿다가"는 건강 제목 규칙 7-1의 "걷기만 하면 된다고"와 같은 방향이고, 대본 문장 3 "건강은 걷기만 하면 충분하다고 믿었고"와 같다.
- "만 보만"·"걷기만"의 '만'이 문제를 걷기 자체가 아니라 **걷기만 한 것**에 둔다 (공통 4-11 — 대본 방법 다섯째 "걷기는 계속하되", 마무리 "만 보는 그대로 두고"와 맞음). 앞 구절 "만 보" ↔ 뒤 구절 "걷기"로 두 검색어(만보 걷기·걷기 운동)를 나눠 잡았다.
- 59자 — 건강 기본 길이 51~60자 안. 결말 "공통점" = 대본의 문제 5개(걷기만으로는 근력이 안 늚·근력운동을 안 함·체중계만 봄·나이 탓·손힘을 넘김).

### 점검
- 세 제목 모두 숫자가 대본과 같다: 만 보(문장 1·5), 2년(문장 1·6), 악력 17kg(문장 10), 6kg(문장 6·15), 60대 = 예순 → 예순둘(문장 2). "근감소증이 됐습니다"는 문장 12 "근육량까지 기준보다 적어서 근감소증이라는 진단"과 같은 사건이다 — 근육량 저하 + 근력 저하(AWGS 2025 진단 = 근육량 + 근력, README 검산 표).
- 숫자 기준값(`title_rules.md` 6-2): 악력 17kg = 50~64세 여자 기준 20kg 미만(AWGS 2025)·65세 이상 기준 18kg 미만(AWGS 2019)이어서 어느 기준으로도 근력 저하. 6-2 표의 "남 28kg·여 18kg"은 65세 이상 기준이다 (사연자 62세는 2025년 50~64세 기준을 씀 — README "기획서와 달라진 점"). 기간 2년(1~3년 안), 몸무게 변화 6kg(5~6kg 안팎).
- 기획서 초안(악력 25kg, 남성)과 다르다: 대본이 사연자를 **여성**(사연 목소리 Sohee)·악력 17kg으로 바꿨기 때문 (README "기획서와 달라진 점" 첫 줄).
- 훅·결말이 모두 다르다: 속마음 / 행동 / 장면(작은 만족) — 공통점 / 후회 / 불편한 진실. 결말 장치는 건강 규칙 7-3의 3개 안에서만 썼다 (T2의 "꼭 하는 후회"는 "마지막에 꼭 하는 후회"를 61자 안에 넣으려고 줄인 것).
- 길이(8-3): T1 59자 · T2 59자 (51~60자) · T3 48자 (45~50자). 61자를 넘는 제목 없음. 모두 두 구절.
- "N가지" 변형은 시험하지 않았다: T1에 "5가지"를 붙이면 63자로 61자 상한을 넘고, 짧은 변형 T3은 45~50자에 넣어야 한다.
- 행동 자체를 나쁘게 쓰지 않음(공통 4-11): 세 제목 모두 "걷기만"·"근력운동 없이"로 문제를 '걷기만 한 것'에 둔다. 대본도 걷기를 그만두라고 하지 않는다(문장 96~101).
- 쓰지 않은 표현(건강 제목 규칙 8·10번): 물음표·느낌표, 공포·경고 단어(최악·위험·경고·주의·조심·절대 등), "소용없다", "습관" 주어, 전문가 직함, 추천·순위·TOP, 완치·약 없이·이것만, 운동 기구·보충제·제품 이름 — 없음.
