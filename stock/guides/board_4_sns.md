- **본문에 '댓글'을 직접 말하지 않고 호기심·군중 심리를 자극하는 멘트** (판 피드백 2026-11-04 "댓글을 직접 언급하지말고 최대한 유저들의 호기심, 군중 심리 등 심리 자극하는 멘트 써봐"): 소개 글 '몇 개나 해당될까요? 솔직하게 세어 보세요' + 마지막 글 '당신은 몇 개? 숫자 하나만 남겨 보세요. 다른 사람들은 몇 개씩 나왔는지 궁금합니다'(`CLOSER`). **근거 없는 통계·'대부분이 …' 단정은 쓰지 않음** (도구가 본문의 '댓글' 낱말을 막음). 낱말은 quick_board 규칙 37 — '빠졌다' ✗ '하락했다', 금리차는 '역전됐다'.

## 2. 명령
```bash
git pull --rebase origin main
python3 tools/sns_posts.py            # 원본 json → stock/topics/sns/sns_posts.md (복사용) + stock/topics/SNS평가판.html · 한도·K8·정답 몰림을 어기면 멈춤
```
- 판 피드백: `ArtifactData query feedback where status == new` (url = 판) → 줄 피드백(`lines` — 판의 줄 번호는 편·플랫폼마다 1부터, `quote` 로 어느 문항인지 확인)·칸 피드백(`field`) → **원본 json 을 고침**(글은 도구가 다시 짬) → 원본 `ver` 올림 → 도구 → 판 다시 올림 → 피드백마다 done·reply.
- 판정 '통과 (올림)' = 사용자가 그 글을 그대로 올림. 영상이 올라가면 `video_link` 를 채우고 도구 다시.
