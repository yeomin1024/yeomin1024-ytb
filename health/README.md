# 건강 주제 폴더 (`health/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **건강에만 해당하는 것**만 둔다. 구조는 `stock/`과 같다.
※ 건강 정보 제공용 콘텐츠다. 의사의 진단·치료를 대신하지 않는다.

분석 결과(`result/`, 실행 2026-10-11)가 나와서 규칙을 다시 검토했다 (`guides/data_insights.md` v1.0). 이제 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).
2026-10-12: 사용자 지시로 근거를 **작은 채널 성공 사례·댓글의 시청자 니즈**로 다시 만들었다 (`guides/data_insights.md` v2.0 — 주식에서 빌린 근거 정리, 쇼츠가 섞인 근거 교체). 규칙: 대본 v1.4·제목 v1.3·썸네일 v1.3·업로드 v1.2.

## 영상 제작 현황

영상 3개는 패키지(대본·SRT·제목 3개·썸네일 프롬프트 3개·업로드 시트·요약)를 마쳤고 오디오를 기다린다 (2026-10-11). 길이는 SRT 추정(초당 약 5.2음절)이라 오디오가 생기면 바뀐다. 규칙의 목표 분량은 10분 안팎(8~12분, `guides/script_rules.md` v1.4 6번)이다.

## 분석 돌리기
```
bash tools/run_analysis.sh health          # 클라우드 (남은 키워드 35개 이어서 수집, 받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config health/analyzer_config.toml   # PC (자동완성·자막·썸네일까지)
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 8번 절차로 근거를 갱신한다. 최근·작은 채널 사례는 YouTube Data API 키로 `tools/outlier_research.py`를 돌려 다시 모은다 (`data_insights.md` 6번).
