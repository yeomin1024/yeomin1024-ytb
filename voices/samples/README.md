# 목소리 후보 샘플 — 듣고 하나씩 고르기

자동 생성 — `tools/tts_narration.py samples` (v1.15). 후보 설정: `samples.json`. 고친 뒤에는 Kaggle 셀을 다시 돌리면 바뀐 후보만 다시 만든다.

**고르는 법:** 아래 mp3를 듣고 Claude에게 "사연자 S0?, 진행자 H0?"라고 말한다 → Claude 가 `python tools/tts_narration.py pick S0? H0?` 로 고정하고 main 에 올린다 → Kaggle 셀을 다시 돌리면 그 목소리로 모든 대본의 오디오를 만든다.
- **current(지금 목소리)** 를 고르면 그 역할은 아무것도 바뀌지 않는다. 다른 후보를 고른 뒤에는 '고르기 전 목소리' 기록으로 남는다 (다시 고를 수는 없음 — git 으로 되돌림).
- 다른 후보를 고르면, 아직 올리지 않은 영상 중 그 역할 오디오가 이미 있는 것은 다음 Kaggle 실행 때 새 목소리로 다시 만든다 (모든 대본 같은 목소리). 이미 유튜브에 올린 영상(youtube.json 있음 — 주식 4개)은 그대로 둔다.
