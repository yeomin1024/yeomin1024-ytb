- 분류: "벌었다가 금액 키워 반납" — 「주식으로 돈 벌고도 결국 망하는 사람들의 3가지 공통점」(판돈 확대·손실 회피·무리한 물타기, 53배), 「공격적인 투자자가 결국 망하는 과정」(31배), 「주식으로 인생 망하는 사람들의 공통점」(챕터: 비기너스 럭과 과신 → 레버리지 → 손절 실패·복수 매매 → 시장을 떠남 → 살아남는 투자자). 댓글: "금액 계속 증액하다 하락장 한번 맞으면 수익 한번에 반납", "씨드 작을때 … 천재인가바 하면서 씨드올리기 시작하는 순간 나락" (`stock/guides/script_rules.md` 5번 속마음 은행).
