## 3. 영상으로 만들 때 꼭 넣을 것 (검토자가 남긴 지적 — 제목엔 다 못 넣음)

- **공통**: 도입 첫 문장에 기간·자료(지수 가격 / 배당 포함)·달러 기준. 결론 1개 + '그래도 다른 경우' 1개를 같이 (고른 기간 의심 — 반론 K3).
- T1: '15년'은 2000년 닷컴 한 번뿐 — 4번 중 3번은 2.1년 안 (가운데값). 매달 사 모은 사람은 어떻게 다른지(P1 질문 — 계산 더 필요).
- T2: −40.8% 는 DVY 하나 — VYM −34.6%, SCHD −32.8%(S&P 와 비슷), 2022·2025 엔 덜 빠짐까지 화면에. "고배당 = 늘 덜 빠진다"가 아니라 "폭락 꼴에 따라 다르다".
- T3: 1년 뒤뿐 아니라 3·5년 뒤도(연금은 오래 두는 돈 — P3·반론) · 1950년부터 센 까닭(일별 자료) · 11번 전부(빼지 않음) · 배당 넣으면 2001 은 +0.5%.
- T4: 기간 1993~2026 · '모든 시작일 1년' 뜻 · 5년에 한 번 봐도 15.1% 는 내린 적 있음(2000년대) — '오래 두면 무조건'이 아님.
- T5: 멈춘 돈 이자 0 으로 셈(예금 이자를 넣으면 차이가 조금 줄어듦 — 계산 더 필요) · 월 50만 원 금액으로(2007-10 시작이면 485만 원 차이) · 2000년 폭락도 같은 쪽.
