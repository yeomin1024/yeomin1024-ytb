## 0. 목표·순서·입출력
- **목표:** 50~70대 시청자가 내레이션을 들으면서 화면만 봐도 바로 이해한다. 화려함보다 **이해**가 먼저다.
- **순서 (사용자 지시 2026-10-15 "오디오를 먼저 만들고나서 영상"):**
  1. 대본 → 2. **오디오** (Kaggle, 진행자 H04 목소리 하나 — `guides/tts_guide.md`) → 3. **오디오가 생긴 뒤에만** 영상
  - 오디오 없이 무음 영상이나 추정 시각으로 영상을 먼저 만들지 않는다. 장면 시각은 오디오에 맞춘 자막 시각이다.
- **입력** (`<주제폴더>/source/<영상ID>/`):
  | 파일 | 쓰는 곳 |
  |---|---|
  | `<영상ID>.txt` | 문장·파트 라벨(장 이름표)·`[장면]` 고지 카드 |
  | `<영상ID>.srt` | 자막 문장·시각 — `align-audio`로 오디오에 맞춘 것 (2-2) |
  | `narration.mp3`·`tts_narration.json` | 내레이션과 문장별 시각 |
  | `README.md`·`checklist.md`·`calc/` | 화면에 쓰는 숫자 (계산 코드 값) |
  | `thumbnails/thumbnail_N.md` | 색의 뜻·시청자층 낱말을 썸네일과 맞춤 |
- **출력:**
  - `video/episodes/<영상ID>/index.html` — 장면·타임라인 한 파일. 브라우저에서 바로 재생된다 (확인용으로 사용자에게 보여 줄 수 있음). git에 올린다.
  - `<주제폴더>/out/<영상ID>/final_1080p.mp4` — 1920×1080, 30fps, 자막을 구운 완성 영상. 용량 때문에 git에 넣지 않는다.
  - 점검용 still은 저장소 밖 임시 폴더에 둔다.

## 1. 절대 규칙
1. **숫자는 대본·계산 코드의 값만** 쓴다. 새 숫자를 만들지 않는다.
   - 아직 말하지 않은 숫자 자리는 `???`로 비운다. 아무 숫자나 돌리는 연출(룰렛 숫자)은 쓰지 않는다 — 가짜 숫자로 읽힌다.
   - 숫자가 올라가는 연출(카운트)은 내레이션이 그 숫자를 말하는 순간 시작해 그 값에서 멈춘다.
2. **자막을 화면에 굽는다** (사용자 지시 2026-10-15). 자막 문장은 SRT 그대로다 (3-5). 업로드 때 같은 SRT를 유튜브 자막으로도 올린다.
3. **장면 적합성:** 화면의 모든 요소는 그 순간 내레이션이 말하는 것을 그림으로 보여 준다.
   - 말보다 먼저 나오지 않는다. 자막에 없는 장식·분위기용 그림을 넣지 않는다.
   - 이미 나온 것(부부·우산·바구니)은 다시 나올 때 **같은 모양·같은 색**으로 쓴다.
4. **그림은 코드로 그린다:** SVG·CSS 도형과 글자만. 사진·AI 이미지·스톡 영상·실제 로고·실제 화폐 도안·이모지를 쓰지 않는다.
5. **예전 스타일 금지:** 크림 종이 배경, 작은 카드에 라벨이 빽빽한 인포그래픽, 표를 그대로 옮긴 화면.
6. 특정 상품 가입·매수를 권하는 것처럼 보이는 연출을 하지 않는다.
7. 내레이션 오디오는 고치지 않는다 (자르기·늘이기·쉼 넣기 금지). 자막을 오디오에 맞춘다.

## 3. 디자인
### 3-1. 무대
- 1920×1080 고정 좌표. 배경: 짙은 남색 원형 그러데이션 (`#17243D` → `#0C1424` → `#070C17`).

### 3-2. 색 (뜻 고정 — 썸네일 `guides/thumbnail_guide.md`와 같은 뜻)
| 뜻 | 색 |
|---|---|

| 아낌·안전·기준 안, 아낀 쪽(예: B 부부) | 청록 `#22C7B0` |
| 기억할 기준·방법·장 이름 | 노랑 `#FFD400` |
| 기본 글자 | 흰색 `#F4F6FA` |
| 보조 글자·눈금 | 회청 `#9AA7BF` |
| 뜻 없는 금액 블록(돈의 구성, 국민연금 등) | 남색 계열 `#2E4470` · `#3C5788` · `#4A69A2` · `#5B7DB8` |
- 한 화면의 노랑은 기준·방법에만 쓴다. 빨강·청록은 비교하는 두 쪽에만 쓴다.

| 등장 | 0.5~0.6초, 아래 40px → 제자리, 투명 → 선명, `power3.out` |
| 퇴장 | 0.3~0.45초, 위로 30~60px, 투명 |
| 장면 바뀜 | 0.35초 겹쳐 사라지고 나타남 (`scene(start, end)`) |
| 숫자 카운트 | 1.2~1.8초 `power2.out`, 말하는 순간 시작 |
| 막대 자람 | 0.9~1.8초 `power2.out`, 실제 비율 (눈금이 있으면 같은 축) |
| 지우는 줄 | 빨강 사선 0.35초 (오답·'넘은 만큼?' 같은 틀린 생각) |
- 흔들기·번쩍임·빠른 깜빡임·화면 전체 확대를 쓰지 않는다. 반복 움직임(비)은 그 장면 안에서만 짧게.
- 무거운 효과(큰 `filter: blur`, SVG 잡음 필터, 큰 그림자)는 쓰지 않는다 — 렌더가 느려진다.

### 3-5. 자막 (굽기 — 사용자 지시 2026-10-15)
- 자리: 아래 가운데, 아래 끝에서 44px 위. 둥근 띠 배경 `rgba(5,9,18,.82)`, 글자 흰색 52px 700, 줄 간격 1.3, 띠 최대 너비 1600px.
- 내용: SRT 자막 하나를 그 시작~끝 동안 그대로 (SRT의 줄나눔 그대로, 한 번에 최대 2줄). 글자를 바꾸거나 줄이지 않는다.
- **자막은 2줄까지 — 예외 없음** (v4.13, 사용자 지시 2026-10-17 "그리고 자막은 2줄까지만 표시되도록 해"): 쇼츠 첫 문장(썸네일 그림 위)도 2줄. 그 자막만 글자 42px(`kit.css` `#cc.cover` — `srt_tool.py` v1.9 'shorts_cover')로 2줄 자막 하나에 넣는다 (자막 2개로 나뉘면 그림이 둘째 자막까지 남아 '다음 문장에도 그림'처럼 보임 — `srt_tool check` 가 잡음). 42px 로도 안 들어가면 대본에서 첫 문장을 줄인다. `render.mjs check` 는 늘 3줄 이상을 문제로.
- **나누기 — 한 문장 = 자막 하나 (v4.12, 사용자 지시 2026-10-17 "자막 좀 되도록 한 문장은 한 자막으로 표시되게해 길지 않은 문장도 잘라서 자막 띄우잖아 문장이 길면 적당한 곳에 분리하도록 해서 반영해 전부 계속 진행해")**: `srt_tool.py build` 가 띠의 글자 크기·폭으로 잰다 (롱폼 52px·한 줄 1500px, 세로 쇼츠 46px·816px — `LAYOUTS`).
  - 한 줄에 들어가면 한 줄. 넘으면 **같은 자막 안에서 두 줄** — 줄바꿈은 쉼표 뒤 > 절 경계(-고·-면·-는데…) > 조사 뒤, 숫자와 단위·날짜·범위('2,100만 원에서 약 1,300만 원')·'나이에 따라'·'본 걸'·'받고 있다'·'B 씨'·꾸밈말 뒤('지난 분이')는 한 줄에.
  - 두 줄로도 넘거나, 두 줄로 바꿀 곳마다 덩어리를 가를 때만 **자막 2개** (나누는 곳 = 쉼표·절 경계일 때만). 2026-10-17 재테크 4편: 롱폼 384문장 → 자막 386개 (예전 규칙 500개), 쇼츠 48문장 → 55개.
  - `check` 는 '하나에 들어가는데 나뉨'·'한 줄에 들어가는데 두 줄'·한 줄 폭·줄 수를 잡는다. 사람이 줄바꿈을 손으로 고쳐도 된다 (두 줄·폭 안이면 통과).
  - 주식(`stock/` — 자막을 굽지 않음)은 예전 한 줄 규칙(`line` — 46px 1432px, 넘으면 앞줄·뒷줄 자막 2개) 그대로.
- 색 강조를 넣지 않는다 (자막은 흰색만 — 색의 뜻은 화면 그림이 맡는다).
- 고지 카드 자리(`[장면]`)는 SRT에 자막이 없으므로 띠도 없다.

### 3-6. 그림 부품 (시안 `storyboard.html`에 있는 것 그대로 다시 쓴다)
| 부품 | 쓰는 곳 | 모양 |
|---|---|---|
| 사람·부부 | 사례 인물 | 원 + 둥근 몸통(회백), 아래 배지(`A 부부` 빨강 · `B 부부` 청록) |
| 돈 블록 쌓기 | 같은 돈의 구성 (예금 2억·연금저축 1억·퇴직금 2억) | 남색 계열 블록, 높이 = 금액 비율 |
| 금액 카운터 + 막대 | 두 쪽 금액 비교 | 큰 숫자 + 같은 축의 막대 (길이 = 금액) |
| 기준선 | 모든 기준 | 노란 점선 + 이름표('이자·배당 기준 1,000만 원') |
| 쌓는 막대 | 합계가 기준을 넘는지 (1,050 + 1,320 = 2,370 > 2,000) | 한 줄 막대에 차례로 이어 붙이고, 기준선은 합계가 나온 뒤 내려온다 |
| 우산 | 피부양자 (자녀 건강보험) | 노란 테두리 우산, 밖으로 나가면 비 |
| 바구니 | 사람마다 따로 있는 기준 | 바구니 둘(남편·아내) + 노란 점선, 동전 = 100만 원 |
| 동전 | 한 달 금액·작은 단위가 쌓여 큰돈 | 동전 쌓기, 손해면 빨강 |
| 달력 카드·봉투 | 시간 순서 (올해 → 다음 해, 고지서) | 카드 두 장 + 봉투 이동 |
| 번호 카드 | 결론·순서 | 노란 번호 + 2줄 글자 |
| 장 이름표 | 파트 라벨 | 왼쪽 위 알약 모양, 원칙이면 점(●○○) |

## 4. 대본 내용 → 장면 모양
| 대본이 말하는 것 | 장면 |
|---|---|
| 같은 조건의 두 사례 | 부부 둘 + 같은 돈 블록 + 노란 `=` |
| 두 금액의 차이 | 카운터 둘 + 같은 축 막대 (빨강·청록) |
| 기준·한도 | 노란 점선 기준선, 넘으면 빨강 |
| 넘으면 전부 (절벽) | 넘은 조각을 '넘은 만큼?'으로 보여 주고 지운 뒤, 막대 전체를 빨강으로 |
| 합계 | 쌓는 막대 + '= 합계' 카운터 |
| 작은 돈이 쌓임 | 동전 쌓기 → 큰 숫자 하나 |
| 제도 자격 | 그 제도의 그림 하나(우산 등) 안·밖 |
| 순서·결론 | 번호 카드 |
| 시간이 걸리는 일 | 달력 카드, 연도 칸(1·2·3·4·5) |
| 물음 | 큰 '왜?' → 오답 지우기 → 답은 노랑 |

## 5. 장 이름표와 구성
- 대본의 파트 라벨(`-원칙 하나, 기준은 한 사람씩`)이 장 이름표다. 앞부분 = '도입', 원칙이면 '원칙 1' + 점 표시.
- 장이 바뀔 때 0.3초 이름표를 바꾼다. 대본에 장 전환 멘트가 있으면 그 문장 동안 다음 장 이름을 크게 한 번 보여 준다.

### 6-1. 코드 화면 + AI 장면 클립 (v4.14 — 2026-10-19, 롱폼·쇼츠 둘 다)

## 7. 작업 순서 (오디오가 올라온 뒤)
