# 우주 주제 폴더 (`space/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **우주에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 과학 정보 제공용 콘텐츠다. 사연은 실제 발표와 보도를 바탕으로 재구성한 이야기이며, 실존 인물(우주비행사·연구원·피해자)을 흉내 내지 않는다.

분석 결과(`result/`, 실행 2026-10-11)로 규칙을 처음 만들었다 (`guides/data_insights.md` v1.0). 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).

## 영상 제작 현황

| 영상ID | 제목 방향 | 상태 |

| `voyager-2026-10` | '보이저 1호는 끝났다'는 영상을 믿고 학생들에게 가르쳤는데, 고장 다섯 달 만에 복구되고 빛으로 하루 거리(2026-11-18)에서 아직 신호 (탐사선 근황 영상 확인법) | 기획 |
| `asteroid-2026-10` | 소행성 2024 YR4 충돌 확률 3.1%에 겁먹고 생존 용품부터 샀는데 엿새 뒤 0.004%, 달 충돌 4.3%도 2026년 0으로 (확률 뉴스 읽는 법) | 기획 |

## 파일

| 위치 | 내용 |
|---|---|
| `analyzer_config.toml` | 분석기 설정: 검색어 48개(사고·실화 / 미스터리·외계 생명체 / 우주의 크기 / 탐사·우주망원경 / 뉴스·위험 / 다큐·수면 포맷), 관련어·제외어 ('우주' 단독 검색은 노래·게임·주식이 섞여 curated 모드) |
| `result/` | 분석 결과 (2026-10-11 실행 `20261011_120612`, 키워드 48개 중 13개 수집 — 직접 고치지 않음) |
| `guides/data_insights.md` | v1.0 분석 결과 요약: 롱폼 48.8%, 길이(12~20분 해설이 작은 채널에서 성공 → 목표 12~14분), 제목 요소(호기심 단어 효과, 긴급성·괄호·해시태그 역효과, 60자 이하), 카테고리 판단(뉴스·위험 71 → 탐사 55, 사고·실화 34 제외), 벤치마크 채널, 시청자 질문 (말하기 속도·도입부·썸네일은 주식 결과 임시 사용) |
| `guides/script_rules.md` | v1.0 우주 대본 규칙: 재구성 사연(실존 인물 흉내 금지, 억울·후회 고백), 파트 구성(문제 분석 = 오해·위험 분석, 올바른 방법 = 제대로 아는 법·대처법), 고지 카드 "과학 정보 제공용 재구성 사연입니다", 출처·숫자 규칙(최신, 1900년대 사건 금지, 발표 날짜), 예상 반론, 분량 12~14분, 마무리 인사, 근거 자료 은행 |
| `guides/title_rules.md` | v1.0 우주 제목 규칙: 상시 고민 목록·제작 현황, 숫자 반전(확률·횟수·시간·거리, 두 개까지), 60자 이하, 호기심형 결말 허용, 금지 표현 |
| `guides/thumbnail_rules.md` | v1.0 우주 썸네일 규칙: 색 의미(위험·틀린 정보 빨강 / 사실·안전 파랑), 실존 인물·우주복 인물·기관 로고·실제 화면 서식·일어나지 않은 폭발 장면 금지, 소품 |
| `guides/upload_rules.md` | v1.0 우주 업로드 규칙: 설명란 재구성 문구·고지·발표 날짜가 붙은 출처, 태그 후보, 음모론·혐오·관련주 댓글 응대 |
| `voices/storyteller.json` | 사연자 말투(우주 소식을 잘못 받아들인 후회 고백) — 공통 `voices/storyteller.json` 위에 instruct만 덮어씀. 화자 Sohee 그대로 |
| `source/used_content.md` | 이전 대본과의 중복 방지 목록 (아직 대본 없음) |

## 분석 돌리기
```
bash tools/run_analysis.sh space          # 클라우드 (남은 키워드 35개 이어서 수집, 받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config space/analyzer_config.toml   # PC (자동완성·자막·썸네일까지)
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.
