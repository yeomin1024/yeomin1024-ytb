# eonje-maesu-2026-10 썸네일 — 글자 없이 그림만, 결말은 가린다 (전 세계 대상)

버전: v1.0 — 2026-10-16 — 최초 (`stock/guides/README.md` 3번 — 글자 없음 · 두 선택을 같은 크기로 · 결과는 닫힌 상자로 가림, 사용자 지시 2026-10-15·2026-10-16).

## 1. 짝 제목과 그림이 전할 한 가지
- 짝 제목: `titles.md` R1 「매수 타이밍, 손절·익절·이평선 등 매수 규칙 10가지는 사서 들고만 있기보다 더 벌까? 32년 백테스트」 (10개 언어 모두 같은 뜻).
  - 썸네일에는 글자가 없으므로 언어와 상관없이 한 장이다.
- 그림이 전할 것: **"규칙 10가지를 들고 바쁜 사람과, 그냥 사서 들고만 있는 사람 — 누가 더 벌었을까?"**
  - 결과는 그리지 않는다. **닫힌 상자**(빛이 새어 나옴)로 가린다.
  - 두 쪽을 같은 크기·같은 높이로. 이기거나 진 표정(뽐냄·좌절)을 쓰지 않는다 — 바쁨·침착함.
- 색 = 영상과 같은 **사람 표시** (이긴 쪽·진 쪽의 뜻이 아님): B(규칙) = 빨강, A(관망) = 청록, 기준 = 노랑, 배경 = 짙은 남색.
- 규칙 10가지의 그림 = 영상 장 카드의 아이콘과 같은 모양 (팔각형 정지 표지 = 손절, 계기판 = RSI, 엇갈리는 두 선 = 골든 크로스, 칸 12개 = 분할 매수, 내려가는 계단 블록 = 물타기, 깃발 = 익절, 위로 뚫는 화살표 = 돌파, 매끈한 점선 위 지그재그 선 = 이동평균선, 달력 + 화살표 = 모멘텀, 별 + 점선 = 저점 매수) — 글자·숫자 없이.

- 이미지 수치: 빨강 비율 P 0.58 · 어두운 비율 P 0.61 → **짙은 남색 배경 + 빨강 요소**.

- 한계: 근거는 한국어 작은 채널의 썸네일이다. '글자 없는 썸네일'·'결과를 가린 그림'·'아이콘 무리'의 근거는 없다 (사용자 지시와 영상 장 카드에 맞춰 정함).

## 4. 검수 (이미지가 올라오면 — 공통 10번 + 주식)
