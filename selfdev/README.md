# 자기계발 주제 폴더 (`selfdev/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **자기계발에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 자기계발 정보 제공용 콘텐츠다. 의사·상담 전문가의 진단을 대신하지 않는다.

분석 결과(`result/`, 실행 2026-10-11, 키워드 48개 중 13개)가 나와서 규칙을 만들었다 (`guides/data_insights.md` v1.0). 2026-10-12 사용자 지시로 근거를 작은 채널·최근 성공 사례 9개와 그 댓글의 시청자 니즈로 다시 정리했다 (v2.0, `result/outliers/`). 사용자 지시(2026-10-11: 주식 밖 주제도 주제마다 최대 3개, 오디오 전까지)에 따라 영상 3개를 기획했고, 3개 모두 패키지(대본·SRT·제목·썸네일 프롬프트·업로드 시트·요약)를 만들었다 — 오디오(Kaggle 내레이션) 대기.

## 분석 다시 돌리기
```
bash tools/run_analysis.sh selfdev                               # 클라우드
python youtube_topic_analyzer.py --config selfdev/analyzer_config.toml   # PC
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.

> 2026-10-11 실행은 키워드 48개 중 13개만 수집됐다 (하루 쿼터를 5개 주제가 나눠 씀). 남은 35개는 다음 실행 때 이어서 수집된다. 자동완성·자막·썸네일은 클라우드 네트워크 정책으로 막혀, PC 실행 결과가 있으면 그것으로 보완한다.
