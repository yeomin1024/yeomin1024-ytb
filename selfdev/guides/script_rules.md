## 1. 시청자와 사연

- 시청자: 자기계발을 여러 번 시도했다가 작심삼일로 끝나 본 **30대 직장인**이 중심이다 (20대 후반~40대 초반도 포함).
  - 근거: 카테고리 "나이대·직장인 고민" 기회점수 70(1위), 성공 4/7 (`data_insights.md` 4-1). 댓글: "40대에 안 바꾸면 50대에 후회"(좋아요 511), "퇴근하면 아무것도 못 함"(1,284).
- 사연은 **유행하는 자기계발 방법을 잘못된 방식으로 따라 했다가 시간·돈·건강을 잃은 1인칭 후회**다.
  - 방법 자체를 조롱하지 않는다. "기준 없이", "잠을 줄여서", "한 번에 다 끊어서"처럼 **잘못된 방식**이 문제였다는 것이 보이게 쓴다 (공통 title_guide 4-11).
- 사연은 **실제 연구와 통계를 바탕으로 재구성**한다. 실존 인물의 이야기가 아니며, 실존 개인(유명 자기계발 유튜버·작가 등)을 1인칭으로 흉내 내지 않는다.
  - 영상 화면 캡션(`guides/video_guide.md` 1-11): **"실제 연구와 통계를 바탕으로 재구성한 사연"**
  - 영상 README에 사연 숫자의 검산 표를 남긴다 (날짜·일수·시간 계산, 기준값과 비교).
- 사연 숫자는 **생활 숫자**로 쓴다: 시간(하루 2시간, 5시간 수면), 일수(21일, 100일), 횟수, 스크린타임, 돈(수십만~수백만 원). 숫자는 연구·공식 통계의 범위 안에 있어야 한다 (예: 권장 수면 7시간 이상과 비교한 5시간).
  - 몸 수치(체중·혈당·혈압)는 기본으로 쓰지 않는다. 건강 주제(`health/`)와 겹치고 의학적 주장으로 읽힌다. 꼭 쓰면 연구 결과의 범위 안에서 "늘었어요" 수준으로만.
- **사연자 소개 (공통 0-1의 14번):** 비트 ②에 **나이와 생활**을 한 마디로 넣는다 (예: "서른넷, 야근이 잦은 직장인"). 근거: 제목에 나이대가 있는 롱폼 성공 2/5 vs 8/32 (직접 계산, n 작음).
- 사연자 목소리는 여성(Sohee, `selfdev/voices/storyteller.json`)이다. 성별이 드러나는 설정(남편·아내 등)은 여성 사연자에 맞춘다.

## 2. `[장면]` 고지 카드 — 정보 제공용 영상입니다

화면 고지에 아래 4가지를 모두 넣고 5~6초 노출한다. (공통 0-1의 6번) SRT에는 카드 자리에 3.5초 이상 공백 (공통 5-2)
1. 자기계발 정보 제공 목적이며 의사·상담 전문가의 진단을 대신하지 않음
2. 사연은 실제 연구·통계를 바탕으로 재구성한 이야기이고 숫자는 예시
3. 같은 방법도 사람마다 효과가 다름 — 수면·건강·마음 문제가 계속되면 전문가와 상담
4. 연구·통계 출처는 설명란에 있음

```
[장면] 정보 제공용 영상입니다
이 영상은 자기계발 정보 제공을 위한 것이며, 의사나 상담 전문가의 진단을 대신하지 않습니다.
사연은 실제 연구와 통계를 바탕으로 재구성한 이야기이고, 사연 속 숫자는 이해를 돕기 위한 예시입니다.
같은 방법도 사람마다 효과가 다르니, 수면·건강·마음의 문제가 계속되면 전문가와 상담하세요.
영상 속 연구와 통계의 출처는 설명란에 있습니다.
```

## 3. 사례·연구·숫자 규칙 (가장 중요)

1. **근거는 연구와 공식 통계만 쓴다.** 동료 심사 논문(메타분석·무작위 실험 우선), 공공기관(질병관리청, 통계청·국가데이터처, 과학기술정보통신부·한국지능정보사회진흥원), 학회 공식 자료. 블로그·유튜브·자기계발서·광고는 근거로 쓰지 않는다.
   - 대학 보도자료나 기사는 논문을 찾는 길잡이로만 쓰고, README 출처 표에는 가능하면 논문(학술지·연도·DOI)을 같이 적는다.
2. **되도록 최신 (사용자 지시 2026-10-10).** 2020년대 연구·통계를 먼저 찾고, 없으면 2010년대까지. **1900년대 사건과 1900년대 자료로 한 연구는 쓰지 않는다.**
   - 쓰지 않는 예 (자기계발 영상에 자주 나오는 옛 연구·출처): 마시멜로 실험(1960~70년대), "21일 습관"의 출처로 알려진 1960년 책, "1만 시간의 법칙"의 바탕 연구(1993), 의지력 고갈 실험(1998), "하버드·예일 목표 연구"(출처 불명 일화).
   - 이런 말을 바로잡을 때는 옛 연구를 소개하지 말고, **최신 연구가 실제로 보여 준 것**만 말한다 (예: "21일은 연구로 확인된 숫자가 아닙니다. 2024년 연구들을 모은 분석에서는 중간값이 59~66일이었고, 사람에 따라 4일에서 335일까지 달랐습니다.").
3. **유행하는 주장은 '연구로 확인된 범위'로 고쳐 말한다.** 대상: "21일이면 습관", "도파민 디톡스로 뇌를 리셋", "새벽 기상이 성공 비결", "2분 규칙·5초의 법칙"(책에서 나온 요령 — 연구 결과처럼 말하지 않는다), "뇌가 녹는다".
   - 의사과학(유사과학) 표현을 쓰지 않는다: "도파민 수용체 리셋", "뇌 퇴화", "호르몬 폭발", "독소 배출" 등. 시청자가 쓰는 말이라 인용할 때는 "흔히 ~라고 하지만"으로 받고 바로 바로잡는다.
4. **연구의 종류를 정확히 말한다.**
   - 상관 연구·설문: "~할수록 ~했습니다", "~한 사람이 ~가 많았습니다" (원인처럼 말하지 않는다).
   - 무작위 실험: "~하게 했더니 ~했습니다".
   - 작은 연구·짧은 연구는 한계를 한 문장으로 밝힌다 (예: "80명이 2주 동안 한 실험이라").
   - 대상이 다르면 밝힌다 (예: 대학생, 50세 이상, 외국 성인). 국내 자료가 있으면 국내 먼저.
5. **숫자 읽기 (내레이션 TTS):** 영문 약어·학술지 이름은 대본에서 풀어 말한다 (예: "미국 수면의학회", "영국 성인 6만여 명의 건강 자료"). 연구자 이름은 꼭 필요할 때만, 처음 나올 때 정체를 한 마디로 (공통 0-1의 10번).
6. 확인하지 못한 수치는 쓰지 않는다. 기획서·근거 자료 은행의 숫자도 쓰기 전에 다시 확인한다. 비슷한 통계 두 개를 섞지 않는다.
7. 새로 쓴 사실은 영상 README 출처 표에 링크·원문 인용·자료 연도를 남긴다.

## 4. 쓰지 않는 것

- 특정 유료 강의·클래스·앱·챌린지 서비스·책·영양제·제품·병원 이름을 권하거나 추천하는 말 (일반 기능 이름은 괜찮다: "스마트폰의 화면 시간 제한 기능", "흑백 화면 설정")
- "이것만 하면 인생이 바뀝니다", "100% 성공" 같은 보장
- 수면제·카페인·약 복용에 대한 조언, 진단처럼 들리는 말 ("당신은 중독입니다", "번아웃입니다")
- 실패를 개인의 의지 탓으로만 돌리는 말, 공포 과장 ("뇌가 망가집니다", "인생 끝")
- 우울·번아웃·불면이 의심되는 상황에서 "버티면 된다"는 말. 이런 신호가 나오면 "전문가와 상담"으로 안내한다.

## 5. 보강 시 경력 시청자(자기계발을 오래 해 본 사람)의 예상 반론과 답 (공통 0-1의 8번)

| 예상 반론 | 대본에서 미리 답하는 방식 |
|---|---|
| 나는 새벽 기상으로 인생이 바뀌었는데? | 맞는 사람도 있다고 인정한다. 차이는 **잠을 줄였는지, 일찍 잤는지**다. 7시간 이상 자면서 일찍 일어나는 건 괜찮다는 기준을 준다 |
| 66일이면 습관 된다던데? | 66일도 중간값일 뿐이다. 사람·행동에 따라 몇 주에서 1년 가까이까지 다르다 |
| 결국 의지가 약해서 그런 거 아니야? | 의지보다 **언제·어디서 할지 정한 계획**과 **환경 설정**의 효과가 연구로 더 분명하다 |
| 그 연구는 외국인(대학생)이잖아 | 한계를 먼저 인정하고, 돈·시간이 들지 않는 방법으로만 권한다. 국내 통계가 있으면 함께 보여 준다 |
| 상관관계일 뿐이잖아 | 상관 연구는 "~할수록"으로만 말하고, 원인을 말할 때는 무작위 실험 결과를 쓴다 |
| 다 끊는 게 제일 확실하지 | 잠깐 쉬는 건 괜찮다고 인정하고, **다시 돌아왔을 때의 규칙**이 없으면 제자리라는 점과 언제 해도 되는지 기준을 준다 |

## 6. 분석 결과 반영 (근거: `selfdev/guides/data_insights.md`)

1. **목표 분량은 롱폼 8~12분, 되도록 10분 이상이다** (공통 0-1의 12번).
   - SRT 추정치로 약 3,100~3,700음절 (최소 2,500음절).
   - 근거: 롱폼 8~12분 성공 2/7(29%), 8분 미만 2/12(17%), 12~20분 2/14(14%). 20~30분 4/7(57%)은 강연·다큐형이라 따르지 않는다.
   - 12분을 조금 넘는 것은 괜찮다. 문장을 늘리지 말고 항목을 더한다.
2. **1인칭 고백형 사연을 유지한다.** 다만 이 주제 성공 영상 14개 중 사연형은 0개다 (주식 근거 1인칭 고백 33% vs 21%를 따른 채널 형식). 그래서:
   - **문제 분석은 항목마다 연구·통계를 1~2개** 붙인다. 근거: 롱폼 성공 10개 중 6개가 뇌·심리 연구로 설명하는 영상.
   - 문제 분석 첫 항목이나 진행자 파트에서 **유행하는 통념 하나를 바로잡는다** (3-3). 근거: 통념 깨기 제목 롱폼 성공 3/7 vs 7/30.
3. **도입:**
   - 사연 첫 문장에 날짜(시점)·행동·숫자 중 둘 이상을 넣는다 (예: "2026년 1월 1일, 저는 새벽 5시 알람을 맞췄어요.").
   - 제목이 약속한 숫자는 **첫 문장**에 나온다. 사연 파트는 20~30초(5~7문장·읽는 음절 85~125), 첫 문장에 결과 숫자 — 공통 `guides/script_guide.md` 0-1의 13번 (사용자 지시 2026-10-12).
   - 비트 ①②에는 시청자의 지금 하루를 그대로 보여 주는 문장을 둔다 (예: "퇴근하면 녹초가 돼서 제 시간이 하나도 없었어요"). 근거: 성공 제목의 "~하는 나" 장치 (`data_insights.md` 5번).
4. 소재 선택은 `title_rules.md` 3·4번을 따른다. 자존감(롱폼 근거 없음)·번아웃(의학 상담 영역)은 지금은 단독 주제로 쓰지 않는다.
