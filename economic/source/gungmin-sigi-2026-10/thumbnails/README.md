## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「국민연금 5년 당기면 77세부터 손해, 미루면 84세부터 이득」 (34자)
- 뺀 말: '미루면 84세부터 이득' — 썸네일 2줄 안에 두 결과를 다 넣으면 글자가 작아진다. 손해 쪽(빨강)만 남기고, 이득 쪽은 제목이 말한다.
- **더한 말: '50대'** (시청자층, 피드백 13) — 제목은 폭 때문에 시청자층 낱말을 뺐다 (`titles.md`). 근거: 엄격히 나이를 밝힌 50대 댓글 285개 중 국민연금 5% (`economic/source/topic_candidates.md` '나이대별로 말하는 것'), 예시 부부 57세. '60대' 맨 앞 −3 이라 나이를 맨 앞에 두는 것은 약하지만, 흰색 짧은 말 뒤에 주제 낱말(노랑)을 붙임 (4번 1항).
- 남은 말은 제목 글자 그대로: '국민연금 5년 당기면' · '77세부터 손해'.
- 조사·뜻 점검 (피드백 21): 1줄만 봐도 '50대가 국민연금을 5년 당기면', 2줄만 봐도 '77세부터 손해' — 무엇을 날리나 묻지 않아도 되는 말. '77세부터 손해' = 77세 넘게 살면 제때 받은 쪽보다 받은 돈 합계가 적다 (대본 문장 6·31·32).
- 크기 (`video/public/fonts/NotoSansKR-900.ttf` 로 잼, 1280×720): 1줄 96px → 너비 1,036px (x 48~1,084, 가로 85%) · 2줄 112px → 약 677px (x 48~725, 가로 57% — 오른쪽 아래 구석 x 1,060 훨씬 앞).
- 사실 확인 (`calc/calc.py` v1.0): '5년 당기면' = 65세 월 130만 원 → 60세 월 91만 원(법 제63조② 1천분의 700) · '77세부터' = 합계가 같아지는 나이 76세 8개월 (연금 금액과 상관없음) · '손해' = 그 뒤로 제때 받은 쪽보다 받은 돈 합계가 적음 (80세 1,560만 원 · 90세 6,240만 원 차이).

## 6. ChatGPT로 이미지 만들기
- **기본 — 남은 재테크 썸네일 전부를 한 번에** (`guides/thumbnail_guide.md` 9번·피드백 25): main 에 올린 뒤 `python tools/make_summary.py --chatgpt-all economic` → **새 ChatGPT 대화**에, 커밋을 고정한 주소로 보낸다:
```

https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/<커밋>/economic/thumbnails_chatgpt.md
```
- 이 영상만: `python tools/make_summary.py --chatgpt economic gungmin-sigi-2026-10` → `thumbnails/chatgpt.md` 주소 (같은 꼴, 커밋 고정).
- 이 계정의 ChatGPT는 저장소에 못 쓴다 → 'Claude 대화창에 붙여 넣어 주세요'로 끝나면 그림을 **번호 순서대로** Claude 대화에 붙인다 → Claude가 검수(10번)하고 통과한 것만 `thumbnail_N.<확장자>`로 올린다.
- 한글이 틀리면 같은 대화에서: `thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.` — 두세 번 틀리면 [B]로 그림만 만들고 글자를 얹는다.
