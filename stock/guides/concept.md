## 1. 한 편의 모양

1. **가설**
   - 시청자가 묻거나 믿는 말을 그대로 가져온다.
   - 근거는 성공 사례 댓글 원문, 또는 잘된 영상 제목의 주장이다 (예: "원금 안 깎여요").
2. **어떻게 확인했나**
   - 자료(출처·기간)와 규칙(언제 사고 언제 파나)을 말한다.
   - 비용(보수·세금·환율)을 넣었는지 말한다.
   - 화면에는 AI가 짠 코드 몇 줄을 보여 준다.
3. **결과**
   - 코드가 낸 숫자와 차트로 보여 준다.
   - 여러 시작 시점의 결과를 '○번 중 △번'으로 말한다.
4. **왜 그런가**: 상품이나 시장의 구조로 설명한다. 이것이 오래가는 원칙이다.
5. **그래서 할 일**: 숫자로 차이가 보이는 구체적 행동 하나 (topic_guide 0번 4).
6. **한계**
   - 과거 자료라는 점, 빠진 비용, 자료가 짧은 상품을 말한다.
   - 개별 종목·상품 추천이 아니라는 점을 말한다.

## 2. 백테스트 규칙 — 숫자를 믿을 수 있게

| 규칙 | 내용 |
|---|---|
| 결론은 결과 뒤에 | 결과를 보기 전에 결론을 정하지 않는다. 예상과 다르면 그대로 말한다 (그것도 영상이 된다) |
| 숫자는 코드 출력만 | 대본·화면의 숫자는 모두 백테스트 코드가 낸 결과 파일에서 가져온다. 손으로 고치지 않는다 |
| 미래 정보 금지 | t 시점 결정은 t 시점까지 알 수 있는 값만 쓴다. 월말 가격으로 정하면 다음 달에 산다. 일별은 그날 종가로 신호를 정하고 **다음 거래일 종가**에 사고판다 (`daily.py`) |
| 같은 돈 | 견주는 쪽은 모두 **같은 돈**으로 시작한다 (예: $10,000 한 번, 더 넣지 않음 — 사용자 지시 2026-10-16 "투자 금액은 변동없이 동일하게"). 매달 넣는 실험이면 모두 같은 날 같은 돈을 넣는다 |
| 현금 | 주식 밖 현금의 이자를 정해 적는다 (기본 0 — 규칙에 불리하지 않게 T-bill 이자로도 한 번 더 돌려 확인) |
| 매수만 견줄 때 | 매수 규칙만 다르게, **매도 규칙은 모두 같게** — 지금(v1.4): **산 뒤 가장 높았던 종가(산 날 포함)보다 n% 낮은 종가가 나온 날 → 다음 거래일 종가에 매도** (`entry.simulate(trail=n)`, 1번 v3 n = 10% — 댓글 손절 % 중 가장 많은 값). 판 뒤 신호가 다시 나오면 다시 매수, 들고 있는 동안 새로 사지 않음. n 을 바꿔(5·15·20%) 결론이 바뀌는지 확인하고 영상에서 말한다. (예전 v1.3: 산 날에 정해지는 보유 기간 252 거래일 — `entry.simulate(hold=…)` 도 남아 있음) |
| 성공률로 견줄 때 (v1.6) | 매수 시점만 견줄 때 끝 값 대신 **성공률**: 산 값보다 **+n% 종가가 −m% 종가보다 먼저** 나오면 성공, 반대면 실패 → 그날 판정, 다음 거래일 종가에 매도 (`entry.simulate(barrier=(m, n))`). **비교 상대 = 무작위 매수 계좌 수천 개** (`entry.random_entry` — 그 신호와 같은 매도 규칙, 매도한 날 뒤 기다리는 거래일 수를 그 신호의 실제 기다림에서 뽑음 → 같은 횟수·쉬는 기간, 날짜만 무작위, 시드 고정) → 무작위 평균·90% 범위(5~95번째)·p(양쪽 = 무작위가 그만큼 벗어난 몫 × 2). 50% 와 견주지 않는다 (오르는 시장은 같은 폭이면 성공이 잦음). m·n 은 결과를 보기 전에 정한다 — 사용자가 범위를 주면 그 안에서 **자료 성질**(하루 변동 표준편차, m 이면 산 다음 날 하루 만에 정해지는 실패 몫, 판정까지 거래일)만 보고 고르고 근거 표를 남김 (`run.py choose_m`). 다른 m·다른 기간으로 범위 밖으로 나가는지 확인해 말한다 |
| 규칙 여러 개 | 흔히 쓰는 기본 값 그대로 쓴다 (예: 200일선·RSI 30/70·50/200). 결과를 보고 값을 바꾸지 않는다. 규칙을 고른 근거(댓글 낱말 수 등)를 적는다 · 사용자가 신호가 드물다고 하면 문턱을 넓히되 **신호가 나온 날·묶음 수만 보고** 정한다 (성공률을 보지 않음 — 1번 v4 RSI 40·VIX 20) |
| 총수익 | 배당·분배금을 넣는다 (수정주가 또는 가격 + 분배금). 가격만 쓰면 '가격만'이라고 말한다 |
| 비용 | 보수·매매 수수료·세금·환율을 넣었는지 하나씩 적는다. 못 넣은 것은 한계에 적는다. 매매 수수료는 그 시장 개인 투자자의 **기본(평균) 수수료**로 (미국 주식·ETF = 국내 주요 증권사 온라인 기본 약 0.25%, 2026 — 이벤트 0.03~0.09% 는 확인용으로) |
| 여러 시작 시점 | 시작 시점 하나의 결과로 결론을 내지 않는다. 굴리는 기간(예: 10년·20년)을 매달 시작해 '몇 번 중 몇 번'을 센다 |
| 생존 편향 | 지금 남아 있는 상품·종목만 쓰면 결과가 좋게 나온다 → 지수·오래된 ETF를 먼저 쓰고, 한계에 적는다 |
| 만든 자료 | 상품이 없던 기간을 만들어 쓸 때(예: 레버리지 배수)는 실제 상품 기간과 맞춰 보고 차이를 적는다 |
| 재현 | 무작위가 있으면 시드를 고정해 결과에 적는다. 자료는 받은 날짜·행 수·빠진 값과 함께 저장한다 |
| 로그 | 단계마다 `[STAGE] 시각 key=value` 를 남긴다 (자료 받기 → 지표 → 신호 → 사고팔기 → 결과) |

## 3. 파일 위치

- 영상마다: `stock/source/<영상ID>/backtest/`

  - 대본 숫자 근거는 `README.md`의 '숫자 근거'에서 이 결과를 가리킨다.

  - `monthly.py`: 총수익 지수·현금 지수·떨어지면 신호·매달 사기·떨어지면 사기·한 번에 vs 나눠서 (여러 시작 시점).

## 4. 자료 길 (2026-10-15 확인)

**클라우드에서 받아지는 것**
- GitHub raw (`raw.githubusercontent.com`)
  - 예: `datasets/s-and-p-500` — S&P500 월별 가격·배당·CPI·금리, 1871~
  - 최근 몇 달은 배당이 0으로 비어 있다 → 마지막 값으로 채우거나 그 달을 뺀다.

- **pypi 휠 (`files.pythonhosted.org`, 2026-10-16)** — 파이썬 꾸러미에 든 자료를 휠 버전·sha256 고정으로 받는다 (`data.py` v1.2 `PYPI_SOURCES`).
  - skfolio 1.9.0: S&P 500 일별 종가 1990-01-02~2022-12-28 (가격만).
  - arch 8.0.0: S&P 500·나스닥 종합 일별 1999~2018 (대조·확인용), Fama-French 월별 무위험 금리(T-bill) 1926~2018-11.
  - S&P 500 일별은 skfolio + `datasets/s-and-p-500` FRED 일별(2016-02-12~)을 이어 붙이고, 겹치는 날을 서로 대조한다. 배당은 Shiller 월 배당을 그 달 거래일에 나눠 더한다 (`daily.tr_index_daily`).

- **VIX 일별** (2026-10-16): GitHub `datasets/finance-vix` (ODC-PDDL, 원자료 CBOE) 커밋·sha256 고정 → `data.vix_daily()` 1990~2026-09-22.
- ⚠️ (Yahoo 없이) S&P 500 **일별** 은 2026-02-11 까지만 열려 있다 (그 뒤는 월평균만).
- **Yahoo Finance 차트 API (2026-10-16 사용자가 Network access 에 허용)** — `data.yahoo_daily(심볼)` (v1.4): `query1.finance.yahoo.com/v8/finance/chart/<심볼>` 일별 종가 + 배당(분할이 있는 심볼은 멈춤). 총수익은 종가 + 배당으로 우리가 계산하고 Yahoo 수정주가와 맞춰 본다. 쓴 것: SPY(1993~)·^GSPC·^VIX·^IRX(13주 T-bill). ## 5. 하지 않는 것

- 개별 종목 추천, 매수·매도 시점 예언.
- 시작 시점 하나의 극단 결과만 제목에 쓰는 것.
  - 쓸 때는 대본에서 '여러 시작 시점' 결과를 함께 말한다.
- 결과에 맞춰 규칙을 여러 번 바꿔 가장 좋은 것만 보여 주는 것 (과최적화).
  - 규칙은 가설에서 정하고, 바꾸면 바꾼 것을 말한다.
