# Gamble Mind Demo — 도박 미니게임 + 시선 엿보기 시험 데모 (Godot 4.7)

VERSION: v0.3.0 — 2026-11-26 (속임수는 노예(암살자) 측만 · 판마다 역할이 바뀜 — CHANGELOG)

> 연구·교육용 데모입니다. 실제 돈·현금화·유료 칩과 관계없습니다.
> 원작(카이지 등)의 이름·캐릭터·그림은 쓰지 않았어요. 규칙 구조만 빌려 '왕·시민·암살자'로 바꿨습니다.

## 1. 해 보기 (PC)

1. Godot 4.7 이상(표준판, .NET 아님)을 받습니다 — https://godotengine.org/download
2. Godot 를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **실행(F5)**
3. 글자가 □ 로 보이면: 프로젝트 설정 → GUI → 테마 → 사용자 지정 글꼴에 한글 글꼴(예: Noto Sans KR)을 넣습니다

### 조작
| 조작 | 뜻 |
|---|---|
| **마우스 위치 = 내 시선** | 가리키는 곳이 '보는 곳'. 시야 제한을 켜면 그 주변만 밝게 보임 |
| 카드 클릭 | 그 카드를 냄 |
| **스페이스** | 잡았다! (감시 턴에 상대가 고민할 때만) |
| Enter | 공개 뒤 다음 턴 |
| 상대 시선 보조선 | 연습용 — 상대가 어디를 보는지 점선으로 보여 줌 |

### 판마다 역할 (진영이 판마다 바뀌므로 번갈아 옴)
| 판 | 누가 먼저 | 할 일 |
|---|---|---|
| **노예(암살자) 측 판 = 속임수 판** | 상대(왕 측)가 매 턴 먼저 카드를 엎어 놓음 | 왼쪽 **잔을 1.8초 보면** 잔에 상대 카드가 비침 (보다가 떼면 진행도가 천천히 줄어듦). 단, 상대 눈이 **당신 얼굴**을 보고 있을 때 잔을 보면 금방 들킴 → 상대 눈이 딴 데를 볼 때 보세요 |
| **왕 측 판 = 감시 판** | 당신이 매 턴 먼저 냄 | 상대가 5~7초 고민하는 동안 상대 **눈**을 지켜보다가, 눈이 왼쪽 잔으로 가면 **스페이스**. 잔을 보는 중이거나 막 뗀 0.6초 안이면 적중, 아니면 헛고발 |

- 속임수는 노예 측만 (v0.3.0): 엿보기는 왕 측에 더 유리했음 — 왕 측은 한 번 보면 그 턴에 이기지만, 노예 측은 왕이 나오는 턴을 맞혀야 함
- 상대가 고개를 돌리는 0.4초 동안은 들키지 않음 → 눈이 움직이기 시작하면 바로 시선을 옮기면 됨
- 상대 눈썹이 찌푸려질수록 의심이 큰 상태 → 당신 얼굴을 더 자주 봄
- 턴이 끝나면 **리플레이**: 당신이 잔을 본 시간과 그동안 상대가 당신을 본 시간, 감시 턴엔 상대가 잔을 몇 번·몇 초 봤는지

### 규칙 한 장
- 왕 > 시민 > 암살자 > 왕, 시민끼리는 비김. 패 = 시민 4 + 특수 카드 1. 판마다 진영을 바꿈.
- 판 점수: 왕 측 승 +1 · 암살자 측 승 +4. 6판, 동점이면 연장 최대 2판(진영은 동전).
- 들키면: 경고 +1 · 벌금 1점 · 그 판 몰수(잡은 쪽 진영 점수). **경고 2개 = 즉시 패배.**
- 헛고발: 고발 토큰 −1(매치당 3개) · 벌금 1점을 상대에게.
- 먼저 내는 사람은 15초 안에 내야 함 (넘으면 남은 카드 중 아무거나).

## 2. 시험·시뮬레이션 (화면 없이)

저장소 맨 위에서 (Godot 실행 파일 이름이 `godot` 가 아니면 그 이름으로):

```bash
godot --headless --path game/gamble-demo --script res://tests/run_tests.gd
```

```bash
godot --headless --path game/gamble-demo --script res://tools/simulate.gd -- --matches=1000 --seed=42
```

- `run_tests.gd` 14묶음: 규칙표 · 공정 확률 · 엿보기·위험률 공식 · **판 진영별 턴 종류 (왕 측은 엿볼 수 없음)** · **잔 1.8초 = 카드가 비침**(나눠 보면 줄어든 만큼 더) · **상대가 얼굴을 보면 거의 들킴 / 딴 곳이면 잘 안 들킴** · 감시 턴 고발 적중·헛고발 · AI 엿보기 최선 응답 · **AI 가 숨은 카드를 몰래 읽지 않음** · 경고 2개 패배 · 시간 초과 · 연장 · 같은 시드 = 같은 매치 · 100 매치 상태 점검.
- `simulate.gd`: 자리 0 = 사람 대신 정책(상대 시선을 0.25~0.4초 늦게 보고 반응), 자리 1 = AI. 조합마다 승률 · 엿보기 시도·성공률 · 시도당 들킴 · 두 번 들켜 진 비율 · 고발 정확도.

## 3. 구조

```
core/            규칙 — 노드에 의존하지 않음 (시험·나중 서버 공용)
  rank_cards.gd    카드 규칙 · 공정 플레이 기준 확률
  cheat_rules.gd   엿보기 진행도 · 시선별 위험률 · 벌금·토큰 값
  ai_brain.gd      AI 성격 · 지켜보기/엿보기 시선 · 카드 선택 · 의심 · (시뮬레이션용 사람 정책 p0_*)
  match.gd         실시간 매치: tick(dt, 사람 시선) · commit · accuse · next · 이벤트
  game_log.gd      [STAGE] [t=…ms] key=value 로그, 수준 조절
scenes/main.gd        화면 연결 · 안내 · 기록 · 시야 제한 셰이더
scenes/table_view.gd  테이블 장면 그리기 (상대·눈동자·잔·카드) + 시선 영역
tests/run_tests.gd  tools/simulate.gd
```

튜닝: `core/cheat_rules.gd`(엿보기 시간·위험률·벌칙) · `core/ai_brain.gd`(성격 묶음·시선 시간) 값만 바꾸고 `simulate.gd` 로 확인.

### 로그 (Godot 출력 창)
`[DEAL]` → `[TURN]`(종류·누가 먼저) → `[COMMIT]` → `[AI_THINK]`(고민 시간·엿볼지·필요 시간) → `[PEEK]`(엿보기 끝) → `[NOTICE]`(상대가 알아챔: 시선·위험률·잔 본 시간) → `[ACCUSE]` → `[AI_COMMIT]` → `[REVEAL]` → `[ROUND]` → `[MATCH]`. `[GAZE]`(시선 바뀜)는 DEBUG. 거절된 행동은 `[REFUSE]`, 시간 초과는 `[TIMEOUT]`(WARNING).

## 4. AI 의 공정성 규칙
- AI 는 상대 카드를 잔 엿보기를 끝냈을 때만 압니다 (`info["opp_card"]`, 시험 `ai_ignores_hidden_card`).
- AI 가 보는 것 = 공개 정보뿐: 당신의 시선(마우스가 가리키는 곳)·판 결과.
- 같은 시드면 같은 매치 (시드는 `[MATCH] event=setup seed=…` 와 기록 첫 줄).
