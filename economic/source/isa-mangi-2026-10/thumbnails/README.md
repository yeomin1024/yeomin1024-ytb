## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「연금저축으로 안 옮기고 ISA 만기 돈 찾으면, 61세 직장인 3년에 96만 원 손해」 (47자)
- 뺀 말:
  - '찾으면' — '안 옮기면'과 뜻이 겹친다 (안 옮기고 찾는 것).
  - '61세 직장인' — 그림이 직장인을 보여 주고, 시청자층은 '50·60대'가 더 넓게 말한다.
- 바꾼 말: '연금저축으로 안 옮기고' → 1줄 끝 '연금저축으로' + 2줄 '안 옮기면'. (v1.0 은 1줄을 한글 14자 너비 안에 넣으려고 '으로'를 뺐지만, 그러면 '연금저축(을) 안 옮기면'으로도 읽혀 v1.1 에서 살렸다. 1줄이 길어진 만큼 두 줄 모두 약 78px로 줄인다.)
- **더한 말: '50·60대'** (시청자층, 피드백 13):
  - ISA 영상 댓글에서 나이를 밝힌 100개: 40대 23% · **50대 47% · 60대 22%** · 70대 이상 8% (2026-10-16 셈, 3-3).
  - 대본 예시도 61세 직장인 (은퇴 전 마지막 만기).
- 결과: '50·60대 ISA 만기 돈 연금저축으로' (14.8 글자 너비 — 78px면 1,155px, x 48~1,203) / '안 옮기면 3년에 96만 원 손해' (12.2 글자 너비 — 78px면 949px, x 48~997, 가로 80% = 1,024 앞 · 구석 칸 x 1,060 앞). 2026-10-17 `video/public/fonts/NotoSansKR-900.ttf` 로 잰 값 (v1.0 의 14.1·13.2 는 근사).
- 사실 확인 (대본 `isa-mangi-2026-10.txt` v1.0, `calc/calc.py` v1.0):
  - '3년에 96만 원' = 만기 돈 6,800만 원을 A 씨처럼 연금계좌로 안 옮기고 찾아 정기예금에 두었을 때 3년 세금 약 172만 원 − B 씨(3,000만 원을 연금계좌로, 나머지 새 ISA) 약 76만 원 = 96.1만 원 (문장 3·64~69, B 씨가 나중에 낼 세금 약 53만 원까지 넣은 숫자).
  - 이 숫자는 세금을 내는 직장인 예시다. 은퇴자(낼 세금 없음)는 73만 원 차이 (문장 71·72) — '50·60대'로 넓혀도 '손해'가 생긴다는 말은 맞지만 금액은 직장인 예시의 것이다. 제목도 같은 숫자를 쓴다.
  - 그림의 '세금' = 이 차이가 세금 차이라서 (문장 3 "3년 동안의 세금이 …").

## 5. ChatGPT로 이미지 만들기
- **기본 — 남은 재테크 썸네일 전부를 한 번에** (`guides/thumbnail_guide.md` v3.3 9번): ChatGPT 새 대화에 이것만 보낸다. 장마다 번호 + 저장 경로가 붙는다.
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 썸네일을 1번부터 차례로 모두 만들어서 장마다 적힌 저장 경로에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/thumbnails_chatgpt.md
```
- 이 영상만 만들 때는 ChatGPT 새 대화에 이것만 보낸다:
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 대로 썸네일을 만들어서 저장소에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/source/isa-mangi-2026-10/thumbnails/chatgpt.md
```
- 한 장 만들고 멈추면 `계속`이라고 보낸다.
- 이 계정의 ChatGPT는 저장소에 못 쓴다 → 'Claude 대화창에 붙여 넣어 주세요'로 끝나면 그림을 **번호 순서대로** Claude 대화에 붙인다 → Claude가 검수하고 통과한 것만 `thumbnail_N.<확장자>`로 올린다.
- 직접 올릴 때: https://github.com/yeomin1024/yeomin1024-ytb/upload/main/economic/source/isa-mangi-2026-10/thumbnails
- 한글이 틀리면 같은 대화에서: `thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.` — 두세 번 틀리면 [B]로 그림만 만들고 글자를 얹는다.
- `chatgpt.md`는 `python tools/make_summary.py --chatgpt economic isa-mangi-2026-10`이 만든다 (직접 고치지 않음).
