## 0. 목표와 출력
- **목표:** 목록에서 스쳐 지나가는 시청자가 1초 안에 "내 얘기다 + 손해 보기 싫다"를 느끼고 누르게 한다. 영상이 실제로 말하는 것만 약속한다.
- **영상 하나당 3개:** **본안 1개(클릭률 최대)** + **실험안 2개**. 공개 뒤 YouTube 스튜디오 '테스트 및 비교'로 시험한다.
- **출력** (`<주제폴더>/source/<영상ID>/thumbnails/`, 모두 저장소에 올린다):
  | 파일 | 만드는 사람 |
  |---|---|
  | `README.md` — 분석 근거, 문구를 줄인 이유, 본안·실험안 가설 | Claude |
  | `thumbnail_1~3.md` — 프롬프트 파일 (`thumbnail_1` = 본안) | Claude |
  | `chatgpt.md` — ChatGPT가 읽고 만들어 저장소에 올리는 파일 (자동 생성) | `tools/make_summary.py --chatgpt` |
  | `thumbnail_N.png`(.jpg·.webp) — 이미지 | 사용자가 ChatGPT로 만듦 → ChatGPT가 쓸 수 있으면 올림, **못 쓰면 사용자가 Claude 대화에 붙임 → Claude 검수 뒤 올림** |
- Claude는 이미지를 그리거나 코드로 렌더하지 않는다 (사용자 지시 2026-10-10).

## 3. 분석 — 디자인 근거는 그 주제 결과로만 (피드백 3)
1. **자료:** `<주제>/result/outliers/`의 승인 영상 썸네일 (성공 / 기준 밖).
   - '성공' = 180일 안·구독자 5만 이하·조회수 ≥ 구독자×3·1만·4분 (`<주제>/analysis_rules.toml`)
2. **이미지 수치 (코드):** `python3 tools/thumbnail_metrics.py <주제> --group <묶음 낱말>`
   - 밝기·채도·색 비율의 중앙값, P(성공>기준 밖), 성공 안에서 배수와의 순위상관
3. **눈으로 표시** (영상 주제와 가까운 묶음, 성공·기준 밖 모두): `codes.csv`
   - 칸: 인물(실사/진행자/그림/없음) · 60대 이상 · 걱정 표정 · 글자 위치(덩어리/아래/위/가운데) · 줄 수 · 숫자 · 금액 · 빨강 · 경고 낱말 · 비교(vs) · 물건
   - 성공 / 성공 배수 상위 / 기준 밖의 비율을 비교한다.
4. **같은 채널 짝:** 잘된 영상과 같은 채널 평소 영상 (`analysis_thumbs_pairs_*.jpg`) — 틀이 같은지, 무엇이 달랐는지.
5. **댓글 니즈 낱말:** `data_insights.md` 질문 묶음과 그 낱말을 썸네일 그림에 쓴 성공·기준 밖 사례.
6. 표본이 작으면(묶음 30개 미만, 차이 10%p 안팎) '방향'으로만 쓰고 `README.md` '한계'에 적는다. 다른 주제 결과를 빌려 쓰지 않는다 (자료가 없으면 "근거 없음" → 실험안으로만).

## 4. 문구 — 하단 2줄 (모든 시안, 피드백 2·6·7)
1. **채택 제목에서 줄일 수 있는 말을 줄여** 2줄로 쓴다. 남은 말은 제목과 글자 그대로 쓴다.
   - 뺄 말: 덧붙인 숫자(예: '월 15만 원씩'), 그림이 보여 주는 말(예: '부부')
   - **빼지 않는 말 — 시청자층 낱말 (피드백 13):** 나이대(예: '50·60대'), '노후', '은퇴'. 제목에 없어도 그 주제 시청자층에 맞게 **더한다**. '그냥 연금'이 아니라 '50·60대 노후 연금'처럼.
     - 시청자층은 `<주제>/guides/data_insights.md`의 '시청자 나이'(댓글에서 밝힌 나이)와 제목 낱말 숫자로 정한다. 재테크: 50대 21% · 60대 29% (50대 이상 73%), 제목 '노후' 맨 앞 +14, '50~70대·N세' +15.
     - 나이 하나만 맨 앞에 두면 약했다('60대' 맨 앞 −3) → '50·60대'처럼 넓게 쓰고 뒤에 '노후 연금' 같은 주제 낱말을 붙인다.
     - '어르신·노인'은 쓰지 않는다 (재테크 댓글: '노인 취급' 반발 👍45).
     - 시청자층 낱말은 흰색으로 맨 앞에, 그 뒤 중요한 것(방법)을 노랑으로.
   - 예: 「노후 연금 꺼내는 순서 모르면, 은퇴 부부 월 15만 원씩 평생 2천만 원 손해」 → **50·60대 노후 연금 꺼내는 순서 / 모르면 평생 2천만 원 손해**
2. **색:**
   - **노랑 #FFD400 = 중요한 것** (방법·핵심 낱말). 예: '노후 연금 꺼내는 순서'
   - **빨강 #FF2A2A = 나쁜 상황** (손해·위험). 예: '2천만 원 손해'
   - 나머지는 흰색이다.
   - 외곽선: 흰색·노랑은 두꺼운 검정 외곽선, 빨강은 두꺼운 흰 외곽선
3. **자리·크기:**
   - 아래쪽 약 35% 안, 아래에서 위로 옅어지는 어두운 띠 위에 왼쪽 정렬로 쓴다.
   - 한 줄은 한글 약 14자 너비 이내(숫자·가운뎃점은 반 글자, 띄어쓰기 포함 20자 이내), 나쁜 상황 줄을 조금 더 크게 한다.
   - 2번째 줄은 오른쪽 아래 구석(영상 길이 표시) 앞에서 끝낸다.
4. 숫자는 제목·대본과 같아야 한다. 대본이 계산하지 않은 금액은 쓰지 않는다.
   - 예: 대본의 '평생 2천만 원'이 세금만 센 숫자라면, 건보료와 함께 써도 되는지 `README.md`에 근거를 적는다.
5. 실험안도 문구는 본안과 **같게** 두는 것이 기본이다 (그림 차이만 시험). 문구를 시험할 때는 그림을 본안과 같게 둔다.

## 5. 그림 — 문구를 보여 주는 장면 (피드백 4·5·8·9)
1. 그림은 하단 2줄이 말하는 상황을 보여 준다. 예: 세금·건보료로 2천만 원 손해 보고 좌절한 50대.
2. **댓글 니즈 낱말**(예: 세금·건보료)은 그림이나 문구에 넣는다.
   - 그림에 넣을 때는 **낱말 그대로**, 꼬리표·판·상자 앞면의 **평면 글자**로 쓴다 (2번 '배운 것').
   - 물건(고지서·서류)으로 바꿔 그리지 않는다.
   - 그림 속 낱말은 2개 이하, 각 4자 안팎으로 하고, 사람이나 물건에 가리지 않게 한다.
3. 영상 내용 자체(예: 꺼내는 순서를 통장 순서로)를 물건으로 그리지 않는다 — 문구가 말한다.
4. 사람은 **AI가 만든 가상 인물**만 쓴다 ("Fictional person, not resembling any real or famous person").
   - 대본 사례와 나이가 다르면 `README.md`에 '시청자 대표 인물'이라고 적는다.
5. 넣지 않는 것: 실제 기업·기관 로고와 서식, 실제 화폐 도안(초상·숫자), 이모지, 따옴표 밖의 글자.
6. 사람·글자는 **가운데 16:9 안**, 위아래 가장자리 8%를 비운다 (이미지 AI가 3:2로 만들면 업로드 때 위아래가 잘린다).

## 6. 본안과 실험안 (피드백 10)
1. **본안 = 분석에서 성공과 차이가 가장 큰 특징을 모두 합친 것.**
   - 예(재테크): 걱정·좌절 표정의 실사 인물 + 빨강 손해 낱말 + 니즈 낱말 꼬리표
2. **실험안 2개 = 성공 자료에 적거나 없는 것, 또는 사용자가 시험하고 싶은 것.** 실험안마다 본안과 **한 가지만** 다르게 한다.
   - 예: 한 사람 → 부부, 사람 있음 → 없음, 꼬리표 → 은유 장면
   - '시험하는 가설'에 무엇이 다른지 한 줄로 적는다.

## 7. 규격
| 항목 | 값 |
|---|---|
| 크기 | 16:9. 업로드 도구가 가운데 기준 16:9로 잘라 1280×720·2MB 이하 JPG로 바꾼다 (.png·.jpg·.webp 모두 됨) |
| 글자 | 굵은 고딕 (Noto Sans KR Black·Pretendard Black 느낌) |
| 오른쪽 아래 | 약 220×70 비움 (영상 길이 표시) |
| 작게 보기 | 가로 320px로 줄여도 하단 2줄과 그림 속 낱말이 읽혀야 한다 |

## 8. 프롬프트 파일 형식 (`thumbnails/thumbnail_N.md`)
- `tools/make_summary.py`가 `| 시험하는 가설 |`·`## 문구`·`## [A]`·`## [B]`를 읽으므로 이 이름을 지킨다.
- **[A]에 반드시 넣는 문장** (피드백 11 — 사용자가 메시지에 따로 적지 않아도 되게):
  - `YouTube thumbnail, 16:9 landscape (1280x720), …`
  - `If 16:9 is not available, use the widest landscape canvas; in any case keep all text and faces inside the central 16:9 area, at least 8% away from the top and bottom edges.`
  - 사람이 있으면 `Fictional person, not resembling any real or famous person.`
  - 그림 속 낱말: `… printed in huge flat bold white letters on the flat front face … not carved or 3D letter shapes …`
  - `Render ONLY the Korean text given in quotes, exactly as written with the same letters and spacing, in a heavy bold sans-serif Korean font. No other text, letters, numbers, watermarks or logos anywhere.`

````markdown
# <영상ID> 썸네일 N — <본안(클릭률 최대) 또는 실험안 ①·②>: <그림 한 줄>

버전: vX.Y — <날짜> — 대본 <영상ID>.txt vX.Y 기준. <사용자 지시>

| 항목 | 값 |
|---|---|
| 역할 | 본안 / 실험안 — 본안과 무엇이 다른지 |
| 시험하는 가설 | (한 줄) |
| 짝 제목 | titles.md R1 「…」 |
| 문구 | 제목에서 뺀 말과 이유 |
| 근거 | 성공 vs 기준 밖 숫자, 닮은 성공 예 (#번호 ×배수) |
| 숫자 근거 | 대본 문장 번호·시간 |

## 화면 구성
- 위쪽 약 62%: 그림 / 아래쪽 약 35%: 하단 2줄 / 오른쪽 아래 비움

## 문구 (그대로 사용)
| 자리 | 문구 | 색 |
|---|---|---|

## [A] 완성형 프롬프트 (이미지 AI에 그대로 붙여 넣기)
```
(영문 장면 + 따옴표 안 한글 + 색 + 하단 2줄 + 위 '반드시 넣는 문장')
```

## [B] 글자 없는 프롬프트 (한글이 틀릴 때)
```
(같은 장면, 글자 자리는 비움, "Absolutely no text …")
```

## 검수
- [ ] …

## 이미지 검수 (Claude — 10번)

## 결과 (업로드 후)
| 날짜 | 테스트 및 비교 결과 (시청 시간 비율) | 메모 |
|---|---|---|
````

## 9. ChatGPT로 만들고 저장소에 올리기 (피드백 11·12·14)
1. **Claude:** 프롬프트 파일을 쓰거나 고칠 때마다 `python tools/make_summary.py --chatgpt <주제폴더> <영상ID>`로 `chatgpt.md`를 다시 만들어 함께 올린다.
   - `chatgpt.md` 내용:
     - ChatGPT가 할 일: 차례로 모두·묻지 않기·프롬프트 그대로·장마다 다른 그림·한글 획을 확대해서 문구표와 맞춰 보기
     - **저장소 올리기**: `<주제>/source/<영상ID>/thumbnails/thumbnail_N.png`로 main에 커밋. **못 쓰면** 그림을 번호 순서로 다시 보여 주고 "이 그림 N장을 Claude 대화창에 그대로 붙여 넣어 주세요. Claude가 검수한 뒤 저장소에 올립니다."로 끝냄 (+ 직접 올리는 업로드 링크 한 줄)
     - 남은 시안의 문구표와 [A]
   - 이미지가 이미 있는 시안은 자동으로 빠진다. 셋 다 있으면 `chatgpt.md`는 '만들 것 없음' 안내로 바뀐다.
2. **Claude가 사용자에게 알려 주는 메시지** (주소만 바꿈):
   ```
   이 파일을 열어 끝까지 읽고, 파일에 적힌 대로 썸네일을 만들어서 저장소에 올려 줘.
   https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/<주제폴더>/source/<영상ID>/thumbnails/chatgpt.md
   ```
   - 한 장 만들고 멈추면 `계속`이라고 보낸다.
   - ChatGPT가 저장소에 못 쓰면 그 이미지를 업로드 화면에 끌어다 놓는다: `https://github.com/yeomin1024/yeomin1024-ytb/upload/main/<주제폴더>/source/<영상ID>/thumbnails`
     - ChatGPT의 GitHub 쓰기는 계정의 ChatGPT 설정 → 앱(GitHub) 권한에 따라 다르다.
   - **기본 길 (이 계정, 2026-10-15 확인):** ChatGPT가 'Claude 대화창에 붙여 넣어 주세요'로 끝내면, 사용자가 그림을 번호 순서로 Claude 대화에 붙인다 → Claude가 검수(10번)하고 통과한 것만 `thumbnail_N.<확장자>`로 main에 올린다.
   - 저장소가 비공개면 주소가 안 열린다 → `chatgpt.md`를 대화창에 끌어다 놓게 한다.
3. 한글이 틀리면 (같은 ChatGPT 대화에서): `thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.`
   - 두세 번 해도 틀리면 [B]로 그림만 만들고, 캔바·미리캔버스에서 문구표대로 글자를 얹는다.

## 10. 검수 (Claude — 이미지가 올라오거나 대화에 붙으면)
1. 원본 크기로 보고, **그림 속 낱말과 하단 2줄을 잘라 확대**해서 한 글자씩 본다 (받침·모음 획).
2. 아래 표를 `thumbnail_N.md` '이미지 검수'에 적는다. 하나라도 ❌면 다시 만든다.

| 항목 | 기준 |
|---|---|
| 크기 | 16:9 (가로÷세로 1.77 안팎) |
| 한글 | 문구표와 한 글자도 다르지 않음 (획 빠짐·가림 없음) |
| 색 | 노랑 = 중요한 것, 빨강 = 나쁜 상황만 |
| 자리 | 하단 2줄이 아래 35% 안, 2줄째가 오른쪽 아래 구석 앞에서 끝남, 얼굴·글자가 가운데 16:9 안 |
| 인물·물건 | 가상 인물, 표정이 문구와 맞음, 실제 로고·화폐 도안 없음 |
| 320px | 줄여도 하단 2줄과 그림 속 낱말이 읽힘 |

3. 통과 → 이미지를 그대로 두거나 (대화에 붙인 것은) `thumbnail_N.<확장자>`로 저장해 올린다.
4. 실패 → 원인을 프롬프트에 반영해 버전을 올리고 `chatgpt.md`를 다시 만들어 올린 뒤, 사용자에게 같은 주소 메시지를 다시 알려 준다.
5. 새로 배운 실패 원인은 2번 '결과에서 배운 것'에 더한다.

## 11. 결과 반영
- 테스트 및 비교 결과(시청 시간 비율)는 각 `thumbnail_N.md`와 `titles.md` 결과 칸에 적는다.
- 영상 3개 이상 쌓이면 이긴 시안의 특징을 `<주제>/guides/data_insights.md` '썸네일'에 적고 다음 본안에 쓴다.
