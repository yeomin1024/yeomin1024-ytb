## 사용자 원문 (2026-11-26)

> 제목 — 관련 주제 영상에서 자주 사용한 주제 관련 단어 사용 · 자극적이고 공감되는 단어 사용, 반전을 숨겨 호기심을 유발하도록 · 관련 주제 영상에서 자주 사용하는 형식 참고
> 썸네일 이미지 — 영상 내용 중 가장 자극적인 부분을 찾아 사용하고 반전을 숨겨 호기심을 유발하도록 표현
> 썸네일 문구 — 제목과 관련이 있는 내용 또는 제목을 축약하여 자극적이고 공감되는 단어 사용, 반전을 숨겨 호기심을 유발하도록 · 관련 주제 영상에서 자주 사용하는 형식 참고
> 설명 — 알고리즘이 영상 내용을 잘 파악할 수 있도록 주제 관련 단어 사용하여 첫 2~3줄 설명과 타임라인 명확하게 작성
> 대본 내용 — 알고리즘이 파악하기 쉬운 구조로 작성 · 음성 생성 시 어색해지지 않도록 익숙한 표현으로 문장 구성

## 0. 먼저 — 관련 영상 낱말·형식 재기

```bash
python3 tools/related_titles.py <주제> "<검색어1>" "<검색어2>" … [--months 6] --out <주제>/result/related/<영상ID>.md
```
- 같은 주제 영상(검색 결과 · 롱폼 · 최근 N개월)을 조회수 무게로 세어 **자주 쓰는 낱말**(주제 낱말 · 감정·자극 낱말)과 **자주 쓰는 형식**(`~하는 사람의 심리` · `| 덧말` · `N가지` · `진짜 ~` · `~만은 아닙니다` …)을 표로. 제목·썸네일 문구·설명 첫 줄은 이 표에서 고른다 (편 폴더 `package.json` 의 `title_why` 칸에 표 이름·숫자).
- 검색 한 번 100단위 — 검색어 3~4개면 충분.

## 1. 제목

| 할 일 | 어떻게 |
|---|---|
| 주제 낱말 | 0번 표의 **주제 낱말 상위**를 2개 넘게 (예: 자꾸 주는 사람 · 심리 · 선물) — 검색·추천이 같은 주제 영상 옆에 붙이는 낱말 |
| 자극·공감 | 시청자가 겪는 장면의 말 ('필요 없다는데' · '거절해도') + 0번 표의 감정 낱말 (진짜 · 숨겨진 · 소름 …) — 과장·거짓 ✗ (대본이 증명하는 말만) |
| 반전 숨김 | 답을 말하지 않고 '예상과 다르다'만 알린다 ('~만은 아닙니다' · '진짜 이유' · '사실은') — 답(이유 목록·결론)은 제목에 ✗ |
| 형식 | 0번 표의 많이 쓰인·조회수 큰 형식을 따른다 (똑같은 제목 ✗ — 반복 콘텐츠 정책) |
| 그대로 | 60자 이하 · 모바일·PC 목록 2줄 안 (`title_fit.py`) · 조사로 뜻 분명히 · 페르소나 `title` 단계 2회차 이상 |

## 2. 썸네일 이미지

- **대본에서 가장 자극적인 장면**을 고른다 — 갈등·손해·뜻밖의 행동이 한눈에 보이는 순간 (예: 받은 반찬을 몰래 버리는 손, '그래도 가져가' 하며 떠미는 손).
- **반전·답은 그리지 않는다** — 왜 그런지(이유)·어떻게 되는지(결과)는 영상에서. 그림은 '왜?'가 생기는 장면까지.
- 이미지는 **ChatGPT 가 만든다** (Claude 는 요청 파일만 — `guides/thumbnail_guide.md`) · 글자 없음 · 화면 끝까지 · 사람 얼굴·손이 문구·말풍선에 가리지 않을 빈자리.

## 3. 썸네일 문구

| 할 일 | 어떻게 |
|---|---|
| 제목과 이어짐 | 제목을 줄인 말이나 제목과 같은 낱말 — 제목과 따로 놀지 않게 |
| 자극·공감 · 반전 숨김 | 1번과 같은 원칙 — 짧게 (주요 2줄 · 줄마다 10~14자 안팎) |
| 형식 | 0번 표 + 그 주제 성공 사례 썸네일 문구 갈래 (심리 `psychology/result/outliers/thumb_text_patterns.md` — 이유형·특징·비밀형·소름 낱말 · 보조 문구는 인물 속마음 대사) |
| 그대로 | 나쁜 상황 빨강 · 중요 노랑 · 보조 문구(말풍선)는 사람을 가리지 않음 · 페르소나 `title` 단계 |

## 4. 설명 (설명란)

- **첫 2~3줄** = 영상 내용 요약에 **주제 낱말**(제목 낱말 + 0번 표 상위 낱말 + 검색되는 넓은 낱말 — 심리는 `result/next_topic/trends.md`)을 자연스럽게. 이 줄만 읽어도 '무엇을 다루는 영상인지'가 보이게.
- **타임라인(챕터)** = 대본 챕터 이름과 같은 말 · 주제 낱말이 든 이름 · 0:00 시작 · 챕터마다 10초 넘게 · 3개 넘게 (`srt_tool.py upload` 가 실제 음성 시각으로 계산).
- 그다음 출처(설명란에만) · 알려 드립니다(짧게) · 해시태그 2개.
- **대본에서 뺀 조건·한계**(계산 조건 · 기준 지수 · 환율·세금 · 투자·진단 권유 아님 등)는 빠짐없이 설명란에 — 대본 단계에서 `research.md`(또는 `upload.md`) '설명란에 꼭' 목록으로 남긴 것을 업로드 시트 쓸 때 하나씩 지운다 (v1.1 · `script_rules.md` 10번).

## 5. 대본 내용

**5-1. 구성 — `guides/script_rules.md` (사용자 대본 피드백 2026-11-26)**: 도입 30초 안(썸네일 연결·공감·호기심 질문·다룰 내용·시청자 이득) · 결론 먼저 ✗ · 챕터 하나씩 + 끝 문장 = 다음 챕터 질문 · 직관적인 말.

**5-2. 알고리즘이 파악하기 쉬운 구조**
- 제목의 핵심 낱말을 **도입 첫 두 문장 안**에 그대로 (유튜브는 자막·음성 글도 읽음 — 자막 파일도 같이 올림).
- **챕터 이름 = 설명란 타임라인 이름** · 챕터 첫 문장에 그 챕터의 주제 낱말 (예: '첫 번째 이유는, 버리기 아까운 마음입니다').
- 주제 낱말은 대본 곳곳에서 같은 말로 (같은 뜻을 이 말 저 말로 바꾸지 않음 — '자꾸 주는 사람'이면 끝까지 그 말).

**5-3. 음성 생성이 어색하지 않은 익숙한 말** (`guides/tts_guide.md` 5-1 과 함께)
- 한 문장 = 한 생각 · 50자 안팎 · 합니다체 (인물 대사만 해요체).
- 기호를 말로: 가운뎃점 `·` ✗ → '와·과' ('캐나다·미국' → '캐나다와 미국') · 괄호 ✗ · 슬래시 ✗ · 영어 글자·줄임말 ✗.
- 따옴표 안에 따옴표 ✗ · 한 문장에 인용 하나.
- 낯선 한자어·글말보다 일상어 ('기부처' → '기부하는 곳' · '답례' 정도는 됨) · 앞에서 쓴 말과 같은 말.
- 점검: `python3 tools/script_rules_check.py <대본> --package <package.json>` (v1.1 — 5-2·5-3 도 봄).
