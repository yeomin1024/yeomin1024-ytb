## 2. 문구를 어떻게 줄였나
- 짝 제목 R1 (2026-10-17): 「은퇴 후 건보료 모르면 월 30만 원 손해｜같은 부부가 건보료 0원 내는 순서」 (43자) — 옛 「은퇴 후 건보료 모르고 그냥 두면 월 30만 원｜같은 부부가 0원 되는 순서」에서 '그냥 두면'(무엇을 안 하는지 모름)을 빼고, 금액 뒤에 '손해', '0원 되는' → '건보료 0원 내는'(좋은지 나쁜지 하나로 읽히게 — 사용자 피드백 2026-10-17, `guides/thumbnail_guide.md` v3.6 피드백 17)
- 순서를 바꿨다: 좋은 결과 '0원 내는 순서'(노랑)를 1줄에, 나쁜 상황 '월 30만 원 손해'(빨강)를 2줄에 둔다 (eunte: 1줄 방법 노랑 · 2줄 손해 빨강과 같은 꼴).
- 뺀 말:
  - '은퇴 후' — 1줄의 '50·60대'가 시청자층을 말한다. 2줄은 '모르면'(조건 경고)으로 시작한다.
  - '같은 부부가' — 그림이 부부를 보여 준다 (eunte 의 '은퇴 부부'를 뺀 것과 같은 규칙).
  - '｜' — 두 줄로 나뉘어 필요 없다.
- **더한 말: '50·60대'** (시청자층, 피드백 13):
  - 건보료 영상 댓글에서 나이를 밝힌 58개: 40대 22% · **50대 34% · 60대 34%** · 70대 9% (2026-10-16 셈, 3-3).
  - 대본 예시는 60세에 퇴직한 부부.
- 결과: '50·60대 건보료 0원 내는 순서' (띄어쓰기 포함 19자, 한글 약 14.0자 너비) / '모르면 월 30만 원 손해' (14자, 10.3자 너비 → 1줄과 같은 크기, 오른쪽 아래 구석까지 가지 않음). Noto Sans KR Black 로 잰 값. (v1.0 은 '…0원 되는 순서' 14.0 / '은퇴 후 그냥 두면 월 30만 원' 12.8)
- 사실 확인 (대본 `toejik-geonbo-2026-10.txt` v1.0.3, `calc/calc.py` v1.0):
  - '월 30만 원 손해' = 예시 부부(월급 500만 원, 집 과세표준 3억 원)가 퇴직 후 아무 신청도 안 하고 지역가입자로 둘 때 처음 13개월 한 달 303,689원 (문장 2·54·55) — 같은 부부가 피부양자면 0원(문장 3)이라 그만큼 더 낸다.
  - '건보료 0원 내는' = 같은 부부가 아들의 피부양자가 될 때 (문장 3·70).
  - '순서' = 피부양자 먼저 → 안 되면 소득 조정 뒤 지역 vs 퇴직 전 내 몫 비교 → 임의계속은 기한 안 (결론, 문장 8~10).
  - 그림의 '지역가입자' = 퇴직하면 저절로 바뀌는 가입 형태이고, 30만 원이 여기서 나온다 (문장 5 "퇴직하면 저절로 따로 내는 지역가입자가 되는데, 보험료에 끊긴 월급과 집이 잡히기 때문입니다").

```

```

```
이 파일을 열어 끝까지 읽고, 파일에 적힌 대로 썸네일을 만들어서 저장소에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/economic/source/toejik-geonbo-2026-10/thumbnails/chatgpt.md
```
- 한 장 만들고 멈추면 `계속`이라고 보낸다.
- 이 계정의 ChatGPT는 저장소에 못 쓴다 → 'Claude 대화창에 붙여 넣어 주세요'로 끝나면 그림을 **번호 순서대로** Claude 대화에 붙인다 → Claude가 검수하고 통과한 것만 `thumbnail_N.<확장자>`로 올린다.
