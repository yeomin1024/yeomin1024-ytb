## 0. 늘 지킬 것
- 결론 = 시청자가 가장 많이 원하는 정보의 답. 주제 → 결론 → 제목 → 대본이 한 줄로 이어진다. '아껴 쓰세요' 같은 상식은 결론이 아님 — **숫자로 차이를 보여 줄 수 있는 구체적 행동** (topic 0번 3·4).
- 숫자는 `calc/calc.py` 출력만. 사실은 **오늘 시행 중인 법령 원문**. 사례·연구는 2020년대 먼저, 1900년대 자료 안 씀.
- 재테크만: 경제 뉴스(금리·환율 해설) 빼기, 개별 종목·상품 추천 없음. 옛 지시사항이 아니라 분석 결과로 정한다.
- 진행자 목소리(H04) 하나로 읽음 → 1인칭 사연 대신 3인칭 예시('두 부부'). 진행자 경험을 지어내지 않음("저도 처음엔…" 금지).
- 호칭은 '여러분'·조건 부르기만 ('어르신·노인·어머님·아버님' 금지).
- 이미 만든 주제와 겹치지 않게 `economic/source/used_content.md` 를 먼저 읽는다.
- 3단계에서 영상 코드·스토리보드는 만들지 않는다. 대본이 바뀌면 SRT·확인표·README·제목(있으면)을 같이 고친다.

## 2. 시청자 니즈 세기 (댓글)
- 예시 인물 나이 = 댓글에서 가장 많은 나이대(또는 사용자가 정한 나이대). 근거 숫자가 필요하면 `data_insights.md` 1번만.
- 사례 폴더 댓글 전부를 낱말로 센다 (채널 주인 빼고 id 중복 제거, 겹치는 묶음은 합집합으로). 정규식은 엉뚱한 댓글이 섞이니 **원문을 읽고** '구체적으로 무엇을 묻는지' 한 문장으로:
  ```
  python3 - <<'EOF'
  import csv,glob,re
  seen=set();rows=[]
  for f in glob.glob('economic/result/outliers/*/comments.csv'):
      for r in csv.DictReader(open(f,encoding='utf-8-sig')):
          if r['creator']=='True' or r['id'] in seen: continue
          seen.add(r['id']); rows.append((f.split('/')[3],int(r['likes'] or 0),r['text']))
  rx=re.compile(r'국민연금.*(조기|당겨|연기)')   # ← 주제 낱말로 바꿈
  hit=[x for x in rows if rx.search(x[2])]; q=[x for x in hit if re.search(r'\?|궁금|나요|까요',x[2])]
  print(len(rows),'|',len(hit),sum(x[1] for x in hit),len({x[0] for x in hit}),'질문',len(q),sum(x[1] for x in q))
  for v,l,t in sorted(hit,key=lambda x:-x[1])[:20]: print(l,v,t[:150])
  EOF
  ```
- 원문은 작성자 이름 없이 README 에 근거로만 적고 대본에 옮기지 않는다. 같은 주제 성공 사례(analysis.md 1번) 1~2개의 대본(`W_<ID>/transcript.json`)은 처음부터 읽되 구성만 참고, 문장은 옮기지 않는다 ('많이 쓰인다' ≠ '잘됐다' — 필요하면 `content_research.py style|feedback economic`).

## 3. 법령 원문 확인
```
python3 tools/law_text.py 국민연금법 --source mirror --out /tmp/law --article 제62조
python3 tools/law_text.py "국민건강보험법 시행규칙" --source mirror --out /tmp/law --grep "2천만원"
```
- 이 클라우드는 law.go.kr 이 막힘 → `--source mirror` (GitHub legalize-kr 개정 이력에서 오늘 시행 중인 판). 판마다 [시행일] [법률 번호] · legalize-kr 커밋 · 시행 전 새 판이 있으면 바뀐 조문이 대본과 상관있는지 적는다.
- 시행령·시행규칙·부칙(개정 예정 시행일)까지. 조문 실제 문장을 확인표에 짧게.
- 별표(PDF — 예: 피부양자 기준 별표 1의2)는 mirror 에 없음 → 같은 채널 영상 확인표가 law.go.kr 원문으로 확인한 줄을 그대로 쓰고 출처를 밝힌다 (그 확인표의 A표 해당 줄만 읽음).
- 운영(법에 없는 관행)은 올해 공식 발표·보도로, 날짜를 적고 작년 것은 '작년'. 공단·국세청 챗봇·전화 답은 사용자가 확인해 준 것만. nps·nhis·nts 누리집은 막힘 → ⚠️ 와 C표.
- 후보 표의 결론 후보가 법과 다르면 법대로 고치고 README '바로잡은 것'에 적고 사용자에게 알린다 (숨기지 않음).

## 4. 계산 `calc/calc.py`
- 머리 docstring 꼴 (본보기 그대로):
  ```
  """VERSION: v1.0 — <날짜> — 최초 작성. 대본 <영상ID>.txt v1.0 의 숫자를 모두 낸다.
  <무엇과 무엇을 비교 (단위)>
  근거 (legalize-kr <날짜> 시행 판 — law_text.py --source mirror): - <법령> [시행 …] [법률 제…호] (<커밋>) 제N조①(요지)
  가정 (계산용 예시 — README 3번과 같음): - …
  실행: python3 calc.py  /  python3 calc.py -v (민감도)   로그: [STAGE] 시각 key=value (stderr). 연구·교육용.
  """
  VERSION = "v1.0"
  LOG = logging.getLogger("<짧은이름>_calc")
  RATE = 0.006   # 제도 값마다 주석에 조문
  def log(stage, **kv):
      LOG.info("[%s] %s %s", stage, time.strftime("%Y-%m-%dT%H:%M:%S"), " ".join(f"{k}={v}" for k, v in kv.items()))
  def main(verbose=False):
      logging.basicConfig(level=logging.INFO, stream=sys.stderr, format="%(message)s")
      log("START", version=VERSION) ...   # 표는 stdout '## N. …' 절로, 끝에 log("END")
  ```
- 점검: ① 세법·제도의 **상호작용**(예: 배우자 공제를 잃음) ② 끝나는 조건 ③ 모르는 가정은 **민감도**(S1·S2…)로 돌려 결론이 그대로인지 → 대본 숫자는 안전한 쪽으로 반올림('약 2천만 원') ④ **실제로 낸 돈과 미래 세금을 구분**하고 어느 쪽인지 적음 ⑤ **중간에 고치면** 얼마인지도 계산 ⑥ 사람마다 크게 다른 것(건보료 재산 몫 등)은 넣지 않고 '넣지 않았다'고 말함.

## 5. 대본 `<영상ID>.txt`
- 한 줄 한 문장, 작성용 메모 없음. 챕터 = 파트 라벨 `-이름` 한 줄 (챕터 사이 빈 줄 됨). **라벨을 숫자로 시작하지 않는다**('-57세 …'는 srt_tool 이 음수 금액 문장으로 셈 → '-동갑 부부, 57세의 …'). 라벨에 '사연' 금지(사연자 목소리가 됨).
- 챕터 9개 순서 (본보기 라벨):
  1. `-같은 X, 다른 Y` 도입 약 50초: 대상 부르기 "~라면, 이 숫자부터 보세요." → 15초 안 비교 숫자 → 질문("왜 이렇게 차이가 날까요?") → 원인 한 줄 → 손해 숫자와 뜻 → "결론부터 말씀드리겠습니다." → 결론 세 가지 → "이 세 가지입니다." → '끝까지' 약속("…할 일도 끝까지 보여드릴게요.") → 전환 "먼저 두 부부의 경우를 통해 알아보겠습니다." (인사·구독 요청 없음 · '숫자는 <연>년 <월>월 기준입니다' 문장은 넣지 않음 — 기준 날짜는 설명란)
  2. `-두 부부의 조건` 예시 인물: 나이·연금·재산·생활비·가정(금리·물가)을 숫자로, 두 방법 한 문장씩, **어떻게 냈는지**("국민연금법의 비율로 계산했고, 금액은 모두 지금 돈 가치입니다.") → "…세 가지 원칙으로 정할 수 있습니다." "하나씩 보겠습니다."
  3~5. `-원칙 하나, …`·`-원칙 둘, …`·`-원칙 셋, …`: "첫 번째 원칙은, ~라는 것입니다." → 기준(이름+금액) → 어려우면 "예를 들어 …" 한 문장 → 예시 인물 숫자 → 쉬운 비유 하나 → "한마디로, ~." (원칙 사이 전환 멘트 없음, 셋째 끝에 "그럼 이 세 가지 원칙으로 …를 정해 보겠습니다.")
  6. `-할 일, A → B → C`: 1단계·2단계·3단계, 단계마다 나이·금액·이유 → "그럼 …의 결과는 얼마나 달라질까요?"
  7. `-두 부부의 결과`: A·B 숫자 + 나온 이유 + 넣고 뺀 것("세금과 건보료는 넣지 않은 숫자입니다.") → "그런데 이미 ~하신 분들도 계실 텐데요." "그럼 어떻게 해야 할까요?"
  8. `-이미 ~했다면`: 되돌릴 수 있는 것(기한)·없는 것, 지금 고칠 것, 고치면 줄어드는 숫자, 늦을수록 덜 준다는 것 → "자, 마지막으로 오늘 내용을 정리하겠습니다."
  9. `-정리, 바뀌어도 그대로인 것`: 바뀔 수 있는 것 한 문장 → "그래도 이 세 가지는 그대로입니다." → 첫째·둘째·셋째 → 오늘 할 일 하나("오늘 …부터 확인해 보세요.") → **"시청해주셔서 감사합니다."** (마지막 문장, 다른 끝인사 안 씀)
- 문장 규칙 (script_guide 0번 피드백 — **대본 전체에** 적용하고, 고친 뒤 처음부터 다시 읽는다 — 18):
  - 결론은 첫 40초 안, 대본 전체가 그 결론을 증명하는 순서 (1). 중심은 오래가는 원칙, 바뀔 수 있는 것은 정리에서 한 번 "바뀔 수 있다" (4).
  - 큰 숫자마다 **무엇을 얼마 동안 계속하면** 나오는지 (6). 계산된 숫자에 근거 낱말 — 기간·곱셈·무엇과 무엇을 더했는지("1년치 국민연금 ~만 원을 더하면") (16).
  - '기준'마다 이름+금액('피부양자 기준 2,000만 원') (17). 어려운 규칙 바로 뒤 예시 한 문장 (14).
  - 한 문장 하나의 뜻, 50자 넘으면 나눔. 어려운 말은 풀기('감면' → '깎아 주는' · 약어는 처음에 '개인형 퇴직연금인 IRP'). 강조 말('이게 중요합니다')은 핵심에만 (12).
  - 조사를 빼지 않음 ("두 부부, 세금이" → "두 부부가 있습니다. 그런데 세금이" · "108만 원." → "108만 원입니다.") (13).
  - 어색한 말 금지: '몰지 않는다'→'나눠서 꺼낸다' · '세 줄'·'세 개'→'세 가지' · '한 분'→'한 사람' · '선'→'기준' · '미뤄진다'→'꺼낼 때 세금을 낸다' · 비유를 끌고 가는 말('녹긴 합니다') · '맨 뒤예요'→'맨 나중입니다' (8). 정보 없는 감상 문장("제도가 좀 불친절합니다") 금지 (15).
  - 전화번호·누리집은 읽지 않음(설명란·README 로) (11).
  - **애매한 말 금지** (19): 행동이 없는 말('그냥 두면'·'그냥 찾으면'·'이대로 가면'·'같은 방법을 하면'·'그렇게 하면'·'알아서') → 실제 행동('퇴직 후 아무 신청도 안 하면') · 바로 앞에 없는 '그 돈'·'이 금액'·'그 기준' → 이름 · 전문 용어는 처음 나올 때 쉬운 말로 · 조사를 빼 두 가지로 읽히는 압축 말 금지.
  - **짧게 + 좋은지 나쁜지** (20): 고쳐도 문장 길이는 거의 그대로(설명 덧붙이지 않음, 음절이 늘지 않게) · 다 아는 말(공시가격·국민연금·건보료·예금·피부양자)은 풀지 않음 · 금액·결과 뒤에 뜻 낱말(손해·더 냄·덜 냄·받음·못 받음·아낌·0원 냄).
  - **왜·어떻게는 빼지 않음** (21): 결과 전에 ① 왜 보는지 ② 어떻게 알아냈는지(어떤 법·계산) ③ 무엇과 왜 비교했는지 ④ 공정하게 맞춘 조건을 한 문장씩 — 20 은 다듬어서 지키고 빼서 지키지 않는다. 끝 안내 말도 자연스럽게.
  - 마지막에 직접 '아무것도 모르는 50~70대 시청자'가 되어 문장마다 '무엇을 한다는 거지? 왜? 어떻게?'가 남는지 읽는다.
## 5-1. 사연형 구성 (2026-10-19 — 이 꼴이면 위 9챕터 순서 대신 이것)
- **도입 25초 이내** (읽는 음절 약 120): 사연 주인공의 말(= 제목의 말) → 누구의 말인지 한 문장 → 걸린 금액 → 반전으로 결론 방향 예고("그런데 다시 계산해 보면, …가 아니었습니다") → '끝까지' 약속. 인사·구독 요청 없음.
- **챕터 4~6개:** 라벨 = 그 챕터의 궁금증(숫자로 시작하지 않음). 챕터마다 사연 한 걸음 + 제도 하나 + calc 숫자. **챕터 끝 문장 = 다음 챕터의 궁금증**(질문 또는 "그런데 …") → 다음 챕터 첫 문장이 바로 답. 반전은 가운데에 하나 이상('범인 아님' → '진짜 까닭').
- **결론 및 마무리 아주 짧게** (20~30초 — 화면이 정리): 반전 한 문장 → 제목의 당부("…꼭 보세요") → 세 가지 한 문장씩 → "시청해주셔서 감사합니다." 바뀔 수 있는 것은 본문에서 한 번.
- **사연은 각색해도 됨:** 기사·댓글은 참고만, 지금 시행 중인 법에 맞게 나이·금액을 바꾼 가상 인물(3인칭 '김 씨'). 숫자는 calc, 진행자는 3인칭, 설명란에 '기사 사례를 바탕으로 각색한 가상 사례'. 지어낸 마음(이득인 줄 알았는데 등)으로 사실을 바꾸지 않는다.
- 나머지 문장 규칙(피드백 1~21)·측정·검사는 그대로.

- 사연(1인칭) 파트는 넣지 않는 것이 기본. 넣으면 20~30초(5~7문장·읽는 음절 85~125), 첫 문장에 결과 숫자, 진행자는 0:30 전에.
- 사용자가 ChatGPT 시청자 검토 결과(`economic/guides/viewer_review.md`)를 붙이면 피드백 19·20 으로 그 자리 낱말만 고치고, 숫자·법은 따로 확인한다.
