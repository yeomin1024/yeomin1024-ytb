# 사연을 통한 교훈 — 데이터 근거 (임시)

버전: v0.1 — 2026-10-10 — 분석기를 아직 돌리지 않아 **YouTube 자동완성**으로 확인한 검색 수요만 적는다. `python youtube_topic_analyzer.py --config story/analyzer_config.toml` 실행 뒤 주식과 같은 형식으로 바꾼다.

## 1. 자동완성으로 본 수요 (2026-10-09 조회, 쿼터 0)
| 씨앗 검색어 | 자동완성 (일부) | 해석 |
|---|---|---|
| 사연 | 사연튜브, 사연극장, 사연툰, 사연 낭독, 사연라디오 | 채널 이름·포맷 중심 → 단독 검색어로 쓰지 않음 |
| 시어머니 사연 / 며느리 사연 | 사이다, 갈등, 오디오북, 실제 사연, 시니어 | 가족 갈등 + 시니어 청취층 |
| 돈 빌려주고 | 못받을때, 이자, 빌려주기 | "못 받을 때 어떻게" — 문제→방법 구조와 맞음 |
| 떼인 돈 | 받기, 받아드립니다(코미디) | 해결 방법 수요. 코미디 영상이 섞임 |
| 인간관계 정리 | 시기, 방법, 신호, 법칙 | 교훈형 수요 |
| 죽기 전에 후회하는 것 / 나이들면 후회하는 것들 | 80세가 되고 후회하는 것들 등 | 시니어 교훈형 |
| 친구 배신 | 썰, 배신감, 드라마 | 관계 사연 |

## 2. 아직 모르는 것 (분석 후 채움)
- AI 음성·대량 생산 채널의 비중과 성과 (YouTube 수익 정책 위험)
- 1인칭 고백형 vs 낭독형(제3자) 성과 차이, 분량, 썸네일 형태
