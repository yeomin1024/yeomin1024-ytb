# 자기계발 — 썸네일 전용 규칙

버전: v1.0 — 2026-10-11 — 최초 작성 (썸네일 분석은 주식 결과 임시 사용 — `data_insights.md` 6번)

공통 규칙 `guides/thumbnail_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

## 1. 색과 숫자 표기

- **잃은 것·나빠짐·경고 = 빨강 #E63B2E**, **되찾은 것·좋아짐 = 파랑 #2D6CDF** (건강 주제와 같은 뜻. 주식과 반대 — 이 주제에서는 이 뜻으로 고정)
  - 예: "잠 -200시간"은 빨강, "7시간 수면"은 파랑
  - 네이비 배경에서 파랑 글자는 잘 안 보인다. 이때는 파랑 박스 위에 흰 글자로 쓴다.
- 노랑 #FFD400 = 강조 한 곳 (예: "21일" 글자, 알람 시각)
- 숫자는 영상 카드와 같은 표기: `하루 2시간`, `잠 -200시간`, `21일 → 0일`, `스크린타임 9시간`, `05:00`
  - 제목의 "200시간"과 값이 같아야 한다 (공통 1번).
- 썸네일 숫자는 시간·일수·스크린타임이 기본이다. 몸 수치(체중·혈당)는 쓰지 않는다.

## 2. 기본 시안 순서 (공통 4번 축을 자기계발에 맞춘 것)

| 시안 | 축 | 자기계발에서 만드는 법 | 근거 |
|---|---|---|---|
| thumbnail_1 | 숫자 반전 | **기록 카드**: 얻으려던 숫자 → 잃은 숫자 (예: 알람 `05:00` + "하루 +2시간" → "잠 -200시간", 달력 동그라미 21개 → "0일") | 주식 성공 썸네일의 숫자 반전형(임시 근거) |
| thumbnail_2 | 인물·감정 장면 | 문제 행동의 결과를 마주한 가상 인물(30대 직장인)의 표정 + 핵심 숫자 하나 (새벽 책상에서 꾸벅 조는 모습, 새벽 3시에 숏폼을 보는 얼굴에 비친 화면 빛) | 주식 성공 썸네일 24개 중 약 20개가 감정이 드러난 얼굴(임시 근거) |
| thumbnail_3 | 대비 | 왼쪽 = 기대(인증 사진·동그라미·"리셋") / 오른쪽 = 결과(오후에 무너진 나·빈 달력·스크린타임) | 문제 분석 첫 번째 메시지를 한눈에 |

## 3. 소품과 화면 그리기

- 쓸 수 있는 소품: 알람 시계(숫자 시계 `05:00`), 종이 달력과 동그라미, 운동 매트, 커피잔, 책, 휴대폰(앱 이름·로고 없는 **단순한 화면**: 막대그래프와 시간 숫자만), 서랍에 넣은 휴대폰
- **실제 앱·서비스처럼 보이지 않게** 한다.
  - 스마트폰 운영체제의 실제 "스크린타임" 화면, 숏폼 앱(유튜브 쇼츠·인스타그램 릴스·틱톡)의 로고·레이아웃·아이콘을 따라 그리지 않는다.
  - 챌린지·인증 앱, 강의 플랫폼, 책 표지(예: 자기계발 베스트셀러)를 그리지 않는다.
- 뇌 그림은 쓰지 않는다 (녹는 뇌, 불타는 뇌, 도파민 분자 같은 유사과학 연상 이미지 금지). 연구 숫자로만 말한다.

## 4. 인물

- AI가 만든 **가상 인물만** 쓴다. 실존 인물·유명 자기계발 유튜버·작가·강사를 닮게 하지 않는다.
- 사연자에 맞춘다: **30대 한국인 여성 직장인** (사연자 목소리와 같음). 사연에 없는 설정(아이·결혼 등)은 넣지 않는다.
- 표정은 피곤·허탈·후회·당황까지만. 우는 얼굴 클로즈업, 쓰러진 모습, 병원·약·주사 장면, 극단적 불안 연출은 쓰지 않는다.
- 흰 가운을 입은 의사·상담사 인물은 쓰지 않는다 (진단·처방처럼 보이는 연출 금지).

## 5. 문구 톤

- 2줄 이하, 20자 이내. 숫자 하나를 가장 크게.
- 시청자 말투, 짧게: "잠 -200시간", "21일 → 0일", "월요일 9시간", "리셋은 없었다"
- 쓰지 않는 문구: "인생 바뀜", "100%", "이것만", "뇌 녹음", "중독자", 앱·서비스·제품 이름, 이모지
