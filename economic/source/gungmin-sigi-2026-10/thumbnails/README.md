## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「은퇴 후 국민연금 신청 한 번에 평생 손해봤어요. 꼭 보세요」 (33자)
- 뺀 말: 당부 '꼭 보세요' — 썸네일 2줄에는 사연(손해)만. 당부는 제목이 말한다.
- 남은 말은 제목 글자 그대로: '은퇴 후 국민연금 신청 한 번에' · '평생 손해봤어요' ('손해봤어요'는 사용자 표기대로 붙여 씀). 시청자층 '은퇴 후'가 이미 맨 앞이라 더한 말 없음.
- 조사·뜻 점검 (피드백 21): 1줄만 봐도 '은퇴 뒤 국민연금을 한 번 신청했더니', 2줄만 봐도 '평생 손해를 봤다' — '무엇을 날리나'를 묻지 않아도 되는 말.
- 크기 (`video/public/fonts/NotoSansKR-900.ttf` 로 잼, 1280×720): 1줄 88px → 너비 1,072px (x 48~1,120, 가로 88%) · 2줄 120px → 800px (x 48~848, 가로 66% — 80% = 1,024 앞).
- 사실 확인 (`calc/calc.py` v1.1.1 8번 절): '평생' = 5년 당긴 30% 감액이 평생 (국민연금법 제61조②·제63조②) · '30% 깎임' = 1년 6% × 5년 · 손해인지는 받기 시작하고 16년 8개월(김 씨 75세 8개월)에 갈림 — 영상이 따져 봄.

## 6. ChatGPT로 이미지 만들기
- **기본 — 남은 재테크 썸네일 전부를 한 번에** (`guides/thumbnail_guide.md` 9번·피드백 25): main 에 올린 뒤 `python tools/make_summary.py --chatgpt-all economic` → **새 ChatGPT 대화**에, 커밋을 고정한 주소로 보낸다:
```
이 파일을 열어 끝까지 읽고, 파일에 적힌 썸네일을 1번부터 차례로 모두 만들어서 장마다 적힌 저장 경로에 올려 줘.
https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/<커밋>/economic/thumbnails_chatgpt.md
```
- 이 영상만: `python tools/make_summary.py --chatgpt economic gungmin-sigi-2026-10` → `thumbnails/chatgpt.md` 주소 (같은 꼴, 커밋 고정).
- 이 계정의 ChatGPT는 저장소에 못 쓴다 → 'Claude 대화창에 붙여 넣어 주세요'로 끝나면 그림을 **번호 순서대로** Claude 대화에 붙인다 → Claude가 검수(10번)하고 통과한 것만 `thumbnail_N.<확장자>`로 올린다.
- 한글이 틀리면 같은 대화에서: `thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로.` — 두세 번 틀리면 [B]로 그림만 만들고 글자를 얹는다.
