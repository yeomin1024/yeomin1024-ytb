## 4. 문구를 어떻게 줄였나
- 첫 문장 (0:00): 「이씨는 ISA 만기 돈을 받고 3년 동안 세금을 96만 원 더 낸다는 걸 알게 됐습니다.」
- 짝 제목 R1 (`../shorts.md` 1번): 「3년 세금 172만 원 이씨가 들은 말… 같은 ISA인데 76만」
- 뺀 말:
  - '이씨는' — 그림이 사람을 보여 준다. 이름은 제목이 말한다.
  - '세금을' — **그림 속 낱말** '세금'으로 옮겼다 (휴대폰에서 떠오르는 꼬리표 — 동료가 계산해 보여 준 '3년 세금', 쇼츠 문장 6·7).
  - '받고' · '낸다는 걸 알게 됐습니다' — 그림이 보여 준다.
  - 제목의 '172만 원'·'76만' — 2줄에 숫자가 셋 넘으면 작은 선반에서 읽히지 않는다. 제목과 문장 7이 말한다.
- 더한 말: **'61세'** — 시청자층 낱말 (지시사항 피드백 13). 숫자는 쇼츠 대본에 있는 것만 쓰므로 롱폼 썸네일의 '50·60대' 대신 대본의 나이 (쇼츠 문장 3 '둘 다 61세').
  - ⚠️ 지시사항 4번 1항: 롱폼 제목에서 나이 하나만 맨 앞에 두면 약했다('60대' 맨 앞 −3). ISA 댓글 나이는 50대가 가장 많다(47%). 여기서는 나이가 '이 이야기의 사람'이라 그대로 두었다 — 근거 없음.
- 남은 말은 첫 문장과 글자가 같다: 'ISA 만기 돈' · '3년 동안' · '96만 원 더'.
- 길이 (Noto Sans KR Black 근사 — 한글 1, 숫자 0.6, 라틴 대문자 약 0.6, 띄어쓰기 0.3 글자 너비): 1줄 7.9 · 2줄 9.0 → 1줄 약 84px · 2줄 약 88px (2줄 너비 약 792px, x 76~868).
- 사실 확인 (`../shorts.md` 6번):
  - '96만 원 더' = 3년 세금 이씨(A) 약 171.7만 − 동료(B) 약 75.5만 = 96.1만 원 (롱폼 README 4번, 대본 문장 6·69). 동료 쪽 숫자에는 나중에 낼 세금 약 53만 원까지 들어 있다 (문장 68).
  - '3년 동안' = 롱폼 '3년 뒤 다음 만기까지 따져 보면'(문장 64) — 만기 때 앞으로 3년을 계산으로 본 숫자라 '더 낸다'.
  - '61세' = 롱폼 대본 문장 13 · 쇼츠 문장 3.
  - 'ISA 만기 돈' = 쇼츠 문장 1 · 5 (이번 달 만기에 받은 돈 6,800만 원).

## 5. 그림·색
- 장면 = 각색한 경위(쇼츠 문장 2·6·7 — 회사 점심시간, 동갑 동료가 두 사람의 3년 세금을 계산해 휴대폰으로 보여 줌)의 순간.
- 동료는 **팔과 손만** 그린다 (휴대폰을 왼쪽에서 내밂) — 얼굴이 둘이면 작은 화면에서 읽히지 않고, 오른쪽 16% 를 비워야 해서.
- 휴대폰 화면은 이씨 쪽을 향한다 (시청자에게는 빛만) — 실제 은행·앱 화면·글자를 그리지 않기 위해 (쇼츠 장면 계획 4번 '이름 없는 계산 화면').
- '세금' 꼬리표: 빨강 둥근 사각형 + 흰 평면 글자, 휴대폰에서 떠오름 (옅은 점선 꼬리). 손해를 만드는 것이라 빨강 (롱폼과 같은 뜻), 화살표 없음.
- 인물: 쇼츠의 이씨는 61세 직장인, 65세까지 일할 생각 (쇼츠 문장 3). 사용자 지시 '되도록 젊게' → **50대 중반처럼**. 사원증·회사 이름·로고 없음.
- 색: 노랑 #FFD400 = 'ISA 만기 돈' (중요한 것) · 빨강 #FF2A2A = '3년 동안 96만 원 더'·'세금' (나쁜 상황) · 흰색 = '61세' · 위·아래 바탕 = 짙은 남색 (#0C1424 근처, 다음 장면과 이어지게).
