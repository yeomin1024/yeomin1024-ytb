# 재테크 쇼츠 지시사항 — 근거 (economic)

버전: v1.0.1 — 2026-10-16 — 1-1에 메모: 사용자 지시로 쇼츠는 프롤로그형(답은 롱폼에 둠) — 이 근거와 반대 방향이라 올린 뒤 8번 숫자로 확인. (v1.0 — 2026-10-15 — 새로 만듦 (사용자 지시: "쇼츠 분석 결과보고 어떤 쇼츠를 만들어야 시청자를 끌어모아서 노후 영상 4개에 자연스럽게 유입될 수 있을지 제목, 대본 만들어봐 각 영상 당 쇼츠 1개 씩이야"))

근거는 **이 주제의 쇼츠 분석 결과 하나**: [`economic/result/outliers/shorts/`](../result/outliers/shorts/) (받은 쇼츠 154개 · 쇼츠 탐색에서 본 영상 6,159개). 롱폼 결과는 빌리지 않는다 (`guides/shorts_guide.md` 3번, CLAUDE.md).
※ 연구·교육용 — 투자·세무 권유가 아님.

**다시 센 숫자다.** GitHub 의 `analysis.md` 는 `shorts_analysis.py v1.0`(2026-10-15T08:59 UTC) 결과라 **돈 이야기가 아닌 쇼츠(연예 클립·운세·명언·정치·'노후차' 같은 다른 뜻)가 섞여 있다** — 예: 「[리센느] 노후 준비 끝난 걸그룹」 938만 회가 '노후·연금' 성공 쇼츠였음. 그래서 이 파일의 숫자는 `compare.csv`(6,159줄)에 지금 규칙(`analysis_rules.toml` v1.6 `[shorts_exclude]` — `shorts_analysis.off_kind`)을 덧대 **다시 셌다** → 쇼츠 237개를 더 뺌(명언·인생조언 126 · 연예·예능·드라마 62 · 운세·사주 36 · 정치 8 · 다른 뜻 5), 비교 집단 574개(성공 17.1%) → **520개(성공 12.9%)**.
- 근사인 곳: `compare.csv` 에는 설명이 없어 받은 쇼츠 154개 말고는 제목·채널 이름으로만 걸렀다 / 뺀 자리에 같은 채널의 다른 쇼츠가 들어가는 것은 채널 이름으로 맞췄다(코드는 채널 ID) / 시장(1번)은 '쇼츠 검색으로 찾은 것' 대신 '채널 쇼츠 목록이 아닌 것'으로 셌다. PC 에서 쇼츠 분석을 다시 돌리면(`.cache/shorts` 가 PC 에만 있음) 이 파일 숫자를 새 `analysis.md` 로 바꾼다
- '(n=…)'은 그 숫자를 센 쇼츠 수. 15개 미만이면 **표본 적음**, '⚑'는 차이 10%p 이상·양쪽 15개 이상(눈에 띔 — 원인은 아님)

## 0. 먼저 알아 둘 한계

- 대본(자막)이 있는 성공 쇼츠는 **9개뿐**(16개 중 7개가 연예·영화 클립이라 빠짐). 첫 3초·말 속도·끝맺음 숫자는 이 9개로만 센 약한 근거다
- 같은 채널 안 비교(analysis.md 1-2번)는 v1.0 숫자뿐이라 쓰지 않았다. 아래 제목·길이 규칙은 비교 집단(조회수 순 검색 — 잘된 쪽으로 치우침)의 차이라 강한 규칙이 아니라 '고를 때의 기울기'다
- 쇼츠의 핵심 신호(피드에서 넘긴 비율·시청 비율·다시 재생)는 API 로 볼 수 없다. 우리 쇼츠를 올린 뒤 스튜디오 숫자를 이 파일에 더한다 (8번)
- 15초 미만 쇼츠는 조회수 부풀림 의심(광고·반복 재생)이 많아 근거로 쓰지 않는다

→ 롱폼이 공개된 뒤, 쇼츠는 **화~목 12~14시**에 하나씩 (네 편을 한꺼번에 올리지 않음 — 이건 근거가 아니라 겹치지 않게 하려는 것).

## 7. 롱폼으로 보내는 장치 (YouTube 기능 — 분석 숫자가 아님)

1. **관련 동영상**: 쇼츠를 올릴 때(스튜디오·앱의 쇼츠 편집) '관련 동영상'에 그 롱폼을 고른다 → 쇼츠 화면 아래에 누를 수 있는 롱폼 링크가 생긴다. 쇼츠 설명란·댓글의 주소는 눌리지 않는다 (YouTube 2023-08 변경)
2. 대본 끝 문장과 마지막 화면 글자가 그 링크를 가리킨다 ("아래 영상")
3. 설명란 첫 줄 = 쇼츠의 결론 한 줄 + "전체 영상: 관련 동영상 링크"
4. 롱폼이 공개되어 있어야 연결할 수 있다 → **롱폼 공개 뒤** 쇼츠를 올린다

## 8. 근거 없음 — 올린 뒤 채울 것

| 무엇 | 어디서 |
|---|---|
| 쇼츠를 본 사람이 롱폼으로 넘어간 수 | 스튜디오 → 쇼츠 → 분석 → '관련 동영상' 클릭 수, 롱폼 → 트래픽 소스 'Shorts 피드' |
| 피드에서 본 비율 vs 넘긴 비율 · 평균 시청 비율 | 스튜디오 → 쇼츠 → 분석 → 참여도 |
| 화면 글자 크기·색·음악의 효과 | 영상을 받지 않으므로 분석 불가 — 우리 쇼츠 네 편의 위 숫자를 서로 비교 |
| 끝 문장 롱폼 안내의 효과 | 위 '관련 동영상' 클릭 수 (안내를 넣은 편·안 넣은 편을 나중에 비교) |
| 해시태그 하나하나의 효과 (#IRP·#ISA·#건보료 등) | 표본 없음 — 네 편 비교 |
