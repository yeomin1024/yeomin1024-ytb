# 주식 — 썸네일 전용 규칙

버전: v1.3 — 2026-10-12 — data_insights v2.0 반영: 근거를 작은 채널 성공 썸네일 15개 직접 확인 결과로 교체 (규칙은 그대로) (v1.2 — 2026-10-11 — 사용자 지시: 모든 시안 아래쪽 제목 문구 2줄, thumbnail_3 = 검은 배경 제목형; v1.1 — 2026-10-09 — 사용자 지시: 필요하면 인물 사용, 이미지 AI 프롬프트 중심 (v1.0: 최초 작성, 분석 결과 반영))

공통 규칙 `guides/thumbnail_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

## 1. 색과 숫자 표기

- 수익·상승 = 빨강 #E63B2E, 손실·하락 = 파랑 #2D6CDF (국내 증권 앱 관례, 영상과 같음)
  - 손실 숫자를 빨강으로 쓰지 않는다. 다른 채널은 빨강을 위험 표시로 많이 쓰지만, 이 채널은 영상 전체에서 파랑=손실로 고정한다.
  - 근거 (data_insights v2.0 2-6·3-5): 작은 채널 성공 썸네일 15개 중 손실 숫자가 있는 7개의 색은 파랑 계열 4개(모두 실제 계좌 화면을 보인 본인 채널), 빨강 2개, 초록 1개. 하락을 "빨갛게"로 말한 영상에는 "표현이 안맞네" 댓글이 달렸다.
  - 네이비 배경에서 파랑 글자는 잘 안 보인다. 이때는 **파랑 박스 위에 흰 글자**로 쓴다.
- 큰 숫자는 영상의 계좌 카드와 같은 표기로 쓴다: `-200만 원`, `-2,000만 원`
  - 제목의 "-2천만원"과 표기는 달라도 값은 같아야 한다.
- 손실은 %가 아니라 금액으로 크게 쓴다. %는 보조로만 쓴다 (제목 규칙과 같음).

## 2. 기본 시안 순서 (공통 4번 축을 주식에 맞춘 것)

| 시안 | 축 | 주식에서 만드는 법 | 근거 |
|---|---|---|---|
| thumbnail_1 | 숫자 반전 | **계좌 카드**: 시작 손익 → 끝 손익 (작은 숫자 → 큰 숫자, 화살표) | 작은 채널 15개 중 숫자가 있는 것 12개(금액 8개), 실제 계좌 화면이 들어간 것 3개(마르지 않는 투자 -72.85% → -95.31%, 최총명 3억 → 3천, 투린부부 -13,397,201). 단 3개 모두 본인 실제 계좌이고, 사람 없이 계좌만 있는 것은 1개뿐 → 근거 약함, 실제 성과로 검증 (사용자 결정 필요: 인물을 함께 넣을지 — `data_insights.md` 4-2의 2) |
| thumbnail_2 | 인물·감정 장면 | 손실을 확인한 가상 인물(30~50대 개인 투자자)의 표정 + 휴대폰 화면의 파란 손실 숫자 | 작은 채널 15개 중 사람·캐릭터 14개 (실제 촬영 7, AI·그림 인물 6, 만화 1). 표정은 괴로움·걱정·멍함 5, 웃음 4, 진지 2, 안 보임 3 |
| thumbnail_3 | 검은 배경 제목형 | 검은 배경에 채택 제목 앞 문장 그대로(3~4줄). **손실 금액은 노랑**(빨강 금지 — 이 채널에서 빨강은 수익), 수익 금액(+1,500만원, +30% 등)은 빨강, 그 밖의 빨강은 손실을 부른 행동·결정적 단어 1곳(예: "물타서", "다 팔았는데") — 숫자가 아닌 단어에만 | 사용자 지시 2026-10-11: 글자만으로 클릭을 부르는지 시험. 작은 채널 15개 중 같은 형태(글자만 있는 검은 배경)는 0개라 데이터로는 아직 모름 |

- **모든 시안 아래쪽에 제목 문구 2줄** (공통 `guides/thumbnail_guide.md` v1.3 1번 2항·4-2, 사용자 지시 2026-10-11). 작은 채널 15개도 같은 방향이다: 주 문구 2줄 10개, 문구가 아래쪽 9개, 제목의 핵심을 거의 그대로 쓴 것 11개 (`data_insights.md` 2-6). 카드·인물·숫자는 위쪽 약 60% 안에 줄여 넣는다. 전에 쓰던 대비 축은 thumbnail_1·2 대신 시험할 때만 쓴다.
- 하단 2줄 안에서도 손실 숫자는 빨강으로 쓰지 않는다: 흰 글자 또는 노랑 단어로 쓴다 (파랑 글자는 어두운 띠 위에서 안 읽힘).

## 3. 계좌 카드 그리기

- 영상(`guides/video_guide.md` 3-5 "계좌 카드")과 같은 모양·같은 색: 크림 카드, 잉크 선, 큰 평가손익 숫자, 작은 라벨 "내 계좌"
- **실제 증권사 앱처럼 보이지 않게** 한다.
  - 증권사·앱 이름, 로고, 실제 앱의 레이아웃을 따라 그리지 않는다.
  - 성공 썸네일은 실제 앱 캡처를 썼지만, 이 채널은 재구성 사연이라 실제 계좌처럼 오해되면 안 된다.
- 종목명·티커는 넣지 않는다. 행동(물타기 등)과 숫자로만 보여 준다. 실존 기업 비방·추천 오해를 막기 위해서다.

## 4. 인물

- **필요하면 넣는다** (사용자 지시 2026-10-09).
  - 썸네일은 사용자가 이미지 AI로 만들므로 영상의 "인물 금지" 원칙과 따로 간다. 영상(Remotion)에는 계속 인물을 그리지 않는다.
- 데이터 (`data_insights.md` 2-6): 작은 채널 성공 썸네일 15개 중 14개에 사람·캐릭터가 있다. 50·60대로 보이는 인물 5개는 모두 AI·그림이고 오디오북·노후 주제 영상이다. 표정은 괴로움만이 아니라 웃음(4개)도 있었다 — 손실 사연에는 지금 규칙(당황·허탈·후회)을 그대로 쓴다.
- AI가 만든 **가상 인물만** 쓴다. 실존 인물·유명인을 닮게 하지 않는다.
  - 사연자 나이대(30~50대 직장인 개인 투자자)에 맞추고, 사연에 없는 설정(노후 등)은 넣지 않는다.
- 표정은 당황·허탈·후회까지만 쓴다. 우는 얼굴 클로즈업, 극단적 공포·자해 연상 장면은 쓰지 않는다.
- 휴대폰 화면은 **증권사 앱을 따라 그리지 않은 단순한 화면**으로 한다: 파란 숫자와 하락 선만 넣고, 앱 이름·로고는 넣지 않는다.

## 5. 문구 톤

- 개미 말투, 짧게: "물타기 2번에", "평단 낮추다가", "버틴 결과"
- 문구에는 종목 추천·수익 보장처럼 읽히는 말("지금 사세요", "무조건 오른다")을 쓰지 않는다.
