## 0. 채널 설명 (`economic/guides/channel.md` — 주제·안은 이 목적·전달 방식에 맞게)

- **목적** = 50·60대가 노후 연금·은퇴 전후 돈 문제에서 **"내 경우엔 얼마를 아끼고, 얼마를 손해 보나?"** 를 실제 금액으로 알게 함 — 한 편에 바로 따라 할 수 있는 한 가지(순서·기한·고르는 법).
- **다루는 것** = 국민연금·기초연금·연금저축·IRP · 퇴직 후 건보료와 피부양자 · ISA · 노후 생활비와 세금. **빼는 것** = 경제 뉴스·금리·환율 해설 · 개별 종목·상품 추천 · 부동산·코인 (CLAUDE.md · 채널 설정 v1.1).
- **전달 방식** = 실제와 비슷한 가상 사례(부부·한 사람)로 두 길을 계산해 차이를 금액으로 → 결론 먼저 → 오늘 시행 중인 법령 원문·공단·국세청 기준으로 확인한 사실만.

| 꼴 | 시청자의 궁금증 | 진행 | 답 |
|---|---|---|---|
| 사연형 | "저 부부처럼 나도 손해 보고 있나" | 도입 25초(결과 숫자 먼저) → 챕터(끝 문장이 다음 궁금증) → 아주 짧은 마무리 (`quick_script.md` 5-1) | 두 길의 금액 차이 + 지금 할 일 |
| 비교형 | "A 와 B 중 어느 쪽이 덜 내나·더 받나" | 같은 사람·같은 기간으로 두 길 계산 → 판정 | 판정 규칙으로 하나의 결론 + 까닭 |

| question | 시청자가 묻는 것 한 문장 |
| conclusion | **예상 결론 한 문장 — 숫자·판정으로** ('…보다 …가 더 남았다', 'N년 이상이면 손실 0%'). 애매한 말 금지: 상황에 따라·경우에 따라·사람마다·개인차·케이스 바이·다를 수·일 수도·할 수도·될 수도·수도 있·신중·적절히·잘 판단·고려해야·알 수 없·정답은 없·모른다·애매·장단점·일장일단·나름·본인 선택·성향에 따라 |
| decide | 판정 규칙 — 자료가 어느 쪽으로 나와도 결론이 하나로 정해지는 기준 ('A가 B보다 높은 구간이 50% 넘으면 A, 아니면 B') |
| data | 자료·기준 (오늘 시행 중인 법령 원문 조문 — tools/law_text.py · 2026년 기준 금액·요율 · 계산 가정, 연도 필수) |
| format | 사연형 (가상 사례 부부·한 사람 — 도입 25초 → 챕터 → 짧은 마무리, economic/guides/quick_script.md 5-1) · 비교형 (A vs B 계산 하나) |
