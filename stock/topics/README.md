## 정답 미리 확인 (v1.3 — 2026-10-29 · 요약본보다 먼저)
**왜**: 예전 판정 규칙('A 가 B 보다 높은 구간이 50% 넘으면 A')은 51 대 49 로 갈려도 정답을 만들었다. 매수 시기 편은 계산 첫 회(2년 vs 5년)부터 뒤집혔는데 항목만 바꿔 넘겼고, 반론 10회 끝에 '정답이 없는 주제'로 드러남.
1. **언제**: 주제를 골라 요약본을 쓰기 **전** (새 묶음을 만들면 20개 모두 · 사용자가 고른 주제는 반드시). `topic_ideas.py use` 는 미리 계산이 없으면 경고한다.
2. **계산** `python3 -B stock/topics/precheck/precheck.py` — 주제마다 함수 하나(실제 자료 · 캐시 `precheck/data/`)를 더하고 돌림 → `precheck/precheck_<날짜>.json`. 비교 주제의 칸 = **기간**(2년·5년, 필요하면 10년) × **시작 시기**(2000~2008 하락기 시작 · 2009~ 시작) × **가정**(현금 이자 5% · 세금·수수료 있음/없음 · 다른 지수 등 결론을 바꿀 만한 것 하나 이상).
3. **분류** (계산 전에 정한 기준 — `precheck.py` 머리):
   | 분류 | 기준 | 만들 수 있는 꼴 |
   |---|---|---|
   | 정답형 | 모든 칸에서 이긴 쪽이 같고, 가장 약한 칸 ≥ 55% · 기본 칸 ≥ 60% (앞 시기 자료가 없으면 정답형 ✗ → 미확인) | 테스트 · 문제 · 비교 |
   | 차이없음 | 모든 칸 45~55% · 금액 차이도 작음 → "차이가 없다"가 정답 | 테스트 · 문제 · 비교 |
   | 사실형 | 지난 한 구간의 숫자(몇 년·몇 %) — 숫자는 분명, 규칙으로 넓히지 않음 | 문제(그때 무슨 일이) · 비교 (결론은 숫자 그대로) |
   | 계산형 | 법·수식으로 정해짐 — 가정 범위에서 같은지 + 법령 원문 확인 | 테스트 · 문제 |
   | 조건부형 | 칸에 따라 이긴 쪽이 바뀜 | **비교만** (결론 = 어떤 조건에서 갈리나 · 내기의 크기) — 정답을 맞히는 테스트형 ✗ |
   | 미확인 | 자료가 이 환경에 없음 | 안 씀 (무엇이 필요한지 적어 둠) |
4. **고친 결론**: 후보의 '예상 결론'을 계산 숫자로 다시 씀 → `precheck/conclusions_<날짜>.json` (`{ID: 문장}`) — 예상과 다르면 계산이 이긴다.
5. **넣기** `python3 tools/topic_ideas.py stock precheck stock/topics/precheck/precheck_<날짜>.json stock/topics/precheck/conclusions_<날짜>.json` → 주제탐색.md 표에 '미리 계산' 칸 · 평가판 제목 앞 [분류] · `settings.toml [precheck]` EXCLUDE(미확인) · NO_TEST(조건부형인데 테스트형)는 ⛔ 묶음에서 뺌.
6. **사용자에게** (요약본 전 한 번): 주제마다 **정답 한 문장 · 미리 계산 결과(어디서 그대로, 어디서 뒤집힘) · 영상 꼴** 세 줄 → 좋음·나쁨. 결과 모음 `정답확인.md`.

## 후보 한 개 (pool JSON — 칸은 `material.md` 머리 표)
- **결론 = 예상 결론 한 문장, 숫자·판정으로** ('…보다 …가 더 남았다', 'N년 이상이면 손실 0%'). 애매한 말(상황에 따라·~일 수도·신중·장단점…)이 있으면 도구가 뺀다.
- **판정 규칙** = 자료가 어느 쪽으로 나와도 결론이 하나로 정해지는 기준 ('A가 B보다 높은 구간이 50% 넘으면 A, 아니면 B'). 기준(보다·이상·%·비율…)이 없으면 뺀다. ⚠ v1.3: 이 규칙만으로 정답이 되지 않는다 — **정답 미리 확인**(위 절)의 칸과 분류를 통과해야 정답.
- **자료** = 실제 미국 주가·지수·재무제표·법령 + 기간(연도). 2000년 이후 (1900년대 자료 ✗).
- 이미 쓴·쓰는 주제와 같으면 뺀다: 낱말 닮음 ≥ 0.40 또는 글자 겹침 ≥ 0.50 (올린 영상 · 옛 대본 · `stock/source/*/요약본.txt` 방향·항목·사례·제목 (새 꼴은 [방향] '항목 N:' 줄 · [N안] 제목 줄, '#' 주석은 뺌) · 앞서 낸 주제).

## 점수와 배우기
- 처음 점수 = 댓글 니즈 👍 · 주제 묶음 성공 비율 · 페르소나 몫 · 공급 틈 · 성공 사례 제목 닮음 (무게는 `settings.toml [score]`).
- 배운 점수 = 갈래(페르소나·형식·주제 묶음·시장·자료·니즈)마다 log((좋음+1)/(나쁨+1)) 평균 + 가장 닮은 좋음 주제 − 가장 닮은 나쁨 주제.
- 평가가 5개를 넘으면 새 20개 중 3자리는 아직 평가 없는 갈래에서 (좋은 쪽만 파다 새 좋은 쪽을 놓치지 않게).
- 2026-10-28 시험 (복사본에서): 좋음 3·나쁨 3을 넣자 '주가 백테스트·실험형' 주제가 오르고 '배당 테스트형'이 내려감 · 다 쓴 묶음은 대기 후보로 갱신되고 탐색 자리 3개가 채워짐.
