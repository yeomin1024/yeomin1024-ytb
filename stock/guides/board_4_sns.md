## 2. 명령
```bash
git pull --rebase origin main
python3 tools/sns_posts.py            # 원본 json → stock/topics/sns/sns_posts.md (복사용) + stock/topics/SNS평가판.html · 한도·K8·정답 몰림을 어기면 멈춤
```
- **피드백은 달린 글(편·플랫폼)에만 고치지 않고 1~4편 X·스레드 8개 글 모두에 반영** (사용자 지시 2026-11-04·05 "피드백했는데 모든 글에 반영하도록 해" · "피드백 모든 글에 반영되도록 수정"): 피드백이 `e1-x` 에 달렸어도 문항·소개 글·말투·형식 규칙이면 **원본 json 의 모든 편**을 같은 기준으로 고치고(편마다 문장이 달라 기계 치환 ✗ — 40개 케이스를 하나씩 읽고 고침), 규칙은 이 파일 1번 + 가능하면 `tools/sns_posts.py` 검사로 남김. 그 편만의 사실(숫자·장면)이 틀렸다는 지적만 그 편에서 끝. 답변(reply)엔 '8개 글 모두 적용' 을 적는다. 이미 **통과한 글**(아래)에도 같은 피드백이면 통과 글도 고치고 판정을 다시 받는다.
- 판 피드백: `ArtifactData query feedback where status == new` (url = 판) → 줄 피드백(`lines` — 판의 줄 번호는 편·플랫폼마다 1부터, `quote` 로 어느 문항인지 확인)·칸 피드백(`field`) → **원본 json 을 고침**(글은 도구가 다시 짬) → 원본 `ver` 올림 → 도구 → 판 다시 올림 → 피드백마다 done·reply.
- 판정 '통과 (올림)' = 사용자가 그 글을 그대로 올림 (판의 db `verdicts/<key>` — key = `e<편>-x`·`e<편>-threads`). 영상이 올라가면 `video_link` 를 채우고 도구 다시.
- **통과 현황**: 2026-11-05 사용자 지시로 **X 글은 1편(`e1-x`)만 통과 (v4)** — 2~4편 X · 1~4편 스레드는 아직 통과 아님. 판정은 `ArtifactData set verdicts/<key>` 로도 넣을 수 있음(사용자가 말했을 때만).

## 2-1. 통과한 글은 외국어 버전도 만든다 (사용자 지시 2026-11-05 "통과된건 외국어 버전도 만들도록 지시사항에 반영해")
- 대상 = 판정이 '통과 (올림)' 인 글(`verdicts/<key>`.verdict == pass)만. 통과 전 글은 번역하지 않음(고칠 때마다 두 번 일하지 않게).
- 언어 = **영어 먼저**(주식 분석이 외국 영상·시청자를 포함 — `stock/analyzer_config.toml` INCLUDE_FOREIGN true). 다른 언어는 사용자가 말할 때만. 새 언어를 정하면 이 줄에 적는다.
- 만드는 법: 통과한 한국어 글을 **뜻 그대로 옮김** — 케이스 10개 순서·판정 기준·댓글 구성(본문엔 기준 ✗·첫 댓글에 공개)·자극 문구·'투자 권유 아님' 한 줄까지 같게, 수치 새로 넣지 않음(케이스에 숫자 ✗), 번역투 말고 그 나라 SNS 말투, 한국 제도·앱 색 등 한국에만 맞는 말은 풀어 쓰거나 뺌(예 '전세금' → money needed for a lease deposit). 글자 한도는 같음(X 가중 280 — 영문은 1이라 더 길게 가능하되 한도 안, 스레드 500자).
