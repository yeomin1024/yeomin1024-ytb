## 4. 문구를 어떻게 줄였나
- 첫 문장 (핵심 문장, 0:00): 「김씨 부부는 은퇴 첫해에만 세금과 건보료로 200만 원 넘게 손해 본 걸 알게 됐습니다.」
- 짝 제목 R1 (`../shorts.md` 1번): 「세금 334만 원 낸 김씨가 본 글… 같은 5억 모은 부부는 108만 원」 (2026-10-17 쉬운 말로 — 예전 '같은 5억인데 108만 원')
- 뺀 말:
  - '김씨 부부는' — 그림이 부부를 보여 준다 (지시사항 4번 1항 '그림이 보여 주는 말').
  - '세금과 건보료로' — **그림 속 낱말** '세금'·'건보료'로 옮겼다 (댓글 니즈 낱말, 지시사항 5번 2항).
  - '본 걸 알게 됐습니다' — 그림의 표정이 보여 준다.
  - 제목의 '334만 원'·'108만 원'·'5억' — 2줄에 숫자가 셋 넘으면 작은 선반에서 읽히지 않는다. 비교 숫자는 제목과 둘째~넷째 문장이 말한다.
- 남은 말은 첫 문장과 글자가 같다: '은퇴 첫해에만' / '200만 원 넘게 손해'.
- 시청자층 낱말 '은퇴'를 맨 앞에 흰색으로 (지시사항 피드백 13). '어르신·노인'은 쓰지 않는다.
- 길이 (Noto Sans KR Black 근사 — 한글 1, 숫자 0.6, 띄어쓰기 0.3 글자 너비): 1줄 6.3 · 2줄 8.7 → 1줄 약 86px(너비 약 540px) · 2줄 약 92px(너비 약 800px) — 왼쪽 x 76 에서 시작해 x 907(너비 84%) 앞에서 끝남.
- 사실 확인 (`../shorts.md` 6번):
  - '200만 원 넘게' = 첫해 세금 차이만 334만 − 108만 = 약 226만 원 (롱폼 README A 333.7 · B 107.8 → 225.9만 원). 건보료 손해(피부양자 탈락)는 그 위에 더해짐 — 금액은 롱폼도 계산하지 않아 '넘게'로만.
  - '은퇴 첫해' = 쇼츠 문장 1 · 롱폼 '첫해 세금 334 vs 108만 원'.

## 5. 그림·색
- 장면 = 첫 문장의 순간 (각색 — 김씨가 은퇴자 커뮤니티 글을 휴대폰으로 보고 알게 됨, `../shorts.md` 2번 문장 2~6): 오후 햇살이 드는 거실, 소파에 나란히 앉은 김씨 부부. 남편은 휴대폰을 들고 믿기지 않는 얼굴로 굳었고, 아내는 어깨에 손을 얹고 걱정스레 화면을 본다.
- 휴대폰 화면은 **시청자 쪽을 향하지 않는다** (빛만) — 실제 커뮤니티 사이트·앱 모양·글자를 그리지 않기 위해.
- '세금'·'건보료' 꼬리표는 휴대폰에서 알림처럼 떠오른다 (점선 꼬리). 빨강 상자 + 흰 평면 글자 — 손해를 만드는 것이라 빨강 (롱폼 꼬리표와 같은 뜻). 화살표는 쓰지 않는다 (롱폼과 달라 보이게).
- 인물: 쇼츠의 김씨 부부는 65세 (쇼츠 문장 3 '나이도 같은 65세 부부'). 사용자 지시 '되도록 젊게'에 따라 **60대 초반처럼** 그린다. 롱폼 썸네일의 인물(50대 시청자 대표, 남색 니트)과 옷·나이를 다르게 해 다른 사람으로 보인다.
- 색:
  - 노랑 #FFD400 = 중요한 것 ('첫해에만')
  - 빨강 #FF2A2A = 나쁜 상황 ('200만 원 넘게 손해', 손해를 만드는 '세금'·'건보료')
