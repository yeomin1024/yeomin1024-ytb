- 녹음한 내레이션이 있으면 `video/`에서 `npm run align-audio -- stock molppang-2026-10 --audio <파일>`로 SRT를 오디오에 맞춘다. 오디오는 고치지 않고, 녹음에 문장 18 뒤 3.5초 이상 쉼이 있어야 한다.
