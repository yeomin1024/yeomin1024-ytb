# 위기 상황 채널 — 채널 설명 (⚠️ 임시 — 사용자 채널 설명 전)

버전: v1.1 — 2026-11-12 — 3번 맨 위 **페르소나 반복 검증** (`guides/persona_loop.md`) — 사용자 지시 "제목,썸네일, 대본 만들때 자꾸 페르소나 반복 검증 빼먹는데 빼먹지 말도록 주제별 지시사항 수정해봐".
이전 v1.0 — 2026-11-12 — 새로 만듦. 사용자 지시 2026-11-12 "범죄, 사고 등 위험한 상황에서 만약 시청자라면 어떻게 하시겠습니까? 물어보고 위기를 모면한 경우와 그렇지 않은 경우 설명해주는 채널" → "지시사항 규칙대로 4가지 대본 만드는 것 까지 해봐".

## 1. 무엇을 하는 채널인가
- **위험한 상황 하나** (범죄·사고·재난) → **"여러분이라면 어떻게 하시겠습니까?"** (보기 2~3개) → **바로 정답과 이유** → **같은 상황에서 위기를 모면한 실제 사례 vs 그러지 못한 실제 사례** → 원칙 → 순서 → 이미 실수했다면 → 정리.
- 질문 뒤 바로 정답을 말하는 꼴은 주식 1~4편과 같다 (`guides/status.md` v3.43 — '여기서 당신은 …하시겠습니까? → 이때는 …옳은 선택입니다. → 해설'). 결론 먼저 40초 안 (`guides/script_guide.md` 0번 1).

## 2. 근거 (이 주제 분석만 — `crisis/result/`)
- 소재: 엘리베이터·시설 성공 비율 41% (1위) · 최근 28일 비중 항공 +8%p · 조난 +6%p · 물 +5%p (`result/analysis.md`).
- 제목: '대처법' 형식만 전체보다 높음 (배수 1.16) · 2인칭 제목 0.13 · 숫자 0.34 · 충격·소름 0.33 · 사망 결말 0.00 → **'여러분이라면'은 대본·썸네일에, 제목은 상황 + 결과**.
- 페르소나 4명 (`result/personas.md` 최종 F1~F4) — 대본 검토 `crisis/guides/viewer_review.md`.
- 한계: 이 분석은 저장소 표준 분석기가 아닌 독립 1차 분석 (`crisis/README.md`). 성공 사례 대본(음성인식)이 없어 말투·전개 숫자는 근거 없음 → 공통 지시사항 기본값(`script_guide.md` 2번·4-4)을 따른다.

## 3. 지킬 것
- **★ 페르소나 반복 검증 — 빠뜨리지 않음** (2026-11-12 사용자 지시 "제목,썸네일, 대본 만들때 자꾸 페르소나 반복 검증 빼먹는데 빼먹지 말도록 주제별 지시사항 수정해봐"): 제목·썸네일 문구·대본을 쓰거나 바꿀 때마다 `guides/persona_loop.md` (`title` · `script_exit` · `script_rebuttal`, 각 2회차 이상 · 회차마다 새 하위 에이전트) — 페르소나 = `crisis/result/personas.md` F1~F4 · 기록 `crisis/source/<영상ID>/persona_loop.json`. `viewer_review.md`(ChatGPT 검토)는 사용자 덧붙임 — Claude 회차를 대신하지 않음.
- **안전 수칙은 공식 자료 원문으로만** (행정안전부·소방청·한국승강기안전공단·금융감독원·사고조사 보고서). 출처는 대본 폴더 `checklist.md`, 영상 설명란.
- **국내 참사(사망자가 많은 최근 사건)의 화면·유가족 이야기는 쓰지 않는다** (분석: 항공 영상 댓글 좋아요 91%가 무안공항 참사 댓글 — 감정이 큰 만큼 이용으로 보이기 쉬움). 사망 사례는 숫자와 교훈만, 피해자 탓을 하지 않는다 ('그 사람이 잘못했다' ✗ → '그 상황에서 무엇이 갈랐나').
- 겁주기만 하고 끝내지 않는다 — 늘 '그래서 지금 할 일'.
- 사람·국적·지역 탓 금지 (분석: 제주 택시 사건 댓글에 외국인 혐오가 몰림).
- 119·112 는 행동으로 말한다 ("119에 신고합니다"). 그 밖의 전화번호·누리집은 대본에서 읽지 않고 설명란에 (`script_guide.md` 0번 11).
- 사례는 2020년대 먼저, 1900년대 사건은 쓰지 않는다 (CLAUDE.md). 개인 이름은 쓰지 않는다.
