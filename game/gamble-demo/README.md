## 1. 해 보기 (PC)

1. Godot 4.7 이상(표준판, .NET 아님)을 받습니다 — https://godotengine.org/download
2. Godot 를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **실행(F5)**
3. 글자가 □ 로 보이면: 프로젝트 설정 → GUI → 테마 → 사용자 지정 글꼴에 한글 글꼴(예: Noto Sans KR)을 넣습니다
4. 처음 뜨는 **사전 설정** 창에서 책상 위 물건 3자리를 고르고 **시작** (라이터·담뱃갑은 반사경이 든 것과 빈 것이 겉모양이 같음)

### 한 턴 = 왕 턴 → 노예 턴 (각 15초) → 판단 시간 → 공개
| 차례 | 왕 (방어) | 노예 (공격) |
|---|---|---|
| **왕 턴** | 카드를 엎어 냄 (클릭) · **C 가리기**(칩 덮개 → 반사경 엿보기 안 통함, 매치 3번) · **R 무작위**(카드를 안 보고 바로 냄 → 엿보기·협력자 둘 다 안 통함, 매치 2번) · **X 바꿔치기**(엿보는 상대에게 가짜 카드를 보여 줌, 매치 2번) | **G 제스처**(왕 턴이 **10초 이상 남았을 때만** −5초, 왕 턴마다 1번) · **2 협력자 부르기**(2.5초 뒤 상대 뒤에 섬, 매치 2번) · **1/3 물건 놓기** |
| **노예 턴** | 노예의 눈을 지켜봄 · 가능성 불이 켜지면 **Q 엿보기 밝혀내기 / W 협력자 밝혀내기** (턴마다 종류별 1번) | 반사경 물건에 시선 **1.5초 고정** 또는 협력자 손에 **1.8초 고정** → 상대 카드 · **F 시선 끌기**(3초 동안 상대가 내 시선을 못 봄, 매치 1번) · 카드 클릭으로 냄 |
| **판단 시간** (v0.6.0) | 노예가 낸 뒤 **5초** — 아직 공개 전, 밝혀내기 가능 (근거 = 이번 턴에 진짜로 썼는지, 적중하면 노예의 다음 차례 −5초) · **판단 끝·공개**(Enter)로 일찍 끝냄 | 기다림 (AI 왕은 1.2초 — AI 는 불이 켜질 때 이미 판단) |

- **시선 고정**: 게이지가 아님 — 눈을 떼면 처음부터. 물건은 왼쪽 아래 내 물건(자리 1~3), 협력자는 상대 오른쪽 뒤 사람.
- **가능성 불** (오른쪽 아래 두 칸): 실제로 썼든 아니든 노예 시선이 물건에 1.5초 / 협력자 자리에 1.8초 고정되면 켜짐 → 빈 물건·빈 자리를 오래 봐서 **미끼**로 쓸 수 있음. 시선 끌기 중엔 안 켜짐.
- **밝혀내기**: 이번 노예 턴에 그 속임수를 **진짜로** 썼으면 적중 → 노예 경고 +1 · 그 속임수 매치 동안 봉인(협력자는 쫓겨남) · 노예 지금 턴 −5초. 헛짚으면 → **내(왕) 다음 턴 −5초**. **경고 2개 = 즉시 패배.**
- 상대(AI) 협력자는 내 뒤에 서므로 안 보임 — 왼쪽 아래 그림자와 상대 눈이 내 머리 너머로 가는지로 알아챔. 상대가 시선 끌기를 쓰면 3초 동안 상대 눈이 가려짐.
- 상대가 바꿔치기·정보를 얻었는지는 공개 뒤에 알려 줌 ("속았다" · "바꿔치기 성공") · 내가 왕일 때 턴 끝 **리플레이**: 상대가 진짜로 했는지, 불이 미끼였는지.

### 화면 보는 법 (v0.7.0)
| 자리 | 무엇 |
|---|---|
| 왼쪽 위 **점수판** | 몇 판째 · 점수 · **당신 역할**(왕 = 방어 / 노예 = 공격) · 경고 ●○ · '다음 내 차례 −5초' |
| 가운데 위 **지금 할 일** | 큰 글씨 한 줄 + 도움말 한 줄 + **시간 막대** (내 차례 = 노란색, 5초 아래 = 빨간색, 상대 차례 = 회색) |
| 왼쪽 **행동 버튼** | 지금 역할의 행동만 큰 버튼으로. 아랫줄 = 효과·남은 횟수, 못 쓸 땐 **까닭**(예 '내 노예 턴에만'). 오른쪽 칩 = 단축키. 가능성 불이 켜지면 밝혀내기 버튼이 깜빡 |
| 오른쪽 **가능성 불** | 엿보기·협력자 두 칸 — 켜지면 노랗게 깜빡, 봉인되면 빨갛게. 아래 줄 = 협력자 상태 |
| 가운데 **알림** | 일이 생기면 잠깐 뜨고 사라짐 (초록 = 좋은 일, 빨강 = 나쁜 일, 노랑 = 주의) |
| 테이블 | 엿본 카드는 상대가 엎은 카드 옆에 반투명하게 · 내 노예 턴엔 물건 위에 할 일 안내 · 보는 물건엔 노란 고리 |
| **턴 결과 창** | 공개되면: 이겼다/졌다 · 두 카드 · 점수 · 이번 턴에 있었던 일 (속았는지, 상대가 진짜로 했는지) · **다음 ▶** |

- 마우스 위치 = 내 시선 · 카드 클릭 = 그 카드를 냄.
- **버튼·설정 위에 마우스가 있는 동안엔 시선이 마지막 자리 그대로** — 반사경을 보다가 버튼을 눌러도 고정이 안 끊기고, 왕이면 상대 얼굴을 계속 보는 걸로 침.
- 단축키: 노예 1 반사경 라이터 · 3 빈 라이터 · 2 협력자 · F 시선 끌기 · G 제스처 / 왕 C 가리기 · R 무작위 · X 바꿔치기 · Q 엿보기 밝혀내기 · W 협력자 밝혀내기 · Enter 판단 끝·다음 / H 규칙 (보는 동안 시간 멈춤).
- 오른쪽 위: 상대 고르기 · 새 매치 · 규칙 · 시야 제한 · 상대 시선 보조선(연습용).

### 규칙 한 장
- 왕 > 시민 > 암살자 > 왕, 시민끼리는 비김. 패 = 시민 4 + 특수 카드 1. 판마다 진영을 바꿈 (1·3·5판 = 당신 왕 측).
- 판 점수: 왕 측 승 +1 · 암살자 측 승 +4. 6판, 동점이면 연장 최대 2판(진영은 동전).
- 차례마다 15초 (제스처·밝혀내기로 줄어듦, 최소 3초) · 넘으면 남은 카드 중 아무거나.

## 2. 시험·시뮬레이션 (화면 없이)

저장소 맨 위에서 (Godot 실행 파일 이름이 `godot` 가 아니면 그 이름으로):

```bash
godot --headless --path game/gamble-demo --script res://tests/run_tests.gd
```

```bash
godot --headless --path game/gamble-demo --script res://tools/simulate.gd -- --matches=1000 --seed=42
```

- `run_tests.gd` 20묶음: 규칙표·반사경 여부 · 왕 턴 → 노예 턴 → **판단 시간** · **판단 시간 밝혀내기(적중 = 노예 다음 차례 −5초)·판단 끝·AI 왕 1.2초** · **버튼이 켜지는 조건 = 실제 규칙(상태 5 × 행동 11)** · **물건 사전 설정(3개까지)·게임 중 놓기** · **1.5초 계속 봐야 카드(눈을 떼면 처음부터)** · **미끼 물건·빈 협력자 자리도 불이 켜짐** · 협력자 1.8초 · 사람 밝혀내기(적중 = 경고·봉인·−5초 / 헛짚음 = 내 다음 턴 −5초) · AI 밝혀내기(진짜 = 적중, 미끼 = 헛짚음) · 봉인 · **가리기(엿보기만)·무작위(둘 다)·바꿔치기(가짜)** · **시선 끌기(불·밝혀내기 없음, 매치 1번)** · **제스처(10초 이상 남았을 때만)** · 경고 2개 패배 · AI 가 숨은 카드를 몰래 읽지 않음 · 시간 초과 · 연장 · 같은 시드 = 같은 매치 · 100 매치 상태 점검.
- `simulate.gd`: 자리 0·1 모두 AI. 조합마다 승률 · 매치당 정보(그중 협력자·가짜) · 들킴 · 두 번 들켜 진 비율 · 불·미끼 · 밝혀내기 수·적중률 · 방어·시선 끌기·제스처 수.

## 3. 구조

```
core/            규칙 — 노드에 의존하지 않음 (시험·나중 서버 공용)
  rank_cards.gd    카드 규칙 · 공정 플레이 기준 확률
  cheat_rules.gd   물건(반사경·겉모양) · 고정 시간(1.5/1.8초) · 턴 시간·깎임 · 방어 횟수 · AI 현장 밝혀내기 위험률
  ai_brain.gd      AI 성격(노예: 엿보기·협력자·미끼·시선 끌기·제스처 / 왕: 가리기·무작위·바꿔치기·밝혀내기) · 지켜보기 시선 · 카드 선택 · 의심
  match.gd         실시간 매치: tick(dt, 사람 시선) · set_objects · place_object · call_accomplice · attention · gesture · cover · play_random · fake · expose · judge_done · commit · next · why_not(행동 가능 여부 — 버튼도 씀) · 이벤트
  game_log.gd      [STAGE] [t=…ms] key=value 로그, 수준 조절
scenes/main.gd        화면 연결 · 준비 창(규칙+물건) · 점수판 · 지금 할 일·시간 막대 · 큰 행동 버튼 · 가능성 불 · 알림 · 턴 결과 창 · 규칙 창 · 시야 제한 셰이더
scenes/table_view.gd  테이블 장면 그리기 (상대·눈동자·물건 6자리·협력자·그림자·칩·카드·엿본 카드·할 일 안내) + 시선 영역
tests/run_tests.gd  tools/simulate.gd
```

튜닝: `core/cheat_rules.gd`(고정 시간·깎임·횟수·위험률) · `core/ai_brain.gd`(성격 묶음 `configure`) 값만 바꾸고 `simulate.gd` 로 확인.

### 로그 (Godot 출력 창)
`[MATCH] event=setup` → `[SETUP]`(사전 물건) → `[DEAL]` → `[TURN]` → `[PHASE]`(왕/노예 턴·제한 시간) → `[OBJECT]` · `[ACCOMPLICE]` · `[GESTURE]` · `[COVER]` · `[RANDOM]` · `[FAKE]` · `[ATTENTION]` → `[INFO]`(얻은 카드·가짜 여부) → `[LIGHT]`(가능성 불, 진짜/미끼) → `[EXPOSE]`(누가·종류·방식 light/watch/manual·적중·경고·시간) → `[COMMIT]` → `[JUDGE]`(판단 시간 시작: 불·실제 시도 여부 / 일찍 끝냄 / 시간 끝) → `[REVEAL]` → `[ROUND]` → `[MATCH] event=end`. `[GAZE]`(시선 바뀜)·`[SUSPECT]` 는 DEBUG. 거절된 행동은 `[REFUSE]`, 시간 초과는 `[TIMEOUT]`(WARNING).

## 4. AI 의 공정성 규칙
- AI 는 상대 카드를 엿보기·협력자로 '보인 카드'(바꿔치기면 가짜)로만 압니다 (`info["opp_card"]`, 시험 `ai_ignores_hidden_card`).
- AI 가 보는 것 = 공개 정보뿐: 당신의 시선(마우스가 가리키는 곳)·책상 위 물건(반사경 여부는 모름)·가능성 불·판 결과.
- 같은 시드면 같은 매치 (시드는 `[MATCH] event=setup seed=…` 와 기록 첫 줄).

## 5. 밸런스 (v0.5.0 — v0.6.0 도 같음: 판단 시간은 AI 끼리엔 1.2초 멈춤뿐이라 숫자가 그대로)
자리 0 → 자리 1, 승률(%) · 1,000 매치 · 두 자리 모두 AI (사람 자리도 같은 AI 성격으로).
성격: 정직(속임수 없음, 방어·밝혀내기는 함) · 손버릇 나쁜 딜러(cheater) · 눈이 매서운 노인(watcher) · 대담한 도박꾼(gambler).

|---|---|---|---|---|---|---|
| 정직 → 정직 | 48.5 / 51.5 | — | — | — | — | — |
| 딜러 → 정직 | **52.7 / 47.3** | 1.52 (0.25) | 0.94 | 9.6% | 1.98 (0.66) | 76% |
| 정직 → 딜러 | 47.2 / 52.8 | AI 1.57 (0.25) | AI 0.94 | AI 8.7% | 2.06 (0.70) | 77% |
| 딜러 → 노인 | 47.5 / 52.5 | 1.15 (0.24) | 0.98 | 10.8% | 1.65 (0.65) | 노인 75% |
| 노인 → 딜러 | 57.2 / 42.8 | AI 1.21 (0.28) | AI 1.00 | AI 13.0% | 1.72 (0.69) | 노인 73% |

- 미끼를 많이 쓰는 도박꾼 상대로는 밝혀내기 적중률이 50% 로 떨어짐 (헛짚을 때마다 왕 다음 턴 −5초).
- 정보의 약 16% 는 바꿔치기한 가짜 (속인 쪽이 오히려 짐).
