# 건강 주제 폴더 (`health/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **건강에만 해당하는 것**만 둔다. 구조는 `stock/`과 같다.
※ 건강 정보 제공용 콘텐츠다. 의사의 진단·치료를 대신하지 않는다.

분석 결과(`result/`, 실행 2026-10-11)가 나와서 규칙을 다시 검토했다 (`guides/data_insights.md` v1.0). 이제 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).

## 영상 제작 현황

영상 3개는 패키지(대본·SRT·제목 3개·썸네일 프롬프트 3개·업로드 시트·요약)를 마쳤고 오디오를 기다린다 (2026-10-11). 길이는 SRT 추정(초당 약 5.2음절)이라 오디오가 생기면 바뀐다. 규칙의 목표 분량은 10~12분(`guides/script_rules.md` 6번)이다.

| 영상ID | 채택 제목 (T1) | 문장 / 자막 | 추정 길이 | 상태 |
|---|---|---|---|---|
| `prediabetes-2026-10` | 공복혈당 108 '경계'라 괜찮다고 넘겼다가 3년 만에 당뇨가 됐습니다. 검진 결과지 대충 본 사람들의 공통점 | 94 / 117 (대본 v1.1) | 9:03 (목표보다 짧음 — v1.1은 1900년대 자료 근거만 바꾼 최소 수정) | 패키지 완성(오디오 대기) |

| `result/` | 분석 결과 (2026-10-11 실행 `20261011_120552`, 키워드 48개 중 13개 수집 — 직접 고치지 않음) |

| `guides/title_rules.md` | v1.2 건강 제목 규칙: 상시 고민 목록·제작 현황(v1.2: 영상 3개 채택 제목·길이), 결과지 숫자 반전, 악력 기준(50~64세 AWGS 2025), 결말 장치 3개("최악의 결말" 안 씀), 길이 51~60자, 금지 표현 |
| `guides/thumbnail_rules.md` | v1.1 건강 썸네일 규칙: 색 의미(위험=빨강, 좋아짐=파랑), 결과지 그리기, 인물·의료 이미지 제한, 소품 |
| `guides/upload_rules.md` | v1.1 건강 업로드 규칙: 설명란 출처·고지, 태그 후보, 제품 추천 요청·의료 상담 댓글 응대 |
| `voices/storyteller.json` | 사연자 말투(건강 후회 고백) — 공통 `voices/storyteller.json` 위에 instruct만 덮어씀. 화자 Sohee 그대로 |

## 분석 돌리기
```
bash tools/run_analysis.sh health          # 클라우드 (남은 키워드 35개 이어서 수집, 받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config health/analyzer_config.toml   # PC (자동완성·자막·썸네일까지)
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.
