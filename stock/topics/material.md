## 0. 채널 설명 (`stock/guides/channel.md` — 주제·안은 이 목적·전달 방식에 맞게)

- **목적** = 장기적으로 지속적인 수익을 내기 위한 **정보**(실제 자료·계산으로 확인한 판단 기준)와 **마인드**(계획·습관·버티는 태도) 전달 — 한 편에 둘 중 하나 이상.
- **전달 방식** = 먼저 시청자 스스로 궁금하게 만들고 → 그 궁금증에 맞는 정보로 답한다. 도입의 궁금증과 끝의 답이 짝 (답 없는 궁금증 ✗ · 궁금증과 상관없는 정보 ✗).
- **결론은 오래 통하는 것** — 한 번의 운(한 구간·한 종목)이 아니라 여러 구간에서 이긴 비율·미리 정한 계획. 단기 급등·몇 배 벌기·종목 추천을 약속하지 않음.

| 방식 | 시청자의 궁금증 | 꼴 | 답 (정보·마인드) |
|---|---|---|---|
| 테스트 | "과연 나는 어떨까" | 상황 항목에 답을 고르고 점수를 더함 → 통과·주의·불통과 | 0점 답 묶음 → 공통된 문제 → 그래서 (10점 답) |
| 문제 | "내 실력은 어느 정도일까" | 그때 공개된 실제 자료로 판단을 고름 → 정답 공개 | 정답·오답의 까닭 (숫자로) |
| 비교 시뮬레이션 | "A와 B 중 어느 쪽이 더 남을까" | 같은 돈·같은 기간·실제 자료로 둘 이상을 돌려 봄 → 결과 공개 | 판정 규칙으로 하나의 결론 + 까닭 |
| 그 밖 | (궁금증 먼저 → 그에 맞는 정보면 됨) | 제안만 → 사용자가 좋음 하면 이 표에 더함 | — |

## 후보 한 개의 칸 (모두 필수 — 빠지면 뺌)

| 칸 | 내용 |
|---|---|
| title | 주제 한 줄 (영상 제목 아님) |
| question | 시청자가 묻는 것 한 문장 |
| conclusion | **예상 결론 한 문장 — 숫자·판정으로** ('…보다 …가 더 남았다', 'N년 이상이면 손실 0%'). 애매한 말 금지: 상황에 따라·경우에 따라·사람마다·개인차·케이스 바이·다를 수·일 수도·할 수도·될 수도·수도 있·신중·적절히·잘 판단·고려해야·알 수 없·정답은 없·모른다·애매·장단점·일장일단·나름·본인 선택·성향에 따라 |
| decide | 판정 규칙 — 자료가 어느 쪽으로 나와도 결론이 하나로 정해지는 기준 ('A가 B보다 높은 구간이 50% 넘으면 A, 아니면 B') |
| data | 자료·기간 (실제 미국 주가·지수·재무제표, 2000년 이후 — 연도 필수) |
| format | 테스트형 = 채널 방식 '테스트'·'문제' (항목 5개 — stock/guides/quick_test.md) · 실험형 = '비교 시뮬레이션' (질문 하나) — 0번 |
| persona | personas.json 키: `worker` (월급으로 모아 가는 3040 직장인), `retired` (은퇴 자금을 굴리는 6070), `pre_retire` (노후를 준비하는 50대) |
| theme | 주제 묶음 번호 (아래 3번 표) |
| needs | 댓글 니즈 ID 목록 (아래 2번 표) |
| market | 미국 · 한국 · 미국+한국 |
| data_kind | 주가 백테스트 · 재무제표 · 세금·법 · 환율 · 그 밖 |
| items | (테스트형) 항목 예 3개 |
| why | 이 주제를 고른 까닭 한 줄 |
