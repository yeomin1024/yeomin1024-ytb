# 자기계발 주제 폴더 (`selfdev/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **자기계발에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 자기계발 정보 제공용 콘텐츠다. 의사·상담 전문가의 진단을 대신하지 않는다.

분석 결과(`result/`, 실행 2026-10-11, 키워드 48개 중 13개)가 나와서 규칙을 만들었다 (`guides/data_insights.md` v1.0). 사용자 지시(2026-10-11: 주식 밖 주제도 주제마다 최대 3개, 오디오 전까지)에 따라 영상 3개를 기획했다.

## 파일

| 위치 | 내용 |
|---|---|
| `analyzer_config.toml` | 분석기 설정: 검색어 48개(무기력·번아웃 / 미루기·작심삼일·습관 / 스마트폰·도파민 / 루틴·갓생 / 나이대·직장인 / 자존감·의지), 관련어·제외어 |
| `result/` | 분석 결과 (분석기 결과 — 직접 고치지 않음) |
| `guides/data_insights.md` | 분석 결과를 지시사항용으로 요약 (포맷·길이·제목 요소·카테고리·댓글·벤치마크). 말하기 속도·도입부·썸네일은 주식 결과 임시 사용 |
| `guides/script_rules.md` | 자기계발 대본 규칙: 30대 직장인 시청자, 재구성 사연·생활 숫자, 고지 카드 "정보 제공용 영상입니다", 최신 연구·유사과학 바로잡기, 마무리 인사, 근거 자료 은행 |
| `guides/title_rules.md` | 자기계발 제목 규칙: 상시 고민 목록, 제작 현황, 생활 숫자 반전, 금지 표현(질문형·방법형·목록형) |
| `guides/thumbnail_rules.md` | 자기계발 썸네일 규칙: 잃은 것 빨강·되찾은 것 파랑, 기록 카드, 실제 앱 화면·뇌 그림 금지, 가상 인물(30대 여성 직장인) |
| `guides/upload_rules.md` | 자기계발 업로드 규칙: 설명란 고지·연구 출처, 태그 묶음, 영양제·링크 홍보 차단, 마음 상태 댓글 응대 |
| `voices/storyteller.json` | 사연자 말투(instruct)만 자기계발에 맞게 덮어씀 — 화자는 공통 Sohee. 진행자는 공통 `voices/host.json`(잠금) |
| `source/used_content.md` | 이전 대본과의 중복 방지 목록 (기획 3개의 배정 근거) |

## 분석 다시 돌리기
```
bash tools/run_analysis.sh selfdev                               # 클라우드
python youtube_topic_analyzer.py --config selfdev/analyzer_config.toml   # PC
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.

> 2026-10-11 실행은 키워드 48개 중 13개만 수집됐다 (하루 쿼터를 5개 주제가 나눠 씀). 남은 35개는 다음 실행 때 이어서 수집된다. 자동완성·자막·썸네일은 클라우드 네트워크 정책으로 막혀, PC 실행 결과가 있으면 그것으로 보완한다.
