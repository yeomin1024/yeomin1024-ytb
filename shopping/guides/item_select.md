# 쿠팡 물건 고르기 — 순서와 자동화 (`shopping/`)

VERSION: v0.1 — 2026-11-27 — 첫 판 (사용자 지시 "아니 나는 어떤 쿠팡 아이템을 선정해야되는지 모르겠어 어떻게 할까? 자동화도 가능해?")

## 1. 고르는 순서 (한 편 = 물건 3~5개 비교)

| 단계 | 무엇 | 누가 | 자동? |
|---|---|---|---|
| ① 수요 | 4050 여성이 유튜브에서 많이 보고, 댓글로 "어디서 사요·제품명"을 묻는 물건 | Claude — `python3 shopping/source/item_scan.py` → `result/items/item_scan.md` | ✅ 지금 (할당량 0) |
| ② 거르기 | 다이소 몫 높음 → 쿠팡 대체품 비교로 · 효능 광고 규제 갈래(조심 칸) → 효능 말 없이 또는 뺌 · 입어 봐야 하는 옷 → 사람이 화면에 나올 때만 | Claude | ✅ 표에 칸으로 |
| ③ 쿠팡 쪽 | 같은 물건 3~5개 — 가격 · 단위 가격 · 리뷰 수 · 별점 · 로켓배송 · 파트너스 링크 | 지금: 사용자가 쿠팡 파트너스 화면에서 / 최종 승인 뒤: 오픈 API 로 Claude | ⏳ API 키 뒤 |
| ④ 최종 고르기 | 후보 표를 보고 살 것 정함 | **사용자** | ✗ (사람이 확인) |
| ⑤ 써 보기·찍기 | 사서 쓰고, 손·물건만 찍음 (얼굴 없이 가능) | **사용자** | ✗ (법 — 써 본 것만 '써 봤다') |
| ⑥ 대본·화면·설명란 | 잰 숫자 비교 화면 · 광고 표시(자막·설명란 첫 줄) 자동 · 링크 | Claude (기존 제작 길) | ✅ |
| ⑦ 성과 | 링크 클릭·주문·수수료 → 다음 ① 점수에 반영 | 최종 승인 뒤: 오픈 API 보고서로 Claude | ⏳ API 키 뒤 |

## 2. 자동화 — 되는 것 / 안 되는 것

- **되는 것**: ① 수요 찾기 · ② 거르기 · ⑥ 대본·화면·설명란 · (쿠팡 파트너스 최종 승인 뒤) ③ 상품 검색·링크 만들기 · ⑦ 클릭·주문 보고서.
  - 쿠팡 파트너스 오픈 API 는 **최종 승인 뒤** 열린다고 알려짐 — 누적 판매 15만 원을 넘기면 자동 심사 (블로그 정보 — ⚠️ 쿠팡 파트너스 공지로 확인). 키 없이 쿠팡 페이지를 긁어 오는 것은 약관 위반이라 하지 않는다.
  - 키는 환경 변수로만 (CLAUDE.md) · 이 클라우드 환경은 쿠팡 API 주소가 막혀 있어 그때 허용 목록에 더하거나 PC 에서 돌림.
- **안 되는 것 (자동으로 하면 안 됨)**:
  - 써 보지 않은 물건을 써 본 것처럼 — 표시광고법 기만 광고 (`channel.md` 3번 3).
  - 같은 틀에 물건만 바꿔 대량 업로드 — 유튜브 스팸(제휴 전용 계정)·진정성 없는 콘텐츠 정책 (`channel.md` 3번 4·5).
  - 최종 고르기를 점수만으로 — 점수는 검색 순위로 모은 자료라 치우침.
