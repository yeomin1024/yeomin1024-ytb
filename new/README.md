# 새 주제 탐색 폴더 (`new/`) — 어떤 채널을 새로 만들까

VERSION: v1.0 — 2026-10-16 — 새로 만듦 (사용자 지시 2026-10-16: "이외에도 내가 어떤 채널을 만들어야 조회수 높은 영상 만들고 구독자 많이 모을 수 있을지 전체적으로 탐색해봐 저장소에 디렉토리 new로 만들어서 새로운 주제 탐색하기 위한 세팅해서 탐색해봐")

- 이 폴더는 **한 주제가 아니라 여러 분야를 같은 방법으로 견준다.** 분야 27개(지금 제작 방식으로 만들 수 있는 A 17개 · 촬영이 필요한 B 8개 · 지금 채널 기준 2개)를 검색어 1~2개로 찔러 본다.
- 결과 숫자: [`result/niche/niche_scan.md`](result/niche/niche_scan.md) (숫자·원문만). **추천(판단)**: [`channel_ideas.md`](channel_ideas.md).
- 좋은 분야를 고르면 **그 분야만의 폴더**(예: `history/`)를 따로 만들어 태그로 검색어를 다시 고르고, 성공 사례 댓글까지 받아 분석한다 (`guides/pipeline.md` 1단계). 이 폴더의 결과로 대본·제목 규칙을 만들지 않는다 (분야마다 검색어 1~2개라 그 분야를 다 대표하지 못함).
- ※ 연구·교육용. 투자·의료·법률 권유가 아니다.

## 실행 (클라우드)

```bash
python3 tools/niche_scan.py new sync                 # niches.toml → keywords.txt('돌아가며' 순서) + tag_rules.toml(TAG_THEMES) — 할당량 0
python3 tools/cloud_run.py new explore --weeks 26    # 탐색 (검색어 44개 × 검색 2번 = 88번 ≈ 8,800단위 + 영상·채널 정보 ≈ 120단위)
python3 tools/niche_scan.py new report               # 분야 비교 → result/niche/niche_scan.md · .csv — 할당량 0
python3 tools/cloud_run.py new status                # 할당량·탐색 목록
```

- 분야·검색어를 바꾸려면 [`niches.toml`](niches.toml) 을 고치고 `sync` → `explore` → `report`. `keywords.txt`·`tag_rules.toml` 은 손으로 고치지 않는다 (만든 파일).
- 탐색 캐시는 `new/cloud_cache/cache.tgz` (다른 주제와 같은 방식 — `cloud_run.py` 가 저절로 묶고 풂). 검색 캐시는 7일 — 7일 안에 다시 `explore` 하면 할당량 0.
- PC 에서도 된다: `run_analyzer.ps1 -Folder new` (웹 화면 '새 주제 탐색' 탭). 그 뒤 `python tools/niche_scan.py new report`.

## 한계

- 분야마다 검색어 1~2개 · 검색마다 조회수 상위 50개 → '그 분야에서 가장 많이 본 영상들'만. 검색어끼리 결과가 다르다 (예: 사연 23% vs 오디오드라마 61% — `niche_scan.md` 3번).
- 자동완성(사람들이 찾는 말)·자막·썸네일·댓글이 없다 → 시청자 니즈·나이는 아직 모른다. 그 분야 폴더를 만든 뒤 승인한 성공 사례의 댓글로 본다.
- 광고 단가(RPM)는 API 로 알 수 없다 — 이 분석에 없음.
