# 사연형 설명 영상 — 썸네일 지시사항 (공통)

버전: v1.3 — 2026-10-11 — 사용자 지시: **모든 썸네일 아래쪽에 제목과 이어지는 문구 2줄**(짧은 문구만 군데군데 있으면 안 됨), **시안 하나(thumbnail_3)는 검은 배경에 채택 제목 문구를 그대로 크게**, 강조할 곳은 빨강·노랑 (v1.2: 프롬프트 파일만(코드 렌더 없음), 이미지 저장 위치·업로드 때 자동 규격 변환 / v1.1: 프롬프트 파일이 최종 산출물, 가상 인물 허용)

이 파일은 **모든 주제에 공통인** 썸네일 규칙이다. 아래 파일을 함께 읽는다.

| 파일 | 내용 |
|---|---|
| `<주제폴더>/guides/thumbnail_rules.md` (예: `stock/guides/thumbnail_rules.md`) | 주제 전용 규칙: 색의 의미, 숫자 표기, 금지 요소, 인물 표현. **이 파일과 다르면 주제 규칙을 따른다.** |
| `<주제폴더>/guides/data_insights.md` 6번 | 성공 영상 썸네일 관찰 결과 |
| `<주제폴더>/source/<영상ID>/titles.md` | 그 영상의 제목 3개 (썸네일과 짝) |
| `<주제폴더>/source/<영상ID>/<영상ID>.txt` | 대본. 썸네일 숫자 = 사연 숫자 |
| `guides/video_guide.md` 3번 | 디자인 시스템(색·폰트) — 썸네일도 같은 색을 쓴다 |

---

## 0. 목표와 출력

- **목표:** 목록에서 스쳐 지나가는 시청자가 1초 안에 "내 얘기다 + 결과가 궁금하다"를 느끼게 한다. 영상 안에서 실제로 보여 주는 장면만 약속한다.
- **영상 하나당 시안 3개**를 만든다. 업로드 뒤 YouTube 스튜디오 **"테스트 및 비교"**(썸네일 최대 3개)로 시험해, 시청 시간 기준으로 이긴 것을 남긴다.
  - 3개 모두 **아래쪽에 제목 문구 2줄**이 크게 들어간다. 그중 하나(thumbnail_3)는 그림 없이 **검은 배경에 채택 제목 문구를 그대로** 넣는다 (사용자 지시 2026-10-11, 1번 2항·4-1).
- **출력 = 프롬프트 파일 3개:** `<주제폴더>/source/<영상ID>/thumbnails/thumbnail_1.md`, `thumbnail_2.md`, `thumbnail_3.md` (6번 형식)
  - 사용자가 이 파일의 프롬프트를 이미지 AI(ChatGPT, Gemini, Midjourney, Ideogram 등)에 넣어 만든다.
  - 완성 이미지는 `<주제폴더>/source/<영상ID>/thumbnails/thumbnail_N.png`(또는 .jpg·.webp)로 저장한다. 프롬프트 파일 옆이다.
  - Claude는 이미지를 그리지 않는다 (사용자 지시 2026-10-10). 이미지 없는 썸네일의 프롬프트 모음: `python tools/make_summary.py --thumb-todo <주제폴더>` → `<주제폴더>/thumbnail_todo.md`
  - 4단계 업로드(`guides/pipeline.md`) 때 채택 제목의 짝 썸네일 1개가 자동 등록된다. 나머지 2개는 공개 전환 때 스튜디오 "테스트 및 비교"에 넣는다.

## 1. 절대 규칙

1. **썸네일 숫자 = 대본 사연 숫자 = 제목 숫자.** 하나라도 다르면 만들지 않고 알린다.
2. **모든 썸네일 아래쪽에 제목 문구 2줄을 크게 넣는다** (사용자 지시 2026-10-11). 짧은 문구만 군데군데 있는 썸네일은 만들지 않는다.
   - 내용: 짝 제목의 앞 문장(사연 부분)을 2줄로 줄인 것. 제목 단어를 그대로 써도 된다. 무슨 일이 있었는지가 이 2줄만 읽어도 보여야 한다.
   - 한 줄 12자 안팎(띄어쓰기 포함 14자 이내), 2줄 합쳐 26자 이내. 어절 중간에서 줄을 바꾸지 않는다.
   - 모양·자리는 4-2. 검은 배경 제목형(thumbnail_3)은 화면 전체가 제목 문구라 4-1을 따른다.
3. **위쪽 그림 영역의 짧은 문구(펀치)는 1개, 10자 이내**로 쓴다 (없어도 됨). 하단 2줄과 같은 말을 반복하지 않는다 (숫자는 같아도 됨).
   - 가장 중요한 숫자 하나를 가장 크게 쓴다 (하단 2줄보다 크게 또는 같게).
   - 이미지 AI가 한글을 정확히 그리도록 글자는 정한 것만 넣는다.
4. **한 썸네일에 한 메시지만** 담는다. 요소는 하단 2줄 + 그림(카드·인물) + 펀치 문구 1개까지다.
5. **영상에 없는 장면·숫자를 넣지 않는다.** 썸네일이 약속한 장면은 영상 1분 안에 나와야 한다 (대본 지시사항 0-1의 13번).
6. **인물:** 필요하면 넣는다. 성공 썸네일 대부분이 감정이 드러난 얼굴을 썼다 (`data_insights.md` 6번).
   - **AI가 만든 가상 인물만** 쓴다. 실존 인물·유명인을 닮게 하거나 이름을 넣지 않는다.
   - 프롬프트에 "fictional person, not resembling any real or famous person"을 넣는다.
   - 인물은 사연자의 감정(당황·후회·불안)을 보여 주는 역할만 한다. 과장된 공포·혐오 표현은 피한다.
7. **넣지 않는 것:**
   - 실제 기업·서비스 로고와 실제 앱 화면을 그대로 따라 그린 것
   - 실제 화폐 도안
   - 이모지
   - 특정 행동(주식: 매수·매도)을 권유하는 것처럼 보이는 연출
8. **오른쪽 아래 구석(약 220×70px)은 비운다.** 영상 길이 표시가 덮는다.
9. **작게 봐도 읽혀야 한다.** 가로 320px로 줄였을 때 문구와 핵심 숫자가 읽히는지 확인한다 (모바일 목록 크기).

## 2. 규격

| 항목 | 값 |
|---|---|
| 크기 | 1280×720 (16:9), PNG 또는 JPG, 2MB 이하. 이미지 AI가 16:9가 아닌 크기로 만들면 16:9로 잘라 1280×720으로 줄인다 |
| 글자 | 굵은 고딕(Noto Sans KR Black 같은 느낌), 외곽선 또는 색 상자로 배경과 분리 |
| 핵심 숫자 | 화면 높이의 20~30% 크기 |
| 하단 제목 2줄 | 글자 높이 화면 높이의 11~14%(약 80~100px), 2줄이 아래쪽 약 35%(y 약 450~690) 안 |
| 여백 | 가장자리 48px 안쪽에 글자 |

## 3. 디자인

- 색은 `guides/video_guide.md` 3-1을 따른다. 채널을 처음 보는 사람도 영상과 썸네일이 같은 채널로 보이게 하기 위해서다.
  - 크림 #F2EBDD, 다크 네이비 #14213D, 잉크 #1E1E1E, 노랑 강조 #FFD400 (한 곳만)
  - 수익·손실 색의 의미는 주제 규칙을 따른다 (주식: 수익 빨강 #E63B2E, 손실 파랑 #2D6CDF)
- 강조색(노랑 #FFD400·빨강 #E63B2E)은 한 썸네일에 **합쳐서 3곳 이하**로 쓴다. 노랑 상자(배경)는 1곳만. 빨강의 뜻은 주제 규칙을 따른다 (주식·사연: 빨강 = 수익·지킨 돈 → 손실 숫자에 쓰지 않음).
- 노랑 강조 위 글자는 잉크 #1E1E1E로 쓴다 (흰 글자는 노랑 위에서 안 읽힘).
  - 어두운 배경에서는 글자 전체 높이의 노랑 상자를 깐다. 절반만 칠하면 잉크 글자 윗부분이 배경에 묻힌다 (미리보기로 확인함).
- 영상에 나오는 대상(예: 사연 주인공의 계좌 카드)을 쓰면 영상과 같은 모양·색으로 쓴다.
- 장식용 도형·효과는 넣지 않는다.

## 4. 시안 3개 만드는 법

시안마다 **시험하는 가설(축)이 달라야** 테스트에서 배울 것이 생긴다. 기본 3축은 이렇다.

| 시안 | 축 | 만드는 법 | 짝 제목 (기본) |
|---|---|---|---|
| thumbnail_1 | **숫자 반전** | 위쪽: 사연의 시작 숫자 → 끝 숫자 (계좌 카드·화살표) / 아래쪽: 제목 문구 2줄 | 채택 제목 |
| thumbnail_2 | **인물·감정 장면** | 위쪽: 문제 행동의 결과를 마주한 가상 인물의 표정 + 핵심 숫자 / 아래쪽: 제목 문구 2줄 | 속마음·장면 훅 제목 |
| thumbnail_3 | **검은 배경 제목형** (사용자 지시 2026-10-11) | 검은 배경에 **채택 제목의 앞 문장을 글자 그대로** 크게, 강조할 곳만 노랑·빨강 (4-1) | 채택 제목 (글자가 곧 채택 제목) |

- 짝 제목은 `titles.md`의 T1~T3과 맞춘다. 다만 **어느 썸네일이든 3개 제목 모두와 어울려야** 한다.
- 전에 쓰던 **대비** 축(화면 분할: 왼쪽 = 기대, 오른쪽 = 결과)은 기본에서 뺐다. thumbnail_1·2 대신 시험하고 싶을 때만 쓴다 (이때도 하단 2줄).
- 주제 규칙이 다른 축을 정하면 그것을 따른다. 단 하단 2줄(1번 2항)과 검은 배경 제목형 1개는 모든 주제에 쓴다.

### 4-1. 검은 배경 제목형 (thumbnail_3)

그림 없이 글자만으로 클릭을 부르는지 시험한다. 목록에서 사진 썸네일 사이에 있으면 오히려 눈에 띈다.

| 항목 | 값 |
|---|---|
| 배경 | 순수 검정 #000000 한 가지. 인물·소품·도형·무늬·그라데이션 없음 |
| 글자 | **채택 제목의 앞 문장을 글자 그대로** (말 바꾸지 않음, 숫자 표기도 제목과 같게). 뒤 문장("~사람들의 공통점" 같은 결말 장치)은 넣지 않는다 — 크게 넣어야 읽히기 때문 |
| 줄 | 3~4줄, 한 줄 12자 안팎(띄어쓰기 포함 14자 이내), 어절 단위로 끊고 의미 덩어리(숫자 반전)가 한 줄에 오게 |
| 크기 | 글자 높이 약 90~110px, 줄 간격 1.15, 화면 폭의 85% 안. 가운데 정렬(또는 왼쪽 정렬) |
| 색 | 기본 흰색 #FFFFFF. **노랑 #FFD400** = 가장 중요한 숫자·결과 1~2곳, **빨강 #E63B2E** = 경고·결정적 행동 단어 1곳. 강조 합쳐 3곳 이하. 빨강의 뜻은 주제 규칙 1번을 따른다 (주식·사연은 손실 숫자를 빨강으로 쓰지 않음 → 손실 숫자는 노랑) |
| 금지 | 외곽선·그림자·네온 같은 효과, 다른 글자·로고, 오른쪽 아래 220×70 구석 침범 |

- 채택 제목이 바뀌면 이 썸네일 문구도 같이 바꾼다.
- 이미지 AI 없이도 만들 수 있다: 편집 프로그램(캔바·미리캔버스 등)에서 1280×720 검정 배경에 "문구" 표대로 글자만 얹는다 (프롬프트 파일의 [B]).

### 4-2. 하단 제목 2줄 (thumbnail_1·2, 대비 축)

| 항목 | 값 |
|---|---|
| 자리 | 아래쪽 약 35% (y 약 450~690), 왼쪽 정렬 x 48부터. 2번째 줄 오른쪽 끝은 x 1040 안 (오른쪽 아래 구석은 영상 길이 표시) |
| 배경 | 아래에서 위로 옅어지는 어두운 띠(검정 또는 다크 네이비 #14213D, 불투명 70~90%) — 그림 위에서도 글자가 읽히게 |
| 글자 | 굵은 고딕, 흰색 #FFFFFF + 두꺼운 검정 외곽선. 줄마다 핵심 단어 하나까지 노랑 #FFD400 또는 빨강(주제 규칙의 뜻대로) |
| 위쪽 그림 | 카드·인물·숫자는 위쪽 약 60% 안에 들어가게 줄여서 배치. 하단 2줄을 가리지 않는다 |

## 5. 만드는 방법

### 기본 — 이미지 AI에 프롬프트 넣기 (사용자)
1. 프롬프트 파일의 **[A] 완성형 프롬프트**를 넣는다. 한글 문구까지 이미지 AI가 그린다.
2. 한글이 틀리게 나오면 (흔함):
   - 두세 번 다시 만들어 본다.
   - 그래도 틀리면 **[B] 글자 없는 프롬프트**로 배경만 만들고, 캔바·미리캔버스·포토샵 등에서 "문구" 표대로 글자를 얹는다.
3. 7번 검수표로 확인하고 `source/<영상ID>/thumbnails/thumbnail_N.png`로 저장한다.
   - 크기는 맞추지 않아도 된다. 1280×720이 아니거나 2MB를 넘으면 업로드 도구(`tools/youtube_upload.py`)가 가운데 기준 16:9로 잘라 JPG로 바꿔 올린다. 그래서 **중요한 글자·얼굴은 가운데 16:9 안에** 두도록 프롬프트에 쓴다.
- 코드(Remotion `Still`)로 썸네일을 렌더하지 않는다 (사용자 지시 2026-10-10: 프롬프트 파일만).

## 6. 프롬프트 파일 형식 (`thumbnails/thumbnail_N.md`)

````markdown
# <영상ID> 썸네일 N — <축 이름>

버전: v1.x — <날짜> — 대본 <영상ID>.txt vX.Y 기준

| 항목 | 값 |
|---|---|
| 시험하는 가설 | (예) 손실 금액이 10배로 커진 숫자 반전이 가장 클릭을 부른다 |
| 짝 제목 | titles.md T1 |
| 숫자 근거 | 대본 자막 번호와 문장, 영상 속 시간 (1분 안인지) |

## 화면 구성
- 배치 설명 (왼쪽/가운데/오른쪽, 크기 비율)

## 문구 (그대로 사용)
| 줄 | 문구 | 색 | 강조 |
|---|---|---|---|
| (위쪽 그림 영역 문구·숫자) | | | |
| 하단 1줄 | (제목 문구 1) | 흰색 + 검정 외곽선 | (노랑·빨강 단어) |
| 하단 2줄 | (제목 문구 2) | 흰색 + 검정 외곽선 | |

## [A] 완성형 프롬프트 (이미지 AI에 그대로 붙여 넣기)
```
(영문 장면 묘사 + 한글 문구를 따옴표로 정확히 지정 + 스타일·색·금지 사항)
```

## [B] 글자 없는 프롬프트 (한글이 틀릴 때)
```
(같은 장면, 글자 없음, 글자 넣을 빈 자리 지정)
```

## 검수
- [ ] 7번 검수표 항목

## 결과 (업로드 후)
| 날짜 | 테스트 및 비교 결과 (시청 시간 비율) | 메모 |
|---|---|---|
````

### [A]·[B]에 붙이는 공통 문구
- [A] 끝에 붙이는 글자 지시:
