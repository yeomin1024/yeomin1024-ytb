## 1. 짝 제목과 그림이 전할 한 가지
- 짝 제목: `titles.md` R1 「커버드콜 분배금, 매달 꺼내 쓰면 같은 금액을 매도한 QQQ보다 13년 뒤 원금이 더 남을까?」 (10개 언어 모두 같은 뜻). 썸네일 글자는 영어 낱말·숫자·기호뿐이라 언어와 상관없이 한 장이다.
- 그림이 전할 것: **"분배금이 나오는 상자 vs 같은 돈을 꺼내는 지수 상자 — 두 상자에서 똑같은 동전이 매달 나가는데, 안에 남은 원금은?"**
- 결말 가리기: 두 상자 앞면은 **흐린 유리**라 안에 남은 금화 높이가 보이지 않는다. 위에 **닫힌 상자**. 두 상자는 같은 크기·같은 높이·같은 밝기, 두 동전 줄기도 같은 굵기.
- 색: 주황 = 커버드콜(QYLD) 계좌 · 파랑 = 지수(QQQ) 계좌 · 노랑 점선 = 처음 넣은 원금 높이 · 금색 동전 = 꺼낸 돈 · 배경 짙은 남색 (영상 화면과 같은 뜻)

## 3. 분석 근거 (`stock/guides/data_insights.md` 5번)
- 그림·캐릭터(반실사 포함) 성공 23% vs 기준 밖 10% → 인물을 **반실사 일러스트**로.
- 이미지 수치: 빨강 비율 P 0.58 · 어두운 비율 P 0.61 → **짙은 남색 배경**.
- 같은 채널 짝에서 잘된 쪽 = '대비' → 같은 크기의 선택을 나란히. 결과를 말하는 그림(차이 나는 높이·좌절 표정)은 쓰지 않는다 (사용자 지시 2026-10-16).
