# 사연을 통한 교훈 — 썸네일 전용 규칙

버전: v1.0 — 2026-10-10 — 최초 작성

공통 `guides/thumbnail_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

## 1. 색의 의미
- **잃은 돈·나빠진 관계 = 파랑 #2D6CDF**, **돌려받은 돈·좋아진 것 = 빨강 #E63B2E** (주식과 같은 뜻 — 국내 금융 앱 관례)
- 노랑 #FFD400 = 강조 한 곳

## 2. 인물
- 가상 인물만. 사연자 나이대(50대)에 맞춘다. 상대방(돈을 빌린 사람)은 얼굴을 보이지 않거나 뒷모습으로 — 특정인을 비난하는 연출이 되지 않게.
- 표정은 허탈·서운함까지. 다툼·폭력·울부짖는 장면 금지.

## 3. 문서·화면
- 차용증·계좌 이체 화면은 실제 서식·은행 앱을 베끼지 않는다. 은행 이름·로고·계좌번호·실명 없이 **금액과 한두 단어**만.
- 휴대폰 메시지 화면은 말풍선 모양만, 앱 이름·로고 없음.
