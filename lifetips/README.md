# 생활꿀팁 주제 폴더 (`lifetips/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **생활꿀팁에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 생활 정보 제공용 콘텐츠다. 특정 제품·업체를 추천하지 않고, 제품마다 다른 사용법은 제조사 사용설명서를 우선한다.

분석 결과(`result/`, 실행 2026-10-11)로 규칙을 만들었고, 2026-10-12에 작은 채널 롱폼 성공 사례·댓글 니즈 중심으로 다시 분석했다 (`guides/data_insights.md` v2.0). 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).

## 분석 다시 돌리기
```
bash tools/run_analysis.sh lifetips          # 클라우드 (받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config lifetips/analyzer_config.toml    # PC
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 8번 절차로 근거 숫자를 갱신한다. 최근 업로드만 다시 모으려면 YouTube Data API 키로 `python3 tools/outlier_research.py lifetips` (`data_insights.md` 6번).

> 2026-10-11 실행은 키워드 48개 중 13개만 수집됐다 (5개 주제가 하루 쿼터를 나눠 씀). 자동완성 수요·성공사례 대본·썸네일 이미지는 클라우드 네트워크 정책으로 받지 못했다.
