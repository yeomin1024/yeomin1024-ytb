## 4. 문구를 어떻게 줄였나
- 첫 문장 (0:00): 「최씨 부부는 퇴직 후 안 내도 될 건보료를 매달 약 30만 원씩 낸다는 걸 알게 됐습니다.」
- 짝 제목 R1 (`../shorts.md` 1번): 「건보료 30만 원 고지서 받은 최씨… 같은 조건 동기는 건보료 0원」 (2026-10-17 `../shorts.md` v2.2 — '0원' 앞에 '건보료'(무엇이 0원인지), 이 그림의 문구는 그대로)
- 뺀 말: '최씨 부부는' (그림·제목이 말함) · '는 걸 알게 됐습니다' (표정이 보여 줌). 나머지는 첫 문장과 글자가 같다 ('건보료를' → '건보료', '낸다는' → '낸다').
- 시청자층 낱말 '퇴직 후'를 맨 앞 흰색으로 (지시사항 피드백 13 — 쇼츠 제목에서는 대상 낱말을 뺐지만(−10%p ⚑), 썸네일 문구는 지시사항을 따른다).
- 제목의 '0원'(동기 부부)은 넣지 않는다 — '안 내도 될'이 같은 궁금증을 만들고, 2줄에 금액 둘을 넣으면 '무엇과 비교'가 그림 없이 설명돼야 해서.
- 길이 (Noto Sans KR Black 근사 — 한글 1, 숫자 0.6, 띄어쓰기 0.3 글자 너비): 1줄 11.2 · 2줄 10.4 → 1줄 약 72px(너비 약 806px) · 2줄 약 78px(너비 약 811px), x 76 에서 시작해 x 907 앞에서 끝남. 네 편 가운데 1줄이 가장 길어 글자가 가장 작다.
- 사실 확인 (`../shorts.md` 6번):
  - '매달 약 30만 원' = 179,750 + 123,939 = 303,689원 — 처음 13개월(2026년 10월분~2027년 10월분) 동안 이 금액 (롱폼 README 4번, 대본 문장 2·55).
  - '안 내도 될' = 롱폼 문장 3·26·33 (같은 부부가 자녀의 피부양자가 되면 0원) — 쇼츠·썸네일은 '피부양자'라는 말과 조건을 쓰지 않는다.
  - '퇴직 후' = 쇼츠 문장 1 (남편 60세 정년퇴직 — 롱폼 문장 15).
  - ⚠️ **확인 전**: 롱폼 `../../checklist.md` C표 1·2 ('약 30만 원·1년 넘게' 계산, '안 내도 될·0원' 판단)가 아직 확인 전이다 (`../shorts.md` 7번). 공단 답이 다르면 쇼츠 문장과 함께 **이 그림의 문구도 바꿔 이미지를 다시 만든다** (글자가 그림에 구워짐).

## 5. 그림·색
- 장면 = 각색한 경위(쇼츠 문장 2·3 — 정년퇴직한 최씨에게 첫 건보료 고지서가 날아옴, 찍힌 금액 약 30만 원)의 순간: 낮의 아파트 현관, 최씨가 열린 봉투와 펼친 편지를 들고 굳었고, 아내가 옆에서 어깨 너머로 들여다보며 걱정한다.
- 고지서는 **이름 없는 일반 봉투** — 앞면에 빨강 띠 + 흰 평면 글자 '건보료 고지서'만. 실제 기관 이름·로고·서식·주소·우표·바코드·금액 없음. 편지는 뒷면(빈 면)이 시청자 쪽 — 고지서 안 계산 내역(소득·재산 점수)을 그리지 않기 위해 (`../shorts.md` 3번 '핵심 정보는 그리지 않는다').
- 빨강 띠 = 손해를 만드는 것 (색 = 뜻).
- 인물: 쇼츠의 최씨 부부 60세 (쇼츠 문장 2·6·7 — 집 한 채, 소득 없는 아내). 사용자 지시 '되도록 젊게' → **50대 중반처럼**. 자녀(아들)는 그리지 않는다 (답을 내비침).
- 색: 노랑 #FFD400 = '안 내도 될 건보료' (중요한 것) · 빨강 #FF2A2A = '매달 약 30만 원씩'·봉투 띠 (나쁜 상황) · 흰색 = '퇴직 후'·'낸다' · 위·아래 바탕 = 짙은 남색 (#0C1424 근처, 다음 장면과 이어지게).

## 7. 넣지 않는 것 (`../shorts.md` 0번 — 롱폼의 핵심 정보)
- 왜 30만 원인지: 퇴직하면 지역가입자가 되고 끊긴 월급·집이 잡힘, 소득은 1~2년 늦게 잡힘, 집 점수·하한 계산.
- 어떻게 0원이 되는지: 자녀의 피부양자(소득 2,000만 원·재산 과세표준 5억 4천만 원 기준, 퇴직하고 90일 안에 신고), 소득 조정 신청, 임의계속가입(약 18만 원·최대 36개월·첫 고지서 납부기한에서 2개월), 고르는 순서, 이미 지역 보험료를 낼 때 할 일.
- 낱말 '피부양자'·'지역가입자'·'임의계속'·'0원 되는'·'순서'를 쓰지 않는다. 그림에도 자녀·피부양자 카드·신청서·기한 달력·고지서 안 계산 내역·월급과 고지서를 잇는 화살표·기준선을 그리지 않는다.
- 실제 기관(국민건강보험공단 등) 이름·로고·서식, 실제 회사, 실제 화폐 도안, 채널 이름, 실존 인물.
