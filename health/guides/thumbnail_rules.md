# 건강 — 썸네일 전용 규칙

버전: v1.0 — 2026-10-10 — 최초 작성

공통 `guides/thumbnail_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

## 1. 색의 의미 (영상과 같음)
- **위험·나빠짐·높은 수치 = 빨강 #E63B2E**, **정상·좋아짐 = 파랑 #2D6CDF** (주식과 의미가 다르다 — 이 주제에서는 이 뜻으로 고정)
- 노랑 #FFD400 = 강조 한 곳 (예: '경계' 글자)

## 2. 결과지 그리기
- 실제 결과통보서 서식을 그대로 베끼지 않는다. 기관 로고·이름·환자 정보·바코드 없이 **"공복혈당 108"처럼 숫자와 한두 단어**만 크게 쓴다.
- 결과지 문구를 쓸 때는 실제 표현을 쓴다 ("경계", "당뇨병 의심").

## 3. 인물
- 가상 인물만 (실존 인물·유명인·의사처럼 보이는 실제 인물 금지). 사연자 나이대(40~50대)에 맞춘다.
- 표정은 당황·걱정까지. 아파서 쓰러진 모습, 병원 침대, 주사·피·수술 장면은 쓰지 않는다.
- 흰 가운 의사 인물은 쓰지 않는다 (진료·처방처럼 보이는 연출 금지).

## 4. 문구
- 2줄 이하, 20자 이내. 결과지 숫자 하나를 가장 크게.
- 쓰지 않는 문구: "완치", "약 없이", "이것만", 제품 이름
