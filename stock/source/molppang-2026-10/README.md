- **장면은 SRT 번호가 아니라 대본 문장 번호(TXT 줄 순서)로 맞춘다.** 긴 문장은 자막 2개라서 SRT 번호는 문장 번호보다 커진다.
- 엔론 5문장(옛 55–59)을 빼서 **옛 문장 60–96 → 새 문장 55–91 (−5)**. 옛 1–54는 그대로다.
- 옛 영상 지시서(v2.0, 30장면)의 장면표는 엔론 장면을 빼고 **S24부터 문장 번호에서 5를 뺀다.** 공통 지시사항 `guides/video_guide.md` 5-3의 품질 예시 S25도 63–68 → 58–63으로 고쳤다.
- 고지 카드는 문장 18 뒤 그대로다 (엔론보다 앞).
