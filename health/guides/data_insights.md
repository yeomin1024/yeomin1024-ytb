버전: v0.1 — 2026-10-10 — 분석기를 아직 돌리지 않아 **YouTube 자동완성**으로 확인한 검색 수요만 적는다. `python youtube_topic_analyzer.py --config health/analyzer_config.toml` 실행 뒤 주식(`stock/guides/data_insights.md`)과 같은 형식으로 바꾼다.

## 1. 자동완성으로 본 수요 (2026-10-09 조회, 쿼터 0)
| 씨앗 검색어 | 자동완성 (일부) | 해석 |
|---|---|---|
| 당뇨 전단계 | 관리, 증상, 식단, 영양제, 간헐적 단식, 완치, 운동, 수치, 관리법 | 9개 모두 '전단계에서 무엇을 할까' — 문제→방법 구조와 맞음 |
| 공복혈당 | 수치, 장애, 낮추는 운동, 100, 낮추는 방법, 110, 장애의심 | 결과지 숫자(100·110)로 검색 → 제목·썸네일에 숫자 |
| 건강검진 추가검사 | 30·40·50·60대 추천, 비용 | 나이대별 검진 관심 |
| 건강 | 건강박수, 건강체조, 건강보험공단 … | 단독 '건강' 검색은 시니어 체조·기관 → 분석 검색어에서 뺌 |
| 영양제 부작용 | 멜라토닌·마그네슘 … | 제품 이름 중심 → 제목·태그에 제품 이름 쓰지 않음(규칙) |
