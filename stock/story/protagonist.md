# 주인공 설정 — 개미 투자자 구본석 (가상 인물)

버전: v1.0 — 2026-10-21 — 처음 만듦.

사용자 지시 (2026-10-21): "아래 이야기에 맞는 개미 투자자들의 평균을 조사해서 아래 내용대로 설정해서 요약해서 파일 만들어 / 전재산의 절반 이상을 읽은 개미 투자자가 원금 회복은 물론 파이어족이라는 꿈을 위해 포기하지 않고 올바른 투자 방법을 찾는 고군분투 이야기 / 이름(이야기에 맞고 특색있게), 나이, 가족, 직장, 투자자금, 주식 시작한지 몇년? 등 이야기 진행에 필요한 설정" · "아 그리고 주인공 이미지도 고정으로 설정해야 하니까 chatgpt가 주인공 이미지 생성해서 저장소 경로에 올릴 수 있도록 말할 것도 알려줘" (→ `protagonist_chatgpt.md`)

- 이 사람은 **가상 인물**이다. 실제 사람이 아니다. 설명란에 "개미 투자자 평균 통계로 만든 가상 인물, 이야기는 각색"이라고 밝힌다 (`stock/guides/story_script.md` 1-2).
- 나이·직장·소득·가족·투자 경력·투자 습관은 **평균 통계에 맞췄다** (8번 근거).
  - **잃은 돈의 크기만 평균보다 훨씬 크다.** 사용자가 정한 이야기 전제가 '전재산의 절반 이상'이기 때문이다. 손실 중인 40대 계좌의 평균 손실은 929만 원이다 (NH투자증권 2025-10-30).
- 영상의 숫자는 이 파일의 값만 쓴다. 새 사건이 필요하면 **5번 연표에 먼저 더한다** (영상끼리 어긋나지 않게).
- 시장 사건은 실제 기사로 확인한 것이다. 주인공 계좌의 숫자는 각색이다. 실제 지수·주가 숫자를 대본에 쓸 때는 코드나 원문으로 다시 확인한다 (story_script 3-1).

## 1. 한 줄 요약

> 6년 반 동안 모은 돈 전부와 전세금까지 주식에 넣었다가, 2026년 7월 폭락과 반대매매로 **전재산의 53%(1억 7천만 원)** 를 잃은 44세 중소기업 차장.
> 원금 회복과 '52세 파이어'를 포기하지 않고, 공장에서 불량을 줄이던 방식(원인 찾기 → 규칙 정하기 → 기록)으로 올바른 투자 방법을 찾아간다.

**이름** — 구본석
- '본(本)'은 본전(원금)과 기본에 쓰이는 글자다. 이야기의 축이 '본전을 찾으려다, 기본으로 돌아간다'라서 이 글자를 넣었다.
- 실제로 흔한 꼴의 이름이라 가상 인물이어도 자연스럽다.
- **이름 뜻풀이는 대본에서 하지 않는다** (번역이 안 됨 — story_script 4-2). 화면 연출이나 고정 댓글에서만 쓸 수 있다.
- 다른 안: 오기철 (오기로 버티는 사람) · 한결 (한결같이).

## 3. 돈 — 지금 (2026-10-21 기준, 가상)

| 항목 | 금액 |
|---|---|
| 6년 반 동안 넣은 내 돈 (투자 원금) | **2억 4,000만 원** = 시작 예금 5,000만 + 월급에서 모은 돈 약 7,000만 + 전세를 반전세로 바꿔 뺀 보증금 1억 2,000만 |
| 빌린 돈 (지금) | 마이너스 통장 **4,000만 원** (증권사 신용 6,000만 원은 2026년 7월 반대매매로 강제로 갚아짐) |
| 주식 계좌 평가액 (지금) | **1억 1,000만 원** → 빚을 빼면 7,000만 원 |
| 투자 손익 | 7,000만 − 2억 4,000만 = **−1억 7,000만 원 (원금의 −70.8%)** |
| 전재산 (투자를 안 했다면) | 보증금 8,000만 + 넣은 돈 2억 4,000만 = 3억 2,000만 원 |
| 전재산 (지금) | 보증금 8,000만 + 계좌 순 7,000만 = **1억 5,000만 원 → 전재산의 53.1%를 잃음** |
| 원금 회복까지 | 계좌 순 7,000만 → 2억 4,000만: **약 3.4배**가 되어야 함 |

- 계산: 1억 7,000만 ÷ 3억 2,000만 = 53.1%. 2억 4,000만 ÷ 7,000만 = 3.43배.
- 영상에서 금액을 말할 때는 어림 한 단위로 말한다 ('약 1억 7천만 원'). 화면에는 정확한 값을 쓴다 (`₩170,000,000`).

## 4. 파이어 꿈

| 항목 | 설정 | 근거 |
|---|---|---|
| 목표 | **52세(2034년) 파이어** — 딸이 대학에 들어가는 해 | MZ세대 희망 은퇴 나이 평균 51세 (NH투자증권 100세시대연구소 2021) |
| 목표 자산 | **9억 원** = 가족 연 생활비 3,600만 원 × 25배 | '25배 법칙' (= 해마다 4%씩 꺼내 쓰기) |
| 국민연금 | 65세(2047년)부터 — 1969년 이후 출생 | 파이어 뒤 13년은 연금 없이 버텨야 함 |
| 지금 거리 | 순자산 1억 5,000만 → 9억 원 (6배) | — |

- 이야기의 줄기: 처음에는 '빨리 본전'을 노린다. 그러다 '본전 + 파이어'에는 정해진 규칙과 시간이 필요하다는 것을 깨닫는다.
- 목표 나이·금액은 영상에서 백테스트·계산 코드로 '가능한지'를 확인하는 소재가 된다 (결론은 결과를 본 뒤에 — concept.md).

- '넣은 돈 누적'은 월 평균 약 100만 원을 넣은 값이다 (신한 2024 보고서 저축·투자 월 105만 원). 2020년 4월~2025년 6,000만 + 2026년 2~10월 1,000만 = 적립 7,000만 원.
- 영상에서 연표의 계좌 숫자를 말할 때는 이 표 값만 쓴다. 실제 지수·종목 주가는 코드·원문으로 확인한 값만 쓴다.

## 6. 투자 습관 — 평균 개미의 실수를 모아 놓음

| 습관 | 본석 | 근거 |
|---|---|---|
| 종목 수 | 늘 6개 안팎 — 그런데 같은 테마라 사실은 하나 | 1인당 평균 보유 종목 6.03개 (예탁원 2025년 말) |
| 매매 | 하루에도 여러 번 MTS 를 열고, 한 달에 수십 번 매매 | 잦은 매매·과도한 확신이 낮은 수익과 이어짐 (자본시장연구원 2021) |
| 정보 | 유튜브 추천 · 유료 리딩방 · 종목 토론방 | 금감원 불법 리딩방 소비자경보 (쓰기 전에 원문 확인) |
| 손실 | 손절을 못 하고 물타기 → 평단만 내려가고 비중이 커짐 | — |
| 빚 | 마이너스 통장 → 증권사 신용 → 반대매매 | 신용융자 38.6조 원 → 반대매매 (2026) |
| 레버리지 | 국내 2배 ETF · 미국 3배 ETF(SOXL) | 서학개미 순매수 상위 10개 중 절반이 레버리지 (2026년 6~7월) |
| 비상금 | 없음 (전세금까지 넣음) | — |

**성격·말투**
- 성실하고 숫자에 밝다 (생산관리 17년 — 엑셀·불량률·공정표).
- 투자에서만은 조급하고, 남의 말에 잘 흔들린다.
- 가족에게 미안해서 혼자 끌어안는다.
- 말버릇: "본전까지만…"
- 전환점: 공장에서 쓰던 방법 — 불량이 나면 원인을 찾고(복기), 공정을 표준화하고(규칙), 기록한다(일지) — 을 투자에 그대로 써 보기로 한다. 이것이 '방법을 찾는 노력'의 틀이다 (story_script 2-1 ④).
- 대본 말투는 해요체다 (story_script 1-3).

## 7. 이야기 소재 — 실수 → 찾을 방법

영상 주제는 분석 결과와 댓글 니즈로 고른다 (`stock/source/topic_candidates.md`). 이 표는 설정과 맞는 소재 목록일 뿐이다. 결론은 백테스트·원문을 본 뒤에 정한다.

| 본석의 실수 | 찾아볼 방법 (가설 — 확인 전) | 확인할 것 |
|---|---|---|
| 테마 몰빵 (2차전지) | 한 종목·한 테마의 비중 한도 | 분산 백테스트 · 생존 편향 |
| 물타기 | 정해진 날·정해진 금액 (적립식) vs 떨어질 때만 더 매수 | 여러 시작 시점 |
| 빚투·반대매매 | 빚 없이 투자 · 담보비율이 깨지는 하락 폭 | 반대매매 계산 |
| 레버리지 ETF | 2·3배 ETF의 '매일 맞추기' 손실 | 횡보장 백테스트 (예전 영상 `reobeoriji-2026-10` 소재와 겹침 — `stock/uploaded_videos.md`) |
| 리딩방·추천 종목 | 지수 ETF vs 골라 사기 | SPIVA(액티브 vs 지수) 원문 |
| 잦은 매매 | 매매 횟수·비용 줄이기 | 수수료·세금 넣은 백테스트 · Morningstar 'Mind the Gap' 원문 |
| 손절 못 함 | 손실 한도 규칙 (−n% 매도) | 여러 n · 다시 매수 규칙 |
