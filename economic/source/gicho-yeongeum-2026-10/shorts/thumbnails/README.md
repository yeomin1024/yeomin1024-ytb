## 4. 문구를 어떻게 줄였나
- 첫 문장 (0:00): 「67세 박씨 부부는 못 받는 줄 알았던 기초연금을 매달 41만 원 넘게 놓치고 있었습니다.」
- 짝 제목 R1 (`../shorts.md` 1번): 「기초연금 신청 안 한 박씨… 형편 같은 이웃 부부는 매달 41만 원 받는다」 (2026-10-17 쉬운 말로 고침 — 예전 「기초연금 포기한 박씨… 형편 같은 이웃 부부는 매달 41만 원」. 썸네일 문구는 그대로)
- 뺀 말:
  - '박씨' — 그림이 부부를 보여 준다. 이름은 제목이 말한다.
  - '못 받는 줄 알았던' — 그림의 생각 꼬리표('집 한 채'·'국민연금' = 못 받는다고 믿은 까닭)가 보여 준다. 줄에 넣으면 1줄이 15자가 되어 글자가 작아진다.
  - '놓치고 있었습니다' → '놓침' (쇼츠 장면 계획 1번 '<빨강>매달 41만 원+ 놓침</빨강>'과 같은 말).
- 남은 말은 첫 문장과 글자가 같다: '67세 부부' · '기초연금' · '매달 41만 원 넘게'.
- 시청자층 낱말: 나이 '67세'를 맨 앞 흰색으로 (지시사항 피드백 13). 숫자는 쇼츠 대본에 있는 것만 쓰므로 롱폼 썸네일의 '60·70대' 대신 대본의 '67세'.
  - ⚠️ 지시사항 4번 1항: 롱폼 제목에서 나이 하나만 맨 앞에 두면 약했다('60대' 맨 앞 −3). 여기서는 나이가 '이 이야기의 사람'을 가리키는 말이라 그대로 두었다 — 근거 없음.
- 길이 (Noto Sans KR Black 근사 — 한글 1, 숫자 0.6, 띄어쓰기 0.3 글자 너비): 1줄 8.8 · 2줄 10.4 → 둘 다 약 78px (2줄 너비 약 811px, x 76~887).
- 사실 확인 (`../shorts.md` 6번):
  - '매달 41만 원 넘게' = 이 부부가 받을 수 있는 기초연금 **최소** 월 41만 9,640원 (아내 27만 9,760 + 남편 최소 13만 9,880원 — 롱폼 README 4번, 대본 문장 4·57·75). 남편 몫은 가입 이력에 따라 더 많을 수 있어 '넘게'.
  - '67세' = 롱폼 대본 문장 2·16.
  - '놓침' = 신청하지 않아 받지 못하는 돈 (기초연금법 제10조①·제14조① — `../../checklist.md` A).
  - 2027년 고시(12월) 뒤에 올리면 41만 원을 다시 셈한다 (`../shorts.md` 7번) — **그림에 구운 숫자라 그때는 이미지도 다시 만든다.**

## 5. 그림·색
- 장면 = 각색한 경위(쇼츠 문장 4~6 — 같은 아파트 이웃 부부와 저녁을 먹다가, 형편이 똑같은 그 부부는 기초연금을 둘이 합쳐 한 달 41만 원 넘게 받는다는 말을 들음)의 순간. 이웃 부부는 **그리지 않는다** (화면 밖 왼쪽을 바라봄) — 얼굴이 넷이면 작은 화면에서 읽히지 않고, 오른쪽 16% 를 비워야 해서.
- 생각 꼬리표: 연회색(#D9DEE6) 둥근 사각형 + 짙은 회색 테두리 + 검정 평면 글자, 남편 머리 쪽으로 작은 회색 점이 이어짐. 회색 = '박씨의 생각' (쇼츠 장면 계획 2번의 회색 생각 풍선과 같은 뜻). 손해 자체가 아니라서 빨강으로 쓰지 않는다 (색 = 뜻).
- 인물: 쇼츠의 박씨 부부 67세 (쇼츠 문장 1·5). 사용자 지시 '되도록 젊게' → **60대 초반처럼**. 롱폼 썸네일 부부와 옷을 다르게.
- 색: 노랑 #FFD400 = '기초연금' (중요한 것) · 빨강 #FF2A2A = '매달 41만 원 넘게 놓침' (나쁜 상황) · 흰색 = '67세 부부' · 위·아래 바탕 = 짙은 남색 (#0C1424 근처, 다음 장면과 이어지게).
