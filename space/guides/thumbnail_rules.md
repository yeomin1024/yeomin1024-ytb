# 우주 — 썸네일 전용 규칙

버전: v1.1 — 2026-10-11 — 사용자 지시: 모든 시안 아래쪽 제목 문구 2줄, thumbnail_3 = 검은 배경 제목형 (v1.0 — 2026-10-11 — 최초 작성 (썸네일 관찰은 주식 결과 임시 사용, `data_insights.md` 6번))

공통 규칙 `guides/thumbnail_guide.md`와 함께 쓴다. **이 파일이 공통 규칙과 다르면 이 파일을 따른다.**

> ⚠️ 이번 분석은 썸네일 이미지를 받지 못했다 (클라우드 네트워크 차단). 아래 시안 축의 근거는 주식 성공 썸네일 관찰(큰 2줄 문구·숫자·감정이 드러난 얼굴·어두운 배경)을 빌린 것이다. 다음 분석에서 우주 썸네일이 받아지면 2번 표를 고친다.

## 1. 색의 의미 (영상과 같음)

- **위험·과장·틀린 정보 = 빨강 #E63B2E** (예: "충돌 확률 3.1%", "끝났다", "실패")
- **확인된 사실·안전·실제 결과 = 파랑 #2D6CDF** (예: "0.004%", "아직 신호", "4번 연속 성공")
- 노랑 #FFD400 = 강조 한 곳 (예: 반전 화살표 옆 한 단어)
- 주식(빨강=수익, 파랑=손실)과 뜻이 다르다. 건강 주제와 같은 방향이다. 이 주제에서는 이 뜻으로 고정한다.
- 우주 배경은 다크 네이비 #14213D를 기본으로 쓴다. 네이비 위 파랑 글자는 잘 안 보이므로 **파랑 박스 위 흰 글자**로 쓴다.

## 2. 기본 시안 순서 (공통 4번 축을 우주에 맞춘 것)

| 시안 | 축 | 우주에서 만드는 법 |
|---|---|---|
| thumbnail_1 | 숫자 반전 | 발표 숫자 카드: 처음 숫자(빨강) → 실제 결과 숫자(파랑), 화살표. 예: 3.1% → 0.004%, ✕ 1번 → ✓ 4번 |
| thumbnail_2 | 인물·감정 장면 | 그 소식을 잘못 받아들인 가상 인물(사연자 나이대 여성)의 당황·후회 표정 + 핵심 숫자 하나 |
| thumbnail_3 | 검은 배경 제목형 | 검은 배경에 채택 제목 앞 문장 그대로(3~4줄). 빨강 = 처음 겁준 숫자·틀린 말(예: "3.1%", "끝났다"), 노랑 = 실제 결과 숫자 1곳(예: "0.004%", "4번 연속"). 검정 위 파랑 글자는 안 읽혀서 쓰지 않는다 |

- **모든 시안 아래쪽에 제목 문구 2줄** (공통 `guides/thumbnail_guide.md` v1.3 1번 2항·4-2, 사용자 지시 2026-10-11). 카드·인물·숫자는 위쪽 약 60% 안에 줄여 넣는다. 전에 쓰던 대비 축은 thumbnail_1·2 대신 시험할 때만 쓴다.

## 3. 그리지 않는 것 (인물·이미지 제한)

- **실존 인물**: 우주비행사·과학자·엔지니어·기관장·연예인을 닮게 하거나 이름을 넣지 않는다. 우주복을 입은 인물은 실존 우주비행사로 오해될 수 있어 쓰지 않는다.
- **기관·기업 표시**: 나사·유럽우주국·우주항공청·한국항공우주연구원·스페이스X 등의 로고·이름·미션 패치, 로켓 몸체의 국기·글자를 그리지 않는다.
- **실제 화면 서식**: 실제 재난 문자 화면, 실제 뉴스 화면(방송사 자막 틀·로고), 나사 웹페이지, 실제 앱 화면을 따라 그리지 않는다. 휴대폰 화면은 숫자와 짧은 문구만 있는 단순한 화면으로 한다.
- **실제 사진처럼 보이는 가짜 우주 사진**: "나사가 찍은 사진"처럼 보이는 연출을 하지 않는다. 그림·일러스트 느낌이 드러나게 한다.
- **일어나지 않은 장면**: 지구·달에 소행성이 부딪혀 폭발하는 장면, 누리호가 폭발하는 장면(1차 발사도 폭발하지 않았다), 탐사선이 부서지는 장면을 그리지 않는다.
- 과장된 공포: 불타는 지구, 멸망 이미지, 비명 지르는 얼굴, 우는 얼굴 클로즈업은 쓰지 않는다. 표정은 당황·허탈·후회까지.

## 4. 소품 (우주 주제에 맞게)

| 소재 | 쓰는 것 |
|---|---|
| 확률·위험 | 확률 게이지(바늘), 숫자 카드, 망원경 실루엣, 생존 배낭·비상식량 같은 생활 소품 |
| 발사 | 일반적인 3단 로켓 실루엣(글자·국기 없음), 발사대 연기, TV·휴대폰 생중계 화면(단순), 체크 표시 줄(✕ ✓ ✓ ✓ ✓) |
| 탐사선 | 안테나 접시가 달린 탐사선 일러스트(로고 없음), 별이 드문 어두운 우주, 지구에서 이어지는 가는 신호선, "빛으로 하루" 같은 거리 띠 |

## 5. 문구

- 위쪽 그림 영역 문구는 1개·10자 이내, 아래쪽 제목 문구 2줄은 한 줄 14자·합 26자 이내 (공통 `thumbnail_guide.md` v1.3 1번 2·3항 — 옛 '2줄 이하, 20자 이내'를 바꿈, 사용자 지시 2026-10-11). 발표 숫자 하나를 가장 크게 (공통 1번).
- 쓰지 않는 문구: "멸망", "종말", "충격 폭로", "나사가 숨긴", "속보", 실존 인물 이름
- 숫자 표기는 제목과 같은 값으로: "3.1%", "0.004%", "46초", "4번 연속", "빛으로 하루"
