## 0. 목표와 출력
- **목표:** 목록에서 스쳐 지나가는 시청자가 1초 안에 "내 얘기다 + 손해 보기 싫다"를 느끼고 누르게 한다. 영상이 실제로 말하는 것만 약속한다.
- **영상 하나당 3개:** **본안 1개(클릭률 최대)** + **실험안 2개**. 업로드 뒤 YouTube 스튜디오 '테스트 및 비교'(최대 3개)로 시험한다.
- **출력 = 프롬프트 파일:** `<주제폴더>/source/<영상ID>/thumbnails/thumbnail_1~3.md` (6번 형식) + 같은 폴더 `README.md`(근거). `thumbnail_1` = 본안.
  - 이미지는 사용자가 이미지 AI(ChatGPT 등)로 만든다. Claude는 이미지를 렌더하지 않는다 (사용자 지시 2026-10-10).
  - 완성 이미지는 같은 폴더에 `thumbnail_N.png`(.jpg·.webp)로 저장한다. 업로드 도구가 채택 제목의 짝(기본 1번 = 본안)을 올린다.
  - 저장소에 올린다 (사용자 지시 2026-10-15 "만든 거 저장소 경로 만들어서 올려").

## 1. 문구 — 하단 2줄 (모든 시안)
1. **채택 제목에서 줄일 수 있는 말을 줄여** 2줄로 쓴다. 남은 말은 제목과 글자 그대로 쓴다.
   - 그림이 보여 주는 말(예: '은퇴 부부')과 덧붙인 숫자(예: '월 15만 원씩')를 먼저 뺀다.
   - 예: 「노후 연금 꺼내는 순서 모르면, 은퇴 부부 월 15만 원씩 평생 2천만 원 손해」 → **연금 꺼내는 순서 모르면 / 평생 2천만 원 손해**
2. **색:**
   - **노랑 #FFD400 = 중요한 것** (방법·핵심 낱말). 예: '연금 꺼내는 순서'
   - **빨강 #FF2A2A = 나쁜 상황** (손해·위험). 예: '2천만 원 손해'
   - 나머지는 흰색이다. 흰색·노랑은 두꺼운 검정 외곽선, 빨강은 두꺼운 흰 외곽선을 쓴다.
3. **자리·크기:**
   - 아래쪽 약 35% 안에 둔다. 아래에서 위로 옅어지는 어두운 띠 위에 왼쪽 정렬, x 48부터 쓴다.
   - 한 줄은 띄어쓰기 포함 14자 이내, 글자 높이 약 85~105px로 한다. 나쁜 상황 줄을 조금 더 크게 쓴다.
   - 2번째 줄은 오른쪽 아래 구석(약 220×70, 영상 길이 표시) 앞에서 끝낸다.
4. 숫자는 제목·대본과 같아야 한다. 대본이 계산하지 않은 금액은 쓰지 않는다.
5. 실험안도 문구는 본안과 **같게** 두는 것이 기본이다. 그림만 다르게 하면 테스트 결과를 그림의 차이로 읽을 수 있다.
   - 문구를 실험할 때는 그림을 본안과 같게 두고 문구만 바꾼다.

## 2. 그림 — 문구를 그대로 보여 주는 장면
1. 그림은 하단 2줄이 말하는 상황을 보여 준다. 예: 세금·건보료로 2천만 원 손해 보고 좌절한 50대 (사용자 지시 2026-10-15: "되도록 젊은 나이대로").
2. **댓글 니즈 낱말**(예: 세금·건보료)은 그림이나 문구에 넣는다.
   - **그림에 넣을 때는 낱말 그대로** 쓴다 (빨강 꼬리표, 거대한 입체 글자 등).
   - 고지서·서류 같은 **물건으로 바꿔 그리지 않는다** (사용자 지시 2026-10-15).
   - 그림 속 낱말은 2개 이하, 각 4자 안팎으로 한다.
3. 영상 내용 자체(예: 꺼내는 순서를 통장 순서로 그린 것)를 물건으로 그리지 않는다 — 문구가 말한다.
4. 사람은 **AI가 만든 가상 인물만** 쓴다. 프롬프트에 "Fictional person, not resembling any real or famous person"을 넣는다.
   - 대본 사례와 나이가 다르면 썸네일 `README.md`에 '시청자 대표 인물'이라고 적는다.
5. 넣지 않는 것: 실제 기업·기관 로고와 서식, 실제 화폐 도안, 이모지, 따옴표 밖의 글자.
6. 사람·글자는 **가운데 16:9 안에, 위아래 가장자리 8%는 비운다** (이미지 AI가 3:2로 만들면 업로드 때 위아래가 잘림).

## 3. 본안과 실험안 고르기 — 분석 결과로만
1. 그 주제의 성공 썸네일과 기준 밖 썸네일을 비교한다 (`economic/source/eunte-kkeonaeseugi-2026-10/thumbnails/README.md` 3번 방법).
   - 이미지 수치: `thumbnails/analysis/metrics.py`
   - 눈으로 표시: `codes.csv` 칸 — 인물·60대 이상·걱정 표정·글자 위치·줄 수·숫자·금액·빨강·경고 낱말·비교·물건
   - 같은 채널 짝도 함께 본다.
2. **본안 = 성공에서 차이가 가장 큰 특징을 모두 합친 것** (예: 재테크 — 걱정·좌절 표정의 실사 인물 + 빨강 손해 낱말).
3. **실험안 2개 = 성공 자료에 적거나 없는 것, 또는 사용자가 시험하고 싶은 것.** 실험안마다 본안과 **한 가지만** 다르게 한다.
   - 예: 한 사람 → 부부, 사람 있음 → 없음, 꼬리표 → 은유 장면
   - '시험하는 가설'에 무엇이 다른지 한 줄로 적는다.
4. 다른 주제 결과를 빌려 쓰지 않는다. 자료가 없으면 "근거 없음"으로 적고 실험안으로만 쓴다.

     `https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/main/<주제폴더>/source/<영상ID>/thumbnails/chatgpt.md`
   - 저장소가 비공개면 주소가 안 열린다 → 파일을 대화창에 끌어다 놓으라고 안내한다.
2. 크기(16:9, 안 되면 가장 넓은 가로형, 가운데 16:9 안·위아래 8% 비움), 한글 그대로(글자·띄어쓰기), 가상 인물, 다른 글자 금지는 **[A] 프롬프트 안에** 쓴다 (6번). 사용자가 메시지에 따로 적지 않아도 되게 한다 (사용자 지시 2026-10-15 "이 내용은 프롬프트에 다 있어야지").
3. 한글이 틀리면 같은 대화에서 "thumbnail_N의 글자를 파일의 문구표와 똑같이 고쳐 줘. 그림은 그대로."라고 한다.
   - 두세 번 해도 틀리면 [B]로 그림만 만들고 캔바·미리캔버스에서 문구표대로 글자를 얹는다.
4. 완성 이미지는 `thumbnail_N.png`로 `<주제폴더>/source/<영상ID>/thumbnails/`에 올린다.
5. 공개 뒤 스튜디오 '테스트 및 비교'에 3장을 넣는다.
   - 이 기능은 **시청 시간 비율**로 이긴 것을 고른다. 결과는 각 파일 '결과' 칸에 적는다.
- 완성 예: `economic/source/eunte-kkeonaeseugi-2026-10/thumbnails/README.md` 5번

## 7. 검수표
- [ ] 하단 2줄이 채택 제목을 줄인 것이고, 남은 말이 제목과 글자 그대로인가
- [ ] 노랑 = 중요한 것, 빨강 = 나쁜 상황만인가
- [ ] 숫자가 제목·대본과 같은가. 대본이 계산하지 않은 금액이 없는가
- [ ] 댓글 니즈 낱말이 그림에 있으면 **낱말 그대로**인가 (물건으로 그리지 않음)
- [ ] 한글이 한 글자도 틀리지 않았는가
- [ ] 320px로 줄여도 읽히는가 · 사람·글자가 가운데 16:9 안인가 · 오른쪽 아래가 비었는가
- [ ] 실존 인물을 닮은 얼굴, 실제 로고·서식·화폐 도안이 없는가
- [ ] 본안 1 + 실험안 2이고, 실험안마다 본안과 한 가지만 다른가
