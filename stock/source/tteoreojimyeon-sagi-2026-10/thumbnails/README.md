## 1. 짝 제목과 그림이 전할 한 가지
- 짝 제목: `titles.md` R1 「저점 매수, 최고점보다 10% 떨어질 때만 매수하면 매달 매수보다 더 벌까? 23년 백테스트」 (10개 언어 모두 같은 뜻).
  - 썸네일에는 글자가 없으므로 언어와 상관없이 한 장이다.
- 그림이 전할 것: **"최고점 아래까지 기다렸다 매수하는 사람과 매달 매수하는 사람 — 누가 더 벌었을까?"**
  - 결과(누가 더 벌었는지)는 그리지 않는다. **닫힌 상자**(빛이 새어 나옴)로 가린다.
  - 두 쪽을 같은 크기·같은 높이로 둔다. 이기거나 진 표정(아쉬움·좌절·뽐냄)을 쓰지 않는다 — 망설임·침착함.
- 색은 영상과 같은 **사람 표시**다 (이긴 쪽·진 쪽의 뜻이 아님): B(기다림) = 빨강 띠·모래시계, A(매달) = 청록 옷·동전 빛, 기준 = 노랑(최고점 별·−10% 점선), 배경 = 짙은 남색.

## 4. 검수 (이미지가 올라오면 — 공통 10번 + 주식)
- 그림 속에 **글자·숫자·기호(물음표 포함)처럼 보이는 것이 하나도 없는가**: 지폐 무늬, 달력 칸, 그래프, 상자 장식을 확대해서 본다.
- **결말이 보이지 않는가**: 두 쪽이 같은 크기·높이인가, 상자는 닫혀 있는가, 어느 인물도 이기거나 진 표정이 아닌가.
- 16:9이고, 얼굴과 중요한 그림이 가운데 16:9 안에 있는가. 오른쪽 아래(영상 길이 표시)를 비웠는가.
- 빨강 = B(현금 띠·모래시계), 청록 = A(옷·동전 빛), 노랑 = 별·점선인가.
- 가로 320px로 줄여도 '기다리는 쪽 vs 매달 넣는 쪽, 가운데 닫힌 상자'가 읽히는가.
