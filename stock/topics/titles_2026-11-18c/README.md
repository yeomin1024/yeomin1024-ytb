### 뺀 것 (검토에서 걸림 — 기록은 `titles.json` status · `titles.persona.json`)
- **M1 「코스피 −40% 4번, 고점에 산 사람 원금까지 1.9~5.5년」** — 3회차 모두 대상 페르소나가 안 누름 (P1 두 번 "나는 나스닥100·S&P 를 사서 코스피는 내 계좌와 멂" · P2 "70대에 5년 반 기다리라는 말로 들려 겁남"). 댓글로 만든 세 페르소나가 모두 배당·ETF·미국 지수 쪽 → **코스피만 다룬 제목은 이 채널 시청자에게 약함** (M3 도 제목에 S&P 500 을 넣고서야 P1 이 누름). 1회차 반론이 짚은 −45% 문턱(2020년 −43.9% 가 빠짐)은 −40% 로 고침.
- **M2 「매달 50만 원 코스피, −20%마다 판 사람 계좌는 절반」** — 게이트는 통과했지만 3회차 반론 지적("−20%에 팔고 전 고점에 되사면 한 번 돌 때마다 지게 짜인 허수아비")이 맞음. 되사는 때를 '판 뒤 바닥에서 +20%'로만 바꿔도 판 사람이 시작 해 5번 모두 더 많음 (`S_rules` — 1997 시작 7.38 vs 7.23억 · 2016 1.38 vs 1.31억). 결론이 규칙에 달려 있어 제목으로 못 씀 + 이긴 쪽은 타이밍 규칙이라 채널 목적(`stock/guides/channel.md` — 타이밍 ✗) 밖.
