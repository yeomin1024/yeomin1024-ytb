## 주제를 고른 이유 (`lifetips/guides/data_insights.md` v1.0)

- 카테고리 "3. 청소(주방·가전·화장실)" 기회점수 **71 (1위)**, 키워드 `세탁기 청소 방법` **80 (1위)** — 소규모 채널 진입 45%, 성공 10개, 배수 중앙 86.85배
- 제목에 세탁기·세탁조·통돌이가 든 영상 **10/10 성공** (롱폼 2/2, 소규모 채널 4/4)
- 벤치마크: 구독자 4,070명 채널의 통돌이 부분 분해 청소 롱폼(4:32, 2025-11-30) **100만 5천 회, 채널 평소의 2,004배** (`result/data/success_cases.csv`)
- 댓글: "저걸 제가 하면 … 고장나서 새 세탁기 할부긁을거 같아요"(좋아요 647), "이거따라하다 고장낫어요.. 가급적 기사님부르세요"(181), "청소한다고 여기저기 풀더니 이젠 탈수할땐 텅텅텅"(40). 질문 단어 세탁기 16·기사 9 (`audience_comments.csv`, `question_terms.csv`)
- 손해 유형: 같은 주제의 다른 기획 2개(heater = 요금, bleach = 몸)와 겹치지 않게 **고장·수리비**

## 기획서와 달라진 점
- 문제 1의 "한 회사 = 염소계 표백제 권장"은 검색으로 확인해 그대로 썼지만, 양(150~300mL)은 대본에서 뺐다.
- 방법 4의 **고무패킹 닦기(치약)는 뺐다** — 원문 미확인 + 통돌이에는 문 패킹이 없다. 대신 확인된 **거름망 비우기**(삼성 안내)를 문제 3·방법 4에 넣었다.
- 방법 5("그래도 직접 분해하고 싶다면": 전원 플러그 등)는 `script_rules.md` 3-6(분해를 권하지 않음)과 근거 미확인 때문에 넷째(직접/맡길 기준)에 합치고, 다섯째는 기획서 문제 (4)의 "맡길 때 보증 조건 묻기"로 썼다.
- 사연에 "월요일 낮"을 넣었다 — 주말 출장이면 할증(3만 3천 원)이라 출장비 2만 8천 원과 맞추기 위해서.
