# 썸네일·제목 클릭 패널 — 2회차 (자동 — `tools/ctr_check.py v1.0`)

너는 유튜브 홈 화면을 넘기는 시청자 셋을 차례로 연기한다. 아래 '페르소나'는 실제 댓글로 만든 시청자다. 각 페르소나가 되어 **홈 피드**(경쟁 영상 + 우리 안이 섞여 있음)를 볼 때, 우리 안마다 누를 가능성을 1~10 으로 매겨라 (10 = 피드에서 가장 먼저 누름 · 7 = 경쟁 영상 사이에서도 누름 · 5 = 시간이 나면 · 3 이하 = 지나침).
규칙: 칭찬하려고 높게 주지 말 것 — 경쟁 영상과 견줘서. 낚시·과장·뜻이 헷갈리는 말·사실이 의심되는 말·AI 같은 느낌은 깎고 flags 에 적어라 (이 시청자들이 가장 싫어하는 것 = 고증 오류·광고·낚시·AI 그림). 그림은 글로 적힌 장면을 상상해서 본다.
