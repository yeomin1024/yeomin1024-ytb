## 클라우드에서 분석 (`tools/cloud_run.py`)

웹 화면(`tools/web_ui.py`)의 작업 함수를 그대로 부르므로 분석·추천(체크)·할당량 계산은 PC 와 같다. 명령 설명은 `stock/README.md` '클라우드에서 분석' (주제 이름만 `history`).

```bash
python3 tools/cloud_run.py history status                       # 할당량·탐색 목록·승인 수·남은 것
python3 tools/cloud_run.py history resume                       # 할당량·하루 검색 횟수 때문에 남은 탐색·댓글·채널 기준선
python3 tools/cloud_run.py history explore --weeks 26           # 롱폼 탐색 (검색어 40개 × 4~20분·20분 넘음 = 80번 ≈ 8,000단위)
python3 tools/cloud_run.py history explore --shorts --weeks 26  # 쇼츠 탐색 (롱폼 탐색이 끝난 뒤 — 40번 ≈ 4,000단위)
python3 tools/cloud_run.py history list --checked               # 새 추천 (이미 분석에 쓴 영상은 숨김)
python3 tools/cloud_run.py history uncheck ID …                 # 역사가 아닌 추천 풀기 (스포츠 '역사를 써'·게임 등)
python3 tools/cloud_run.py history approve                      # 추천 승인 → 설명·자막·썸네일·댓글 → 주별·성공 사례 분석
python3 tools/cloud_run.py history captions                     # 대본 없는 승인 영상의 자막만 다시 (할당량 0)
python3 tools/cloud_run.py history analyze                      # 롱폼·쇼츠 분석 다시 (할당량 0)
python3 tools/tag_keywords.py history --write-keywords          # 검색어를 실제 영상 태그로 다시 고르기 (씨앗 검색 — 할당량)
```

- **매일 이어서**: 예약 작업 **'역사 분석 이어서 (할당량 초기화 뒤 매일)'** `trig_01HMG95DYgQiYDH7NsthAyx9` — 태평양 자정 +20분(한국 16:20, 서머타임 끝나면 17:20)에 이 클라우드 세션을 깨워 resume → explore(롱폼, 끝나면 쇼츠) → 새 추천 훑기·승인 → captions → analyze → main (`guides/status.md` 2-5). 재테크 예약 작업(+15분)과 5분 띄움.
- **캐시**: `history/cloud_cache/cache.tgz` (+ 목록 `cache.json`) = `result/outliers/.cache`(검색·영상 정보·채널·자동완성·쇼츠) + `result/web`(탐색 목록·체크·승인 목록). 명령 뒤 저절로 묶고 새 컨테이너에서 저절로 풂.
- **키**: 이 클라우드 환경 변수 `YOUTUBE_API_KEY` (지문 `58333e86`) — **`new/` 분야 탐색과 같은 키**라 같은 날 `new/` 를 돌리면 하루 10,000단위·하루 검색 횟수를 함께 쓴다. 역사만 다른 키를 쓰려면 환경 변수 `YOUTUBE_API_KEY_HISTORY` (`outlier_research.load_api_key` 가 먼저 읽음).
- ⚠️ **PC 웹 화면에서 역사 탭을 켜지 않는다** — PC 가 자기 `history/result/outliers/` 로 GitHub 것을 통째로 바꿔 클라우드가 받은 사례 폴더(`W_…`)가 지워짐 (`guides/pc_analysis.md` '클라우드에서 돌리기'). 음성인식(PC 만)은 그래서 보류.
- 자막은 클라우드에서 대부분 못 받는다 (YouTube 가 `www.google.com/sorry` 봇 확인으로 돌려보냄 → `ProxyError`, 또는 `RequestBlocked`) — 영상 설명으로 대신 분석 (글 출처 '설명' = 대본 근거로 쓰지 않음).
