## ChatGPT에게 — 이 파일을 읽으면 할 일
0. **이 주소를 지금 새로 열어 그 내용만 쓴다** — 이 대화에서 예전에 읽은 파일·프롬프트가 있어도 쓰지 않는다. 답의 첫 줄에 이 파일 맨 위 '작성' 줄을 그대로 적는다.
1. 아래 1~18번 **18장을 번호 순서대로 모두** 만든다. 질문하지 말고, 한 장을 만든 뒤 멈추지 말고 다음 장으로 넘어간다. 이미지 한도 때문에 멈추면 사용자가 `계속`이라고 보낸다 → 아직 안 만든 번호부터.
2. 프롬프트(``` 안)를 **한 글자도 바꾸지 않고 그대로** 쓰고, 맨 앞에 아래 **공통 화풍** 문단을 그대로 붙인다. **1~14번(소품)**은 그다음 **CUTOUT** 문단도 붙인다. **15~18번(썸네일)**은 CUTOUT 을 붙이지 않는다.
3. **15~18번의 주인공은 시리즈 주인공과 같은 인형**이다 (짧은 검은 머리 · 남색 정장 · 금빛 넥타이 · 어른 비율 · 작은 점 눈). 이 대화에 그 인형 그림이 없으면 위 설명대로 그린다 — 네 장 모두 같은 사람으로.
4. **잘림 검사 (1~14번 필수, 올리기 전에):** 파이썬으로 아래 코드를 돌려 `OK` 가 나와야 올린다. `잘림`이면 더 작게(여백을 더 넓게) 다시 만든다. 투명이 아니면 배경을 **순초록 #00FF00 한 색 평면**으로 다시 만든다.
   ```python
   from PIL import Image
   import numpy as np
   def check(path, margin=0.06):
       a = np.array(Image.open(path).convert("RGBA"))
       h, w = a.shape[:2]
       if a[2, 2, 3] > 0:                       # 투명이 아니면 순초록 바탕을 빈 곳으로 봄
           g = a[:, :, 1].astype(int) - np.maximum(a[:, :, 0], a[:, :, 2]).astype(int)
           filled = ~((g > 80) & (a[:, :, 1] > 150))
       else:
           filled = a[:, :, 3] > 40
       ys, xs = np.where(filled)
       box = (xs.min() / w, ys.min() / h, xs.max() / w, ys.max() / h)
       ok = box[0] >= margin and box[1] >= margin and box[2] <= 1 - margin and box[3] <= 1 - margin
       print(path, "OK" if ok else "잘림 — 더 작게 다시", [round(v, 3) for v in box])
       return ok
   ```
5. **글자·숫자·로고·워터마크를 하나도 넣지 않는다** — 화면·서류·상자·계기판·꼬리표에도 없음. 실제 회사의 물건·로고를 닮게 그리지 않는다. 만든 뒤 확대해 글자가 보이면 다시 만든다.
6. 그림 바로 위에 번호와 저장 경로를 한 줄 적는다 (`1. stock/source/daebi-test-2026-11/puppet/P-VIDEOCALL.png`). 그림 안에는 쓰지 않는다.
7. **다 만들면 저장소에 넣는다 — 저장 경로 그대로.**
   - 저장소 `yeomin1024/yeomin1024-ytb` main 브랜치, 경로는 표의 파일 이름 그대로 (대소문자·하이픈까지 같게).
   - **올리기 전에 700KB 이하로 만든다** — GitHub 앱은 약 768KB 를 넘는 파일을 잘라 올려 그림이 깨진다. 올린 뒤 GitHub 의 파일 크기(바이트)가 내 파일과 같은지 확인하고, 다르면 다시 올린다.
     - 15~18번(JPEG): RGB · 크기 그대로 · 품질 90부터 5씩 낮춰 700KB 아래가 될 때까지 저장.
     - 1~14번(PNG, 투명 유지): 아래 코드 그대로.
       ```python
       from PIL import Image
       import os
       Q = getattr(Image, "Quantize", Image).FASTOCTREE
       def save_png(src, dst, limit=700_000):
           im = Image.open(src).convert("RGBA")
           w, h = im.size
           s = min(1.0, 1400 / max(w, h))
           while True:
               cur = im.resize((round(w * s), round(h * s)), Image.LANCZOS) if s < 1 else im
               cur.save(dst, optimize=True)
               if os.path.getsize(dst) > limit:
                   cur.quantize(colors=256, method=Q).save(dst, optimize=True)   # 256색 (투명 유지)
               if os.path.getsize(dst) <= limit or max(cur.size) <= 800:
                   break
               s *= 0.9
           print(dst, os.path.getsize(dst), cur.size)
       ```
   - **GitHub 앱으로 장마다 커밋한다.** 커밋 메시지: `[stock] <편 폴더> <파일 이름> 이미지` (예: `[stock] daebi-test-2026-11 P-VIDEOCALL.png 이미지`). 다 올리면 올린 파일 경로와 커밋 링크를 목록으로 적는다.
