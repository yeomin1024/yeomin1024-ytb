## 1. 짝 제목과 그림이 전할 한 가지
- 짝 제목: `titles.md` R1 「매수 타이밍, 저점·RSI·200일선 등 매수 신호 10가지 중 1만 달러로 10년 뒤 가장 많이 번 건?」 (10개 언어 모두 같은 뜻).
  - 썸네일에는 글자가 없으므로 언어와 상관없이 한 장이다.
- 그림이 전할 것: **"매수 버튼 10개 — 어느 것을 눌러야 가장 많이 남았을까?"**
  - 결과는 그리지 않는다. 가격 벽 끝의 **닫힌 상자**(빛이 새어 나옴)로 가린다.
  - 버튼 10개는 모두 같은 크기·같은 높이. 어느 버튼도 더 밝거나 크지 않다 (1위를 보여 주지 않음).
  - 사람 표정 = 망설임·집중 (뽐냄·좌절 없음).
- 색 = **영상 화면과 같은 뜻** (이 영상은 A/B 두 사람 비교가 아니라 신호 10가지라서, `README.md` 3번의 빨강 B·청록 A 대신 영상의 색을 그대로 쓴다):
  - 청록-초록 = 주식을 든 동안의 가격 벽 (영상 BUY~SELL 구간) · 주황 = SELL 표시 점 · 노랑 = 기준(별·점선) · 배경 = 짙은 남색.
- 버튼 위 아이콘 10개 = 영상 머리 카드의 아이콘과 같은 모양 (글자·숫자 없이): 빈 달력(매달 첫 거래일) · 깃발(52주 신고가) · 위로 꺾인 화살표(12개월 모멘텀) · 매끈한 노란 선을 위로 넘는 선(200일선) · 엇갈리는 두 선(골든 크로스) · 아래로 꺾인 빨간 화살표(−2% 급락) · 반원 계기판(RSI) · 뾰족한 빨간 산 모양 선(VIX 공포) · 별과 멀리 아래 점선(−20%) · 별과 바로 아래 점선(−10%).

## 3. 분석 근거 (`stock/guides/data_insights.md` 5번)
- 그림·캐릭터(반실사 포함) 성공 23% vs 기준 밖 10% (배수 상위 15 의 40%) → 본안·실험안 ②의 인물을 **반실사 일러스트**로.
- 이미지 수치: 빨강 비율 P 0.58 · 어두운 비율 P 0.61 → **짙은 남색 배경** + 빨강·주황 요소(급락 화살표·VIX 선·SELL 점).
- 같은 채널 짝에서 잘된 쪽 = '대비'. 이 썸네일의 대비 = 빛나는 버튼 10개 vs 어두운 배경, 사람 vs 거대한 가격 벽. 결과를 말하는 하락선·좌절 표정은 쓰지 않는다 (사용자 지시 2026-10-16).
- 한계: 근거는 한국어 작은 채널의 썸네일이다. '글자 없는 썸네일'·'결과를 가린 그림'·'버튼 10개'·'3D 가격 벽'의 근거는 없다 (사용자 지시와 영상 화면에 맞춰 정함).

## 4. 검수 (이미지가 올라오면 — 공통 10번 + 주식)
- 그림 속에 **글자·숫자·기호(물음표·% 포함)처럼 보이는 것이 하나도 없는가**: 버튼 표면, 달력 칸, 계기판 눈금, 가격 벽 주변, 상자 장식을 확대해서 본다.
- **결말이 보이지 않는가**: 버튼 10개가 같은 크기·밝기, 상자는 닫혀 있음, 사람 표정이 망설임(웃음·좌절 아님).
- 16:9, 얼굴과 중요한 그림이 가운데 16:9 안, 오른쪽 아래(영상 길이 표시) 비움.
- 색: 청록-초록 = 가격 벽, 주황 = 벽 위 점, 노랑 = 별·점선.
- 가로 320px로 줄여도 '버튼 10개 앞에서 고르는 사람, 오르는 가격 벽, 끝의 닫힌 상자'가 읽히는가.
