## 2. 문구를 어떻게 줄였나
- 짝 제목 R1: 「은퇴 부부 배당·이자 한 사람이 받으면 건보료 월 26만 원 손해」 (36자)
- 뺀 말: '은퇴 부부' — 본안은 그림이 부부를 보여 주고, 시청자층은 '50·60대'가 맡는다 (실험안 ①(남편 한 사람)·②(사람 없음)는 그림에 부부가 없어 '부부' 없이도 읽히는지 함께 본다).
- **더한 말: '50·60대'** (시청자층, 피드백 13):
  - 이 영상은 **50대 후반 시청자 편** — 나이를 밝힌 댓글(엄격 751개)에서 50대가 배당·ETF를 가장 많이 말함 11% (60대 10% · 70대 0%) — `economic/source/topic_candidates.md` '나이대별로 말하는 것'.
  - 예시 부부도 58세.
- 남은 말은 제목과 글자 그대로 ('배당·이자 한 사람이 받으면' · '건보료 월 26만 원 손해').
- 폭 (2026-10-18 `video/public/fonts/NotoSansKR-900.ttf` 로 잼, 1280 기준 72px): 1줄 1,124px (x 48~1,172, 가로 92% — 오른쪽 끝에서 8% 남음) · 2줄 684px (x 48~732, 가로 57% — 구석 칸 x 1,060·가로 80% = 1,024 앞).
- 사실 확인 (대본 `geumyung-soduk-2026-10.txt` v1.0, `calc/calc.py` v1.0):
  - '건보료 월 26만 원' = A 부부(6억 원을 남편 한 사람 이름 일반 계좌에, 1년 2,400만 원)가 피부양자에서 빠져 내는 지역 보험료 267,739원 (이자·배당 143,800 + 집 123,939, 장기요양 제외 — 문장 3·32~36). '26만 원이 넘는' 쪽으로 내려 잡음.
  - '손해' = 같은 돈을 부부가 나눈 B 부부는 0원이라서 (문장 3·37·38).
  - 조건: 직장인 자녀의 피부양자였던 부부, 집 과세표준 3억 원 (2억이면 23.7만 · 4억이면 28.8만 — calc 7번). 제목·대본도 같은 숫자를 쓴다.

```

https://raw.githubusercontent.com/yeomin1024/yeomin1024-ytb/<커밋>/economic/thumbnails_chatgpt.md
```
- 이 영상만: 주소를 `economic/source/geumyung-soduk-2026-10/thumbnails/chatgpt.md` 로 (`python tools/make_summary.py --chatgpt economic geumyung-soduk-2026-10` 이 만듦 — 직접 고치지 않음).
