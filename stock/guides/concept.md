# 주식 채널 컨셉 — AI가 코드로 가설을 백테스트해 검증한다

버전: v1.0 — 2026-10-15 — 최초. 사용자 지시: "주식 채널 컨셉은 ai로 코드 만들어서 가설을 백테스트해서 검증해보는거니까 고려해서 주제 4가지 정해봐".

- 주식(`stock/`) 영상은 모두 이 컨셉을 따른다. 공통 지시사항(`guides/topic_guide.md`·`title_guide.md`·`script_guide.md`·`video_guide.md`)에 이 문서를 더해 읽는다.
- 주제 후보와 근거: `stock/source/topic_candidates.md`.
- ※ 연구·교육용이다. 투자 권유가 아니다. 과거 결과는 미래를 보장하지 않는다.

## 1. 한 편의 모양

1. **가설**
   - 시청자가 묻거나 믿는 말을 그대로 가져온다.
   - 근거는 성공 사례 댓글 원문, 또는 잘된 영상 제목의 주장이다 (예: "원금 안 깎여요").
2. **어떻게 확인했나**
   - 자료(출처·기간)와 규칙(언제 사고 언제 파나)을 말한다.
   - 비용(보수·세금·환율)을 넣었는지 말한다.
   - 화면에는 AI가 짠 코드 몇 줄을 보여 준다.
3. **결과**
   - 코드가 낸 숫자와 차트로 보여 준다.
   - 여러 시작 시점의 결과를 '○번 중 △번'으로 말한다.
4. **왜 그런가**: 상품이나 시장의 구조로 설명한다. 이것이 오래가는 원칙이다.
5. **그래서 할 일**: 숫자로 차이가 보이는 구체적 행동 하나 (topic_guide 0번 4).
6. **한계**
   - 과거 자료라는 점, 빠진 비용, 자료가 짧은 상품을 말한다.
   - 개별 종목·상품 추천이 아니라는 점을 말한다.

## 2. 백테스트 규칙 — 숫자를 믿을 수 있게

| 규칙 | 내용 |
|---|---|
| 결론은 결과 뒤에 | 결과를 보기 전에 결론을 정하지 않는다. 예상과 다르면 그대로 말한다 (그것도 영상이 된다) |
| 숫자는 코드 출력만 | 대본·화면의 숫자는 모두 백테스트 코드가 낸 결과 파일에서 가져온다. 손으로 고치지 않는다 |
| 미래 정보 금지 | t 시점 결정은 t 시점까지 알 수 있는 값만 쓴다. 월말 가격으로 정하면 다음 달에 산다 |
| 총수익 | 배당·분배금을 넣는다 (수정주가 또는 가격 + 분배금). 가격만 쓰면 '가격만'이라고 말한다 |
| 비용 | 보수·매매 수수료·세금·환율을 넣었는지 하나씩 적는다. 못 넣은 것은 한계에 적는다 |
| 여러 시작 시점 | 시작 시점 하나의 결과로 결론을 내지 않는다. 굴리는 기간(예: 10년·20년)을 매달 시작해 '몇 번 중 몇 번'을 센다 |
| 생존 편향 | 지금 남아 있는 상품·종목만 쓰면 결과가 좋게 나온다 → 지수·오래된 ETF를 먼저 쓰고, 한계에 적는다 |
| 만든 자료 | 상품이 없던 기간을 만들어 쓸 때(예: 레버리지 배수)는 실제 상품 기간과 맞춰 보고 차이를 적는다 |
| 재현 | 무작위가 있으면 시드를 고정해 결과에 적는다. 자료는 받은 날짜·행 수·빠진 값과 함께 저장한다 |
| 로그 | 단계마다 `[STAGE] 시각 key=value` 를 남긴다 (자료 받기 → 지표 → 신호 → 사고팔기 → 결과) |

## 3. 파일 위치

- 영상마다: `stock/source/<영상ID>/backtest/`
  - 코드, 결과(`results.json`·표 csv), 실행 로그
  - 대본 숫자 근거는 `README.md`의 '숫자 근거'에서 이 결과를 가리킨다.
- 공통 백테스트 코드: `tools/backtest/` (만들 차례 — `guides/status.md` 다음 할 일)
- 받은 가격 자료: `stock/data/` 에 캐시 (같은 자료를 다시 받지 않음, 받은 날짜 기록)

## 4. 자료 길 (2026-10-15 확인)

**클라우드에서 받아지는 것**
- GitHub raw (`raw.githubusercontent.com`)
  - 예: `datasets/s-and-p-500` — S&P500 월별 가격·배당·CPI·금리, 1871~
  - 최근 몇 달은 배당이 0으로 비어 있다 → 마지막 값으로 채우거나 그 달을 뺀다.

**클라우드에서 막힌 것**
- 막힌 곳:
  - Yahoo Finance (`query1/query2.finance.yahoo.com`)
  - Stooq, FRED (`fred.stlouisfed.org`)
  - KRX, 한국은행 ECOS, law.go.kr
- 쓰는 길 둘:
  - (a) 사용자가 클라우드 환경 설정 'Network access'에 도메인을 더한다.
  - (b) PC 에서 받은 자료를 `stock/data/` 로 올린다.

## 5. 하지 않는 것

- 개별 종목 추천, 매수·매도 시점 예언.
- 시작 시점 하나의 극단 결과만 제목에 쓰는 것.
  - 쓸 때는 대본에서 '여러 시작 시점' 결과를 함께 말한다.
- 결과에 맞춰 규칙을 여러 번 바꿔 가장 좋은 것만 보여 주는 것 (과최적화).
  - 규칙은 가설에서 정하고, 바꾸면 바꾼 것을 말한다.
