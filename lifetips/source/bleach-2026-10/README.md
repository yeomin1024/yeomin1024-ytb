## 주제를 고른 이유 (분석 숫자, `lifetips/guides/data_insights.md` v1.0)
- 키워드 `화장실 청소 꿀팁` 기회점수 61, 검색 상위 일평균 조회 **1.8천 회로 수집 키워드 중 수요 1위**

- 질문 댓글 단어 **곰팡이 13·락스 13**·세제 12·욕실 8. 경험 댓글 "락스 원액 … 팍팍 뿌렸는데 … 눈물 콧물 헛구역질함"(좋아요 79), "5일 정도 머리가 깨질 듯이 아팠음"(57) (`result/data/audience_comments.csv`)

- **제주 사고 50ppm·"허용농도 1ppm의 50배"**: 측정 시점이 보도마다 다르고(사고 1시간 40분 뒤 / 2시간여 뒤 / 소방 1차 측정에서 측정 최고치), 1ppm 기준 원문을 찾지 못함
- **염소계 표백제 라벨 문구 원문**("산성 세제나 주방 세제 등과 혼합하여 사용하지 마십시오…", 세계일보 2025 인용): 실제 제품 라벨 원문을 확인하지 못함 → 대본에서는 "통 뒷면 주의사항을 먼저 확인하라"고만 하고 문구를 인용하지 않음
- **국립환경과학원 "습도 60% 이상 집 곰팡이 2.7배"**: 기관 원문을 찾지 못함 (같은 2.7배가 다른 기관의 장마철 세균 연구에도 있어 혼동 위험) → 미국 환경보호청 30~60%로 대체
- **미국 CDC MMWR 사례 "몇 시간 관찰 뒤 퇴원"**: 이번에 원문 문장을 다시 확인하지 못함 → 대본에 쓰지 않음 (검산 참고에서도 뺌)
- **서울시 희석 비율(가정용 락스 20mL + 찬물 1L)**: 소독용 기준이고, 안전 규칙상 비율을 말하지 않음 → "표시사항에 적힌 비율대로"
- **원액·뜨거운 물 경고**: 제품 표시사항 원문을 확인하지 못해 쓰지 않음 (기획서 문제 4번 선택 항목 제외)
- 한국소비자원 2011년 락스 사고 126건 분석(2009~2011 자료): 2000년대 자료라 쓰지 않음
- 미국 독극물센터 "산성 제품과 표백제 혼합 4,800건": 원 보고서를 확인하지 못함, 조합을 알려 주게 됨

## 기획서와 달라진 점
- MMWR 숫자 해석: 기획서는 "세정제 20.4%, 소독제 16.4%"로 적었지만 원문은 **세정제+소독제 전체 상담이 2019년보다 20.4%(2018년보다 16.4%)** 늘었다는 뜻이다. 62.1%는 **세정제 분류 안에서 늘어난 몫** 중 표백제 비율이다 → 대본 문장 21~23을 그 뜻대로 씀
- 제주 사고의 50ppm·허용농도는 뺐다 (위). 원인은 제주도 발표(오주입)로 씀
- 세계일보 라벨 문구, 습도 2.7배는 확인하지 못해 뺐다. 대신 미국 환경보호청 안내 2건(곰팡이 청소에 표백제를 늘 쓰지 않음·습도 30~60%·24~48시간·환기)을 새로 확인해 넣었다
- 서울시 가정 소독 안내는 2020년이 아니라 **2021년** 미디어허브 글로 확인
- 문제 분석은 3개(섞기 / 닫힌 욕실에서 뿌리기 / 더 독하게 해도 끝나지 않음), 방법 5개. 기획서의 선택 항목(원액·뜨거운 물)은 근거를 확인하지 못해 뺐다
- 사연: 분량과 "응급실 4시간을 1분 안에" 때문에 "산소 치료" 표현을 빼고 "응급실에서 4시간을 보낸 뒤에야 집에 돌아왔어요"로 줄였다. 사연 ⑥은 "통 뒷면 문구"를 인용하지 않고 "두 세정제가 섞이면서 자극적인 기체가 생긴 거였어요"로 썼다
- 제목 T1 뒤 구절 "화장실 곰팡이 혼자 잡던" → "화장실 곰팡이 잡던"(65자), T2·T3은 새로 다듬음 (`titles.md`)
