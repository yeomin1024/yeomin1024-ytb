1. 아래 1~8번 **8장을 번호 순서대로 모두** 만든다. '있음'이라고 적힌 그림은 만들지도 올리지도 않는다. 질문하지 말고, 한 장을 만든 뒤 멈추지 말고 다음 장으로 넘어간다. **한 장에 프롬프트에 적힌 것만** 그린다 (다른 사람·물건을 같이 그리지 않는다).

2. 프롬프트(``` 안)를 **한 글자도 바꾸지 않고 그대로** 쓴다.
   - **1~8번 모두:** 프롬프트 맨 앞에 아래 **공통 화풍** 문단을 그대로 붙이고, 그다음 **주인공** 문단을 그대로 붙인다. 1번 기준표와 머리·몸 비율·눈·눈썹·넥타이를 똑같이 맞춘다.

3. 사람 인형은 실존 인물이나 만화 캐릭터를 닮게 그리지 않는다 (특히 흰 강아지·유명 캐릭터처럼 보이면 안 된다 — 단순한 흰 종이 사람). 휴대전화·클립보드는 실제 회사 모양·색·로고를 닮게 그리지 않는다.
4. **잘림 검사 (2~7번 필수, 올리기 전에):** 파이썬으로 아래 코드를 돌려 `OK` 가 나와야 올린다. `잘림`이면 그림을 더 작게(여백을 더 넓게) 다시 만들고 다시 검사한다. 투명이 아니면(귀퉁이 알파가 0 이 아님) 배경을 **순초록 #00FF00 한 색 평면**으로 다시 만든다 (그때는 초록 바탕 기준으로 여백을 본다).
   ```python
   from PIL import Image
   import numpy as np
   def check(path, margin=0.06):
       a = np.array(Image.open(path).convert("RGBA"))
       h, w = a.shape[:2]
       if a[2, 2, 3] > 0:                       # 투명이 아니면 순초록 바탕을 빈 곳으로 봄
           g = a[:, :, 1].astype(int) - np.maximum(a[:, :, 0], a[:, :, 2]).astype(int)
           filled = ~((g > 80) & (a[:, :, 1] > 150))
       else:
           filled = a[:, :, 3] > 40
       ys, xs = np.where(filled)
       box = (xs.min() / w, ys.min() / h, xs.max() / w, ys.max() / h)
       ok = box[0] >= margin and box[1] >= margin and box[2] <= 1 - margin and box[3] <= 1 - margin
       print(path, "OK" if ok else "잘림 — 더 작게 다시", [round(v, 3) for v in box])
       return ok
   ```
5. **8장 모두 글자·숫자·로고·워터마크를 하나도 넣지 않는다** — 휴대전화 화면·클립보드에도 없음 (빈 칸, 단색, 또는 뜻 없는 가는 줄로). 만든 뒤 그림을 확대해 글자·숫자·로고처럼 보이는 것이 하나라도 있으면 다시 만든다.

       ```python
       from PIL import Image
       import os
       Q = getattr(Image, "Quantize", Image).FASTOCTREE
       def save_png(src, dst, limit=700_000):
           im = Image.open(src).convert("RGBA")
           w, h = im.size
           s = min(1.0, 1400 / max(w, h))
           while True:
               cur = im.resize((round(w * s), round(h * s)), Image.LANCZOS) if s < 1 else im
               cur.save(dst, optimize=True)
               if os.path.getsize(dst) > limit:
                   cur.quantize(colors=256, method=Q).save(dst, optimize=True)   # 256색 (투명 유지)
               if os.path.getsize(dst) <= limit or max(cur.size) <= 800:
                   break
               s *= 0.9
           print(dst, os.path.getsize(dst), cur.size)
       ```
