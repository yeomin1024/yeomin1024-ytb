# 우주 주제 폴더 (`space/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **우주에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 과학 정보 제공용 콘텐츠다. 사연은 실제 발표와 보도를 바탕으로 재구성한 이야기이며, 실존 인물(우주비행사·연구원·피해자)을 흉내 내지 않는다.

분석 결과(`result/`, 실행 2026-10-11)로 규칙을 처음 만들었다 (`guides/data_insights.md` v1.0). 2026-10-12에 작은 채널·최근 성공 사례 23개와 댓글 2,078개의 시청자 니즈로 근거를 다시 썼다 (v2.0, 사용자 지시). 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).

## 분석 돌리기
```
bash tools/run_analysis.sh space          # 클라우드 (남은 키워드 35개 이어서 수집, 받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config space/analyzer_config.toml   # PC (자동완성·자막·썸네일까지)
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 6번 "갱신 방법"으로 근거 숫자를 갱신한다. 최근 사례 수집은 `python3 tools/outlier_research.py space` (YouTube Data API 키 필요).
