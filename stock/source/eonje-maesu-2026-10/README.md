- **성공 = 산 값보다 +5% 종가가 −5% 종가보다 먼저** (반대면 실패) → 그날 판정, 다음 거래일 종가에 매도. 들고 있는 동안 새로 사지 않음, 매도한 다음 신호에 다시 매수. SPY 2016-01-04~2026-10-15 · 수수료 0.25%.
- 왜 ±5%: 방법마다 10년 39~70번 판정 (↻ 84번) (±10% 는 20~26번뿐, ±3% 는 수수료 왕복 0.5% 가 폭의 1/6). 판정까지 평균 19~37 거래일.
