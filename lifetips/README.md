# 생활꿀팁 주제 폴더 (`lifetips/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **생활꿀팁에만 해당하는 것**만 둔다. 구조는 `stock/`·`health/`와 같다.
※ 생활 정보 제공용 콘텐츠다. 특정 제품·업체를 추천하지 않고, 제품마다 다른 사용법은 제조사 사용설명서를 우선한다.

분석 결과(`result/`, 실행 2026-10-11)로 규칙을 만들었다 (`guides/data_insights.md` v1.0). 제작을 진행한다 (사용자 지시 2026-10-11: 주제마다 최대 3개, 오디오 전까지).

## 영상 제작 현황

| 영상ID | 제목 방향 | 상태 |
|---|---|---|
| `washer-2026-10` | 업체비 12만 원 아끼려고 세탁기를 직접 분해했다가 수리비 21만 원 (세탁기·세탁조 청소) | 기획 |
| `heater-2026-10` | 보일러보다 싸다는 말에 온풍기만 틀었다가 전기요금 2만 원이 13만 원 (난방비·누진제) | 기획 |
| `bleach-2026-10` | 1분이면 녹는다는 말에 락스에 세정제까지 뿌렸다가 응급실 4시간 (화장실 곰팡이·락스) | 기획 |

## 분석 다시 돌리기
```
bash tools/run_analysis.sh lifetips          # 클라우드 (받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config lifetips/analyzer_config.toml    # PC
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.

> 2026-10-11 실행은 키워드 48개 중 13개만 수집됐다 (5개 주제가 하루 쿼터를 나눠 씀). 자동완성 수요·성공사례 대본·썸네일 이미지는 클라우드 네트워크 정책으로 받지 못했다.
