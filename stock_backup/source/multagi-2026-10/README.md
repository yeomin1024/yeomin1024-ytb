- 다섯째는 7문장이라 보강 규칙의 "3~6문장"보다 1문장 길다. 넷째(8문장)와 비슷하다. 50자 제한 때문에 S&P 500 문장을 둘로 나눴다.

## 지시사항 적용 메모

- 사용자 초안이 없어서 처음부터 작성했다. 항목 수는 문제 분석 4개, 올바른 방법 5개다 (v1.1까지 4개).
- 사연 비트 ③은 손실형 주제라서 "초기 작은 손실 → 물타기 → 기대감"으로 썼다. (대본 지시사항 2-1)
- 인사는 넣지 않았다. (대본 지시사항 0-1의 2번, v1.5)
- ⑦ 한탄은 물타기 내용에 맞춰 새로 썼다. (대본 지시사항 2-1, v1.5)
- 투자 유의 사항 카드는 4가지 요소를 모두 넣었다. (대본 지시사항 0-1의 6번)
- 50자를 넘는 자막 문장은 없다. 고지 카드 문구는 자막에서 뺐다.
