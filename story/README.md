# 사연을 통한 교훈 주제 폴더 (`story/`)

공통 지시사항은 저장소 최상위 `guides/`에 있고, 이 폴더에는 **사연·교훈 주제에만 해당하는 것**만 둔다. 구조는 `stock/`과 같다.
※ 가족·돈·관계 사연(재구성)으로 법·제도와 통계를 알려 주는 콘텐츠다. 법률 자문을 대신하지 않는다.

분석 결과(2026-10-11, 키워드 48개 중 13개 수집)가 나와 보류를 풀었다. 남은 키워드는 다음 분석 실행에서 수집한다.

| 위치 | 내용 |
|---|---|
| `analyzer_config.toml` | 분석기 설정: 검색어 48개(가족 갈등 / 돈·배신·결혼 후회 / 인생 후회 / 인간관계 / 사연 포맷 / 사이다·감동), 관련어·제외어 |
| `result/` | 분석 결과 (실행 20261011_120652 — 직접 고치지 않음) |
| `guides/data_insights.md` | 분석 결과를 지시사항용으로 요약: 대량 생산형(사이다·모음) 롱폼 7% vs 나머지 68%, 노후·며느리 소재, 제목 요소, 목표 분량 근거 (자막·썸네일은 주식 결과 임시 차용) |
| `guides/script_rules.md` | 사연 대본 규칙: 50~70대 시청자, 재구성·여성 사연자, 사연 규모, 고지 카드 "법률 자문이 아닙니다", 출처 규칙, 분량 10~13분, 마무리 인사, 근거 자료 은행 |
| `guides/title_rules.md` | 사연 제목 규칙: 상시 고민 목록, 숫자는 기간·나이 위주(앞 구절 2개까지), 금지 단어(사이다·참교육·실화 등), 말줄임 변형 시험 |
| `guides/thumbnail_rules.md` | 사연 썸네일 규칙: 색 의미, 가상 여성 사연자, 시아버지·며느리 연애 암시 금지, 실제 서식·로고 금지, 소품 |
| `guides/upload_rules.md` | 사연 업로드 규칙: 설명란 재구성·고지·출처, 태그 후보, 법률 질문·개인정보 댓글 응대 |
| `voices/storyteller.json` | 사연자 말투 덮어쓰기 (가족·돈 고백 — 화자는 공통 Sohee). 진행자는 공통 `voices/host.json` 그대로 |
| `source/used_content.md` | 이전 대본과의 중복 방지 목록 (영상 3개 기획 배정) |

## 분석 돌리기
```
bash tools/run_analysis.sh story                                # 클라우드 (남은 키워드 35개 이어서 수집, 받은 검색은 7일 캐시)
python youtube_topic_analyzer.py --config story/analyzer_config.toml   # PC (자막·썸네일까지 받아짐)
```
→ `result/`가 새 결과로 바뀌면 `guides/data_insights.md` 9번 절차로 근거 숫자를 갱신한다.
