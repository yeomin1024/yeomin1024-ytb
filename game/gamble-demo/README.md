## 1. 해 보기 (PC)

1. Godot 4.7 이상(표준판, .NET 아님)을 받습니다 — https://godotengine.org/download
2. Godot 를 열고 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → **실행(F5)**
3. 글자가 □ 로 보이면: 프로젝트 설정 → GUI → 테마 → 사용자 지정 글꼴에 한글 글꼴(예: Noto Sans KR)을 넣습니다
4. 처음 뜨는 **게임 준비** 창에서 책상 위 물건 3자리를 고르고 **시작** (라이터·담뱃갑은 반사경이 든 것과 빈 것이 겉모양이 같음)

### 한 턴 = 왕 턴 → 노예 턴 → 판단 시간 → 공개 (차례마다 30초)
| 차례 | 화면 | 왕 (방어) | 노예 (공격) |
|---|---|---|---|
| **왕 턴** | 고르는 쪽(왕)은 **내 테이블**, 상대는 **상대 테이블** | 카드만 고름 — **방어 못 함** | 상대가 안 볼 때 **협력자 부르기**(2.5초 누르고 있기) · 시선 끌기 · 라이터 놓기 |
| **노예 턴** | 노예 = 내 테이블, 왕 = 상대 테이블 | 낸 뒤 방어: **가리기**(칩 → 반사경 막기) · **섞기**(낸 카드를 안 보고 섞음 → 반사경·이어폰 막기, 나도 모름) · **바꿔치기**(엿보면 가짜) · **물건 클릭 = 물건 확인** · **상대 클릭 = 몸 수색** | 반사경 물건을 **1.5초** 계속 보면 상대 카드 · 이어폰이 연결돼 있으면 **3초 뒤** 카드를 알려 줌 · 카드 클릭으로 냄 |
| **판단 시간** | 왕 = 상대 테이블 | 노예가 낸 뒤 **5초** — 물건 확인·몸 수색 · '판단 끝 · 공개' | 기다림 (AI 왕은 1.2초) |

- **상대 시선 = 불빛**: 상대가 보는 자리가 밝아짐. 나를 보면 화면 가장자리가 붉게 + "상대가 당신을 보는 중".
- **게이지와 '!'**: 노예 시선이 물건에 머물면 그 물건에 고리 게이지가 참 (떼면 처음부터). 1.5초가 다 차면 **'!'** — 진짜(반사경)든 미끼(빈 것)든 똑같이 뜸. 시선 끌기 3초 동안엔 상대에게 안 보임('안 들킴').
- **협력자 (원격)**: 현장에 오지 않고 이어폰으로 상대 카드를 알려 줌. **부르기 = '협력자 부르기'(키 2)를 2.5초 누르고 있기**(귀 만지기 신호) — 중간에 떼면 실패(횟수는 씀). 그동안 상대가 나를 보고 있으면 **협력자 가능성 %** 가 오름. 연결되면 그 판 동안 내 노예 턴마다 3초 뒤 카드.
- **밝혀내기**: 물건 확인 = 그 물건에 반사경이 있으면 적중 (이번 턴에 썼는지와 관계없이, 장치가 증거) / 몸 수색 = 이어폰(연결·부르는 중)이 있으면 적중.
  - **적중**: 노예 경고 +1 · 그 속임수 봉인(반사경 물건·이어폰 압수) · **그 턴 무효 → 둘 다 다시 고름** · 노예가 다시 고르는 턴 −10초.
  - **헛짚음**: 왕의 다음 차례 −10초 · 확인한 빈 물건엔 '빈 것 (확인됨)'.
  - **경고 2개 = 즉시 패배.**
- 상대가 숨긴 것(바꿔치기·상대가 얻은 정보·이어폰 연결 여부)은 공개 전엔 안 보여 줌 — 협력자 가능성 %와 '!' 만 단서.

### 행동 횟수 (매치당, 시뮬레이션으로 정함)
| 노예 (공격) | 횟수 | 왕 (방어) | 횟수 |
|---|---|---|---|
| 라이터 놓기 (게임 중) | 2 | 가리기 | 3 |
| 협력자 부르기 (시도) | 2 | 섞기 | 2 |
| 시선 끌기 | 1 | 바꿔치기 | 2 |
| | | 물건 확인 (턴마다 1번) | 3 |
| | | 몸 수색 (턴마다 1번) | 2 |

### 화면 보는 법
| 자리 | 무엇 |
|---|---|
| 왼쪽 위 **점수판** | 몇 판째 · 점수 · **당신 역할** · 경고 ●○ · '다음 내 차례 −10초' |
| 가운데 위 **지금 할 일** | 큰 글씨 한 줄 + 도움말 + **시간 막대** (내 차례 노랑, 5초 아래 빨강) |
| 왼쪽 **행동 버튼** | 지금 역할 것만 크게 · 아랫줄 = 효과·남은 횟수 / 못 쓸 땐 까닭('카드를 낸 뒤에만' 등) · '!'·협력자 가능성이 있으면 밝혀내기 버튼이 깜빡 |
| 오른쪽 **의심 표시** | 내가 왕: 상대 '!' 수 · 협력자 가능성 % · 남은 확인·수색 / 내가 노예: 상대에게 보인 '!' · 상대가 느낀 협력자 가능성 · 이어폰 상태(부르는 중이면 진행 막대) |
| 왼쪽 아래 **알림** | 일이 생기면 잠깐 (초록 좋음 · 빨강 나쁨 · 노랑 주의) |
| **턴 결과 창** | 공개되면: 이겼다/졌다 · 두 카드 · 점수 · 이번 턴에 있었던 일 · 다음 ▶ |

- 마우스 = 내 시선. 내 테이블에선 **위쪽 = 상대를 봄**(상대의 수상한 행동이 보임), 상대 테이블에선 상대 얼굴·몸을 보면 '주시'.
- 버튼·설정·의심 표시 위에 마우스가 있는 동안엔 시선이 마지막 자리 그대로 (엿보다 버튼을 눌러도 안 끊김).
- 단축키: 노예 1 반사경 라이터 · 3 빈 라이터 · **2 (누르고 있기) 협력자 부르기** · F 시선 끌기 / 왕 C 가리기 · R 섞기 · X 바꿔치기 · Q 물건 확인(물건 위에서 누르거나, 누른 뒤 물건 클릭) · W 몸 수색 · Enter 판단 끝·다음 / H 규칙 (보는 동안 시간 멈춤).

### 규칙 한 장
- 왕 > 시민 > 암살자 > 왕, 시민끼리는 비김. 패 = 시민 4 + 특수 카드 1. 판마다 진영을 바꿈 (1·3·5판 = 당신 왕 측).
- 판 점수: 왕 측 승 +1 · 암살자 측 승 +4. 6판, 동점이면 연장 최대 2판(진영은 동전).
- 차례마다 30초 (밝혀내기로 −10초, 최소 5초) · 넘으면 남은 카드 중 아무거나.

## 2. 시험·시뮬레이션 (화면 없이)

저장소 맨 위에서 (Godot 실행 파일 이름이 `godot` 가 아니면 그 이름으로):

```bash
godot --headless --path game/gamble-demo --script res://tests/run_tests.gd
```

```bash
godot --headless --path game/gamble-demo --script res://tools/simulate.gd -- --matches=1000 --seed=42
```

- `run_tests.gd` 20묶음: 규칙표 · 왕 턴 → 노예 턴 → 판단 → 공개(30초) · **고르는 중엔 방어 못 함** · 물건(사전 3개·게임 중 2번) · **게이지(1.5초 계속, 떼면 처음부터)·'!'** · 미끼도 '!' · **협력자 부르기(보면 가능성 ↑, 안 보면 0, 멈추면 실패)·이어폰 3초** · **물건 확인(반사경 적중 → 압수·봉인·그 턴 무효·−10초 / 빈 것 헛짚음)** · **몸 수색** · 가리기·섞기·바꿔치기 · 시선 끌기('!' 안 뜸) · AI 판단 · 경고 2개 패배 · 판단 시간 · 버튼 활성 = 실제 규칙 · AI 가 숨은 카드를 몰래 읽지 않음 · 시간 초과 · 연장 · 같은 시드 = 같은 매치 · 100 매치 점검.
- `simulate.gd`: 자리 0·1 모두 AI. 조합마다 승률 · 정보(반사경·이어폰·가짜) · 들킴 · 두 번 들켜 짐 · '!'·미끼 · 부르기·연결 · 물건 확인·몸 수색 적중률 · 무효 턴 · 방어 수.

## 3. 구조

```
core/            규칙 — 노드에 의존하지 않음 (시험·나중 서버 공용)
  rank_cards.gd    카드 규칙 · 공정 플레이 기준 확률
  cheat_rules.gd   턴 30초 · 머묾 1.5초 · 부르기 2.5초·이어폰 3초·가능성 속도 · −10초 · 행동 횟수 · 물건(반사경·겉모양)
  ai_brain.gd      AI 성격(노예: 엿보기·미끼·부르기·시선 끌기 / 왕: 가리기·섞기·바꿔치기·물건 확인·몸 수색) · 시선 · 카드 · 의심
  match.gd         실시간 매치: tick · set_objects · place_object · start_call/stop_call · attention · cover · play_random · fake · inspect · search · judge_done · commit · next · why_not · dwell_progress · 이벤트
  game_log.gd      [STAGE] [t=…ms] key=value 로그, 수준 조절
scenes/main.gd        화면 연결 · 화면 전환(내 테이블/상대 테이블) · 점수판 · 지금 할 일·시간 막대 · 행동 버튼 · 의심 표시 · 알림 · 턴 결과 창 · 규칙 창
scenes/table_view.gd  두 테이블 그리기 (상대·눈동자·불빛·물건·게이지·'!'·카드·엿본 카드) + 시선 영역 · 클릭 대상
tests/run_tests.gd  tools/simulate.gd
```

튜닝: `core/cheat_rules.gd`(시간·횟수·속도) · `core/ai_brain.gd`(성격 묶음 `configure` · `CAUTION`) 값만 바꾸고 `simulate.gd` 로 확인.

### 로그 (Godot 출력 창)
`[MATCH] event=setup` → `[SETUP]` → `[DEAL]` → `[TURN]`(replay=true 면 무효 뒤 다시 고름) → `[PHASE]` → `[CALL]`(start/cancel/connected · 가능성) · `[OBJECT]` · `[ATTENTION]` · `[COVER]` · `[RANDOM]` · `[FAKE]` → `[MARK]`('!') · `[INFO]`(반사경/이어폰 · 가짜 여부) → `[COMMIT]` → `[JUDGE]` → `[EXPOSE]`(inspect/search · 적중 · 경고 · 시간) → `[VOID]` → `[REVEAL]` → `[ROUND]` → `[MATCH] event=end`. `[GAZE]`·`[SUSPECT]` 는 DEBUG, 거절은 `[REFUSE]`, 시간 초과는 `[TIMEOUT]`.

## 4. AI 의 공정성 규칙
- AI 는 상대 카드를 반사경·이어폰으로 '보인 카드'(바꿔치기면 가짜)로만 압니다 (`info["opp_card"]`, 시험 `ai_ignores_hidden_card`).
- AI 가 보는 것 = 공개 정보뿐: 당신의 시선(마우스)·'!'·협력자 가능성·책상 위 물건(반사경 여부는 확인 전엔 모름)·판 결과.
- 같은 시드면 같은 매치 (시드는 `[MATCH] event=setup seed=…`).
