# 자기계발 채널 설명 — 0에서 시작하는 30대의 목표 달성 브이로그

VERSION: v1.0 — 2026-11-27 — 최초 (사용자 지시 2026-11-27 "아무것도 없는 30대인 나 자신이 목표를 이뤄나가는 브이로그 형식의 자기계발 유튜브 채널 운영할 건데 타깃은 나와 비슷하고 성장해나가고 싶은 사람이야")

> ⚖️ 아래 '전달 방식'·'원칙'은 분석 전 Claude 판단(가설)이다. 성공 사례 분석·구글 트렌드 결과가 나오면 숫자로 다시 고친다.

## 1. 한 줄 설명
**가진 것 없는 30대가 목표 하나씩 실제로 해 보고, 날짜·숫자로 기록하는 채널.** 잘된 날도 실패한 날도 그대로 보여 준다.

## 2. 누구를 위한 채널 (타깃)
| 칸 | 내용 |
|---|---|
| 나이 | 20대 후반 ~ 30대 (진행자와 같은 또래) |
| 처지 | 돈·경력·스펙·인맥이 '없다'고 느낌 · 늦었다는 불안 · 회사·퇴사·이직 고민 |
| 원하는 것 | 나도 바뀔 수 있다는 근거 · 따라 할 수 있는 작은 방법 · 같이 가는 사람 |
| 싫은 것 | 이미 성공한 사람의 설교 · 과장된 '인생 역전' · 비싼 강의 홍보 |

## 3. 진행자 = 사용자 본인 (얼굴·목소리 실제 촬영)
- 이 저장소의 다른 채널(AI 내레이션·코드 애니메이션)과 다르다 — **브이로그 = 직접 찍은 영상이 중심**, 코드 화면은 기록 숫자(달성률·누적 시간·잔고 변화) 정리 장면에만.
- 진행자 경험을 지어내지 않는다 (CLAUDE.md 제작 공통) — 이 채널은 **진짜 기록만** 쓴다. 대본은 찍은 뒤 정리하는 말(도입·챕터 질문·정리)만 Claude 가 돕는다.

## 4. 전달 방식 (가설)
1. **목표 선언 → 기간 → 결과 숫자** — "30일 동안 ○○ 해 보면?" 꼴. 결과는 숫자 하나로 (몇 일 성공 · 몇 kg · 몇 권 · 몇 원).
2. **실패도 콘텐츠** — 못 지킨 날·포기한 목표와 이유를 숨기지 않는다 (타깃이 가장 공감하는 장면일 가능성 — 댓글 분석으로 확인).
3. **매달 결산** — 목표판(달성률)을 같은 꼴로 매달 → 시리즈로 다시 보러 오게.
4. **쇼츠 = 하루 한 장면 / 결과 숫자 하나** → 롱폼으로 보냄.

## 5. 원칙
- 돈·투자·건강·다이어트는 **내 기록**으로만 말하고 남에게 권하지 않는다 (투자·의료 조언 아님 — 설명란에 밝힘).
- 제품·강의 홍보를 하면 광고 표시를 지킨다.
- 다른 사람이 찍히면 얼굴·목소리 허락을 받거나 가린다.
