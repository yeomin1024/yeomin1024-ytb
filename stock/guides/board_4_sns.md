## 1. 꼴 (편 하나 = X 글 + 스레드 글)
- 원본 = `stock/topics/sns/sns_<날짜>.json` — 편마다 `title`(롱폼 제목) · `items` 10개 `{q, A, B, ans}` · `types`(통과·주의·불통과가 어떤 사람인지 — 롱폼 '결과' 문장 그대로).
- **문항 1~5 = 롱폼 다섯 갈림길**(보기를 짧게, '당신' 꼴) · **6~10 = 같은 주제의 계획·생각 문항** — 결과(그 뒤 오르내림)에 따라 맞고 틀림이 갈리는 문항 ✗, 계획이 있느냐·빚·비상금·비중·확인 습관처럼 원칙으로 답이 정해지는 것만 (옛 `stock/topics/롱폼요약본_2026-10-30.md` L1~L4 문항이 재료). 편끼리 같은 문항 ✗ · 정답 글자 섞기 · 보기에 사람마다 다른 수치 ✗ · 권유·과장 낱말 ✗('무조건'·'사세요' 등 — 인용이어도).
- **정답·점수·결과는 댓글** — 본문엔 소개 + 문제만. 점수 = 맞힌 문제마다 10점 · 90점↑ 통과 · 60~80 주의 · 50↓ 불통과 · 끝에 영상 링크(올린 뒤 `video_link` 채움) · '투자 권유가 아닌 테스트' 한 줄.
- 글자 한도: **X 글 하나 = 가중 280**(한글 2·영문 숫자 1 — 무료 계정) → 소개 글 + 문항 글(묶음) + 댓글 2 · **스레드 글 하나 = 500자** → 소개+앞 문항 · 이어 쓰기 · 댓글 1. 나누기·세기는 도구가 함.

## 2. 명령
```bash
git pull --rebase origin main
python3 tools/sns_posts.py            # 원본 json → stock/topics/sns/sns_posts.md (복사용) + stock/topics/SNS평가판.html · 한도·K8·정답 몰림을 어기면 멈춤
```
- 판 피드백: `ArtifactData query feedback where status == new` (url = 판) → 줄 피드백(`lines` — 판의 줄 번호는 편·플랫폼마다 1부터, `quote` 로 어느 문항인지 확인)·칸 피드백(`field`) → **원본 json 을 고침**(글은 도구가 다시 짬) → 원본 `ver` 올림 → 도구 → 판 다시 올림 → 피드백마다 done·reply.
- 판정 '통과 (올림)' = 사용자가 그 글을 그대로 올림. 영상이 올라가면 `video_link` 를 채우고 도구 다시.
