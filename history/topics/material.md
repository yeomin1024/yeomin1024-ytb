## 0. 채널 설명 (`history/guides/channel.md` — 주제·안은 이 목적·전달 방식에 맞게)

- **목적** = "옛날 사람들은 정말 그랬을까?" 하는 궁금증에 **기록(실록·일기·여행기)과 숫자(계산·지도)로 답**한다 — 한 편에 질문 하나, 끝에 판정 한 문장 (⚠️ 임시 — 사용자 채널 설명 전, 추천 v1.2 기준).
- **다루는 것** = 조선 백성·평범한 사람의 삶(밥·겨울·주막·화장실·노비·과거길·병) 주력 · 세계사는 지도로 답할 수 있는 '어떻게·왜'(제국·종교·이동) 실험. **빼는 것** = 지금 정치·전쟁과 엮기 · 반일·국뽕 선동 · 재야사학·영토 주장 · 지어낸 야담·타임슬립 · 끝난 유행(단종 영화).
- **전달 방식** = 궁금증 먼저(흔한 믿음·사극 장면·시청자 질문) → 기록 원문 한 줄 + 계산 숫자 → 판정. 사실은 원문으로 확인한 것만, 숫자는 계산 코드 출력만. 시청자 셋: 틀어 두고 듣는 사람(P1 49% — 차분하고 길게) · 옛일을 기억하는 6070(P2 30% — 그 시절 경험과 이어서) · 공부하는 학생(P3 12% — 용어는 처음에 풀어서).

| 꼴 | 시청자의 궁금증 | 진행 | 답 |
|---|---|---|---|
| 생활사 해설형 | "조선 사람들은 정말 ~했을까" | 사극·흔한 믿음 → 기록 3~4개(시대 순) → 숫자로 크기 보이기(한 끼 양·땔감·거리) → 정리 | 판정 한 문장 + 오늘과 비교 숫자 |
| 확인형 | "그 말(댓글·통념)이 사실일까" | 주장 그대로 → 판정 규칙을 먼저 말함 → 기록·숫자 → 판정 | '사실 / 절반만 사실 / 사실 아님' 하나 |
| 지도형 (세계사 실험) | "어떻게 그렇게 넓어졌나·퍼졌나" | 연도별 지도(넓이·속도) → 까닭 2~3개 | 숫자(넓이·연수) + 까닭 |

| decide | 판정 규칙 — 자료가 어느 쪽으로 나와도 결론이 하나로 정해지는 기준 ('A가 B보다 높은 구간이 50% 넘으면 A, 아니면 B') |
| data | 자료 (사료 원문 — 조선왕조실록·승정원일기·일기·여행기·연구 논문 · 지도 자료 historical-basemaps 등, 시대·연도 필수) |
| format | 생활사 해설형 (조선 사람들은 정말 ~했을까) · 확인형 (댓글·통념이 사실인가 — 판정 하나) · 지도형 (세계사 — 연도별 지도·넓이) — history/guides/channel.md 1번 |
| persona | personas.json 키: `listener` (일·집안일·잠들기 전에 틀어 두고 듣는 사람), `elder` (옛일을 기억하는 6070), `student` (역사를 공부하는 학생) |
| theme | 주제 묶음 번호 (아래 3번 표) |
| needs | 댓글 니즈 ID 목록 (아래 2번 표) |
| market | 한국사 · 세계사 |
| data_kind | 사료 원문 · 계산(양·거리·수) · 지도 넓이 · 연구 통계 · 그 밖 |
| items | (테스트형) 항목 예 3개 |
| why | 이 주제를 고른 까닭 한 줄 |
