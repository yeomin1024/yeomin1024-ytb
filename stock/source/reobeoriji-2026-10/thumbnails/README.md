## 1. 짝 제목과 그림이 전할 한 가지
- 짝 제목: `titles.md` R1 「레버리지 ETF, 닷컴 폭락부터 27년 매달 모으면 QLD·TQQQ가 1배 QQQ보다 더 남을까?」 (10개 언어 모두 같은 뜻). 썸네일 글자는 영어 낱말·숫자·기호뿐이라 언어와 상관없이 한 장이다.
- 그림이 전할 것: **"1배·2배·3배 — 같은 크기 로켓 세 대에 같은 동전을 매달 넣는데, 폭풍(폭락)을 지나 27년 뒤 어디까지 갔을까?"**
- 결말 가리기: 세 로켓은 **같은 크기·같은 높이, 모두 발사대 위**(아무도 날아오르지 않음). 배수는 숫자 대신 로켓 옆 **빛나는 점 1·2·3개**로. 위 먹구름 속에 **닫힌 상자**.
- 색: 파랑 = 1배 · 보라 = 2배 · 주황 = 3배 (영상 화면과 같은 색) · 번개·먹구름 = 폭락 · 금색 동전 = 매달 넣는 돈 · 배경 짙은 남색

- 그림·캐릭터(반실사 포함) 성공 23% vs 기준 밖 10% → 인물을 **반실사 일러스트**로.
