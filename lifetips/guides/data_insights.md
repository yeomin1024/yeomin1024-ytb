버전: v2.0 — 2026-10-12 — 사용자 지시: 작은 채널·최근 성공 사례와 댓글의 시청자 니즈 중심으로 다시, 주식에서 빌린 근거 정리 (v1.0 — 2026-10-11 — 최초 작성: 분석 실행 `20261011_120712` 결과)

대본·제목·썸네일·업로드 지시사항이 "분석 근거"라고 적은 숫자는 모두 이 파일에서 온다.
원본 자료는 `lifetips/result/`(분석기 결과 `data/*.csv`, 작은 채널 성공 사례 `outliers/`)에 있다. 결과 파일은 고치지 않는다.

> ⚠️ **읽을 때 주의**
> - 상관관계이지 인과관계가 아니다. 성공 사례는 24개, 롱폼 성공 사례 댓글은 327개뿐이다. 숫자 옆에 n을 같이 적었다. **방향**으로만 쓴다.
> - "작은 채널 성공 사례" = 롱폼(4분 이상) · 구독자 5만 명 이하 · 조회수가 구독자의 3배 이상 · 조회수 1만 이상. 쇼츠는 뺐다 (이 채널은 롱폼을 만든다).
> - 댓글 니즈 숫자는 사람이 1,416개를 모두 읽고 분류한 것이다 (3-1). 한 댓글이 두 니즈에 들어갈 수 있다.

### 1-3. 공통점 (살림 실습 24개)

## 5. 지난 판(v1.0)에서 고친 것

1. **성공 사례를 다시 골랐다.** v1.0이 본 분석기 "성공 사례 8개"(`result/success_cases/`)는 8개 중 5개가 1분 안팎 짧은 영상(쇼츠 4 + 63초 1)이었고, 2개는 구독 10만 명이 넘는 채널(36.9만·10.1만)이었다. 분석기가 고른 점수의 35%가 조회수 크기였기 때문이다 (`youtube_topic_analyzer.py` `SUCCESS_SCORE_WEIGHTS` views 0.35). v2.0은 **롱폼 · 구독 5만 이하 · 조회 ≥ 구독 × 3** 기준으로 엄격 9개 + 넓은 세트 24개를 봤다.
2. **댓글을 니즈로 분석했다.** v1.0은 질문 단어 빈도와 좋아요 많은 경험 댓글 몇 개만 적었다. v2.0은 1,416개를 모두 읽고 13개 니즈로 나눠 개수·좋아요·롱폼 안 개수를 셌다 (3번).
3. **주식에서 빌린 근거 3곳(말하기 속도·도입부·썸네일)을 정리했다** (4-2). 썸네일은 이 주제 성공 썸네일 24장을 직접 봤다.
4. v1.0의 "작은 채널 롱폼 성공 5개 모두 7분 이하 → 짧을수록 좋다"는 표본이 5개였다. 넓은 세트 24개는 중앙값 7.1분이지만 작은 채널 후보 안에서는 길이 차이가 없었다 (2-2). 7~9분 규칙은 유지하되 근거를 고쳐 적었다.
5. v1.0 7번 "벤치마크 채널" 표는 1-1·1-2 표로 바꿨다 (쇼츠 2개 뺌).

## 8. 갱신 방법

1. API 키가 있으면 `python3 tools/outlier_research.py lifetips`로 최근 업로드를 다시 모은다 (`result/outliers/`가 바뀐다). 없으면 `bash tools/run_analysis.sh lifetips`로 분석기만 다시 돌린다 (받은 검색은 7일 캐시).
2. 1번 표를 새 `outliers.csv`로 바꾸고, 썸네일을 **직접 열어 보고** 2-4를 다시 센다.
3. 새 댓글로 3번 니즈를 다시 센다 (같은 13개 분류, 롱폼 성공 사례 댓글을 따로).
4. 결론이 바뀐 항목만 4-1 표의 지시사항 파일에 반영하고, 각 파일 변경 이력에 "data_insights vX.Y 반영"으로 남긴다.
5. 우리 영상 성과(YouTube 스튜디오 "테스트 및 비교", 시청 지속)는 `source/<영상ID>/titles.md`·`thumbnails/` 결과 칸에 적고, 3개가 쌓이면 4-3을 다시 본다.
