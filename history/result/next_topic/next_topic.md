- **1번을 먼저 권함**: 데이터가 가장 강하게 가리키는 물결(겨울 버티기) 안에서 아직 아무도 안 한 '물건 하나' 각도. 영상 진행은 채널 꼴 그대로 — 판정 규칙(기록 속 이불 재료·값) → 시대 순 기록 → 백성 집 하룻밤 → 판정 한 문장 + 오늘과 비교. 형식 숫자(4번 — 단면 4.01)대로 **이불 단면 그림**(솜·누비·짚 겹)을 한 장 넣는다.
- **1·2번 모두 지금 꼴(따뜻한 2D 그림 + 코드 화면)로 만들 수 있고, 같은 꼴로 잘 된 전례가 있음.** 1번 '이불 단면'(솜·누비·짚 겹)도 2D 단면 그림 한 장으로 (3D 렌더 아님).
- **2번(장빙·반빙)은 바로 쓸 수 있음** (I편 제목·썸네일 3안 13회차 통과, 그림 안도 2D) — 검색은 0 이라 피드에 기대는 주제. 12월 중순~1월 (실제 장빙 철).
- **겨울옷은 뒤로** (v1.1 의 2번): 트렌드는 오르지만 잘 된 영상이 모두 실사·3D — 지금 꼴로 이길 근거가 없음. 겨울 생활사는 12~1월이 철이라 1번은 **12월 안**에 올리는 것이 좋음.
- **김장**은 검색이 가장 크게 올랐지만(6.2배) 11-15 주가 꼭짓점이고 역사 김장 영상도 이미 둘 (9.6만·7.5만) → 롱폼은 늦음, 한다면 쇼츠로만.
