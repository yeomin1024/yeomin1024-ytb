# 새 영상 스타일 시안 — 은퇴 꺼내 쓰기 스토리보드 (2026-10-15)

버전: v1.0 — 2026-10-15 — 사용자 지시 "영상 만드는 것도 예전 스타일 하지말라고 어떻게 하면 설명의 이해를 최대한 도울지 필요한 최대한 고퀄리티 html 기반의 고퀄리티 도구 많잖아 전력을 다해서 한번 일부만 스토리보드 만들어서 보여줘봐".

- 대본: `economic/source/eunte-kkeonaeseugi-2026-10/` v1.2
- 범위: 컷 14개 = 0:00~0:49(도입) + 2:49~4:06(원칙 하나의 핵심). 시안 시간 0~127.28초.
- 시간: SRT 타이밍 그대로 (내레이션 오디오가 아직 없음). 오디오가 생기면 그 시간에 다시 맞춘다.
- 연구·교육용 자료이며 투자·세무 권유가 아니다.

## 파일
| 파일 | 내용 |
|---|---|
| `storyboard.html` | 재생기 + 컷 카드 페이지. 무대(1920×1080)의 장면은 HTML·SVG, 움직임은 GSAP 타임라인. `?render`를 붙이면 무대만 보이고 `window.SB.seek(t)`로 멈춘 장면을 만든다 |
| `render.js` | Playwright로 장면을 찍는다: `stills`(컷 대표 장면 → `frames/`), `video`(30fps → `out/storyboard_preview_720p.mp4`), `page`(페이지 화면·가로 넘침 확인), `extra`(`TIMES=…` 시각) |
| `package.json` | gsap 3.12.5 (렌더 때 로컬 파일로 씀 — 렌더 환경에서 cdnjs가 막혀 있음) |

## 실행
```
cd video/prototypes/storyboard-2026-10-15
npm install                                   # gsap
node ../../scripts/get-fonts.mjs              # 없으면: video/public/fonts/NotoSansKR-500·700·900.ttf
NODE_PATH=$(npm root -g) node render.js stills
NODE_PATH=$(npm root -g) W=1280 node render.js video     # 3,819장, 약 2분 (이 환경 기준)
```
- `frames/`·`out/`·`_render.html`은 저장소에 올리지 않는다 (`.gitignore` — 점검용 still·영상은 저장소 밖).
- 렌더는 `<!doctype html>`을 붙인 `_render.html`로 한다. doctype이 없으면 quirks 모드라 클래스 이름 대소문자(`.a`·`.A`)가 섞여 배치가 깨진다 (2026-10-15 실제로 겪음).
