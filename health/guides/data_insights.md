# 건강 — YouTube 분석 결과 요약 (지시사항 근거)

버전: v2.0 — 2026-10-12 — 사용자 지시: 작은 채널·최근 성공 사례와 댓글의 시청자 니즈 중심으로 다시 쓰고, 주식에서 빌린 근거를 정리 (v1.0 — 2026-10-11 — 분석 실행 `20261011_120552`(분석기 v2.3.0) 결과로 처음 정식 작성 / v0.1 — 2026-10-10 — 자동완성 근거만 적은 임시본)

대본·제목·썸네일·업로드 지시사항이 "분석 근거"라고 적은 숫자는 모두 이 파일에서 온다.
"직접 집계"는 Claude가 `health/result/` 의 CSV를 다시 센 것이고, "직접 봄"은 Claude가 썸네일 이미지를 하나씩 열어 본 것이다.
다른 채널의 댓글·제목은 짧게만 인용한다 (60자 이하, 괄호 안은 좋아요 수). 실존 인물 이름과 제품 이름은 옮기지 않는다.

> **옛 번호 안내:** 공통 지시사항이 이 파일의 옛 번호를 가리킬 때가 있다 — 옛 2번(말하기 속도) → 0번 한계 5항 (건강 근거 없음), 옛 5번(도입부) → 2-3, 옛 6번(썸네일) → 2-4, 옛 9번(갱신 방법) → 8번.

**한계 — 읽을 때 꼭 같이 본다**

1. **최근·작은 채널 자료가 거의 없다.** 자료는 분석기 실행(2026-10-11, 검색 키워드 48개 중 13개)에서 모은 것이고, 그 검색은 최근 영상만 찾지 않았다. 후보 560개 중 730일 안 영상 303개, 그중 4분 이상 롱폼 95개, 그중 구독자 10만 이하는 **20개뿐**이다. 그래서 엄격 기준 통과가 2개이고, 1번에서 기준을 넓힌 묶음을 따로 만들었다 (넓힌 묶음 A는 업로드 중앙값 약 4년 전 — "최근"이 아니다).
2. **댓글은 대부분 큰 채널 영상의 것이다.** 1,243개 중 1,114개(90%)가 구독자 25만 명 이상 채널의 영상 12개에서 나왔다 (영상마다 최대 100개). 구독자 10만 이하 채널 영상 댓글은 9개 영상 123개뿐이다. 그래서 3번은 "작은 채널 시청자"가 아니라 **건강 유튜브 시청자 전반의 니즈**로 읽는다.
3. **댓글 분류 방법:** 키워드 규칙으로 1차 분류 → 좋아요 상위 250개(전체 좋아요의 89.4%)와 질문·경험·기타로 분류된 댓글을 Claude가 직접 읽고 갈래를 정했다 (441개). 한 댓글은 한 갈래에만 센다. 규칙 분류라 개수에는 오차가 있다 (특히 좋아요 0~1개짜리).
4. **좋아요는 몇 개 댓글에 몰린다.** 상위 10개가 전체 좋아요의 33.0%, 좋아요 0개 댓글이 235개다. 그래서 "몇 번 나왔나(개수)"와 "얼마나 공감받았나(좋아요 비중)"를 따로 적는다. 질문은 개수는 많고 좋아요는 적다 (개인 질문이라).
5. **설명란·자막이 없다.** 설명란은 이 자료에 없고, 자막(대본)은 클라우드에서 막혔다. 그래서 성공 영상의 **도입부·말하기 속도는 건강 근거가 없다** (지난 판은 주식 결과를 빌렸다 — 5번).
6. **분석기의 "롱폼"에 쇼츠가 섞였다.** 분석기는 쇼츠가 아닌 영상을 모두 롱폼으로 셌는데, 4분 미만이 21개였고, 그중 성공 사례 3개(1:24, 3:00, 1:04)를 직접 보니 썸네일이 세로(쇼츠)였다. **이 파일은 4분 이상만 롱폼으로 본다.**
7. 상관관계이지 인과관계가 아니다. 표본이 작은 숫자는 n을 같이 적고, 방향으로만 쓴다.
8. 새 수집(최근 365~730일, 구독자 5만 이하, 4분 이상)은 YouTube Data API 키가 있어야 한다 → 다음 세션에서 `tools/outlier_research.py`로 한다 (6번).

### 1-4. 공통점

**작은 채널 (A, 13개)**
1. **소재 = "내 검사 숫자가 무슨 뜻인가".** 13개 중 9개가 검사 숫자 해설이다 — 건강검진 결과지 읽는 법 7개, 간수치 2개. 지방간 해설 2개까지 합치면 11개가 검사·간 이야기다 (나머지: 당뇨 전단계 1, 속눈썹 영양제 1). 재구성 사연 형식은 0개.
2. **형식 = 의사가 직접 설명.** 12개가 의사·병원 채널이다.
3. **오래 검색으로 쌓였다.** 업로드 중앙값 1,585일 전(약 4년 3개월). 730일 안은 엄격 사례 2개뿐.
4. **길이 5.1~14.4분, 중앙값 7.4분.** 13개 중 10개가 10.2분 이하.
5. 최근 2년 안에 퍼진 2개는 둘 다 제목에 **믿을 근거**를 걸었다: "광고X!"(제품 비교), "강남 세브란스병원 교수"(당뇨 전단계). n=2라 가설로만 적는다 — 3번의 시청자 니즈 1위(신뢰)와 같은 방향이다.

**최근 큰 채널 (B, 9개)**

### 3-2. 니즈 6가지 — 근거와 어떻게 채우나

**N1. 파는 사람 말고 믿을 수 있는 출처 (공감 1위)**

- 말: "약 팔이하는 의사들이 문제, 홈쇼핑과 TV편성이 동시간대에…"(883) · "영양제 팔아먹는 티비프로 없애라"(812) · "양심있는 의사 당신은 환자들에게 희망입니다"(1,085) · "교수님들께서 제약사 눈치안보고 돌직구날려주시는 용기는…"(114)
- 어떻게 채우나: 제품·브랜드 이름을 말하지 않고(이미 규칙), **모든 건강 영상**의 설명란·고정 댓글에 "제품을 추천·판매하지 않는다"를 적는다. 숫자마다 기관 이름을 말과 화면으로 댄다(이미 규칙). 제품 체험담 댓글은 숨긴다. 신뢰는 직함이 아니라 **출처**로 얻는다 (의사 연출 금지 유지).

**N2. 핵심만 정리된 목록 (시간을 아끼고 싶다)**

- 말: "축약정리 함 (tv처럼 시간을 많이 납치하는 동영상을 별로 안 좋아하는 1人이라)"(1,112) · "약사님 영상 마지막에 전체 리스트 보여주고 끝냈으면 완벽!"(31) · "이렇게 딱딱 표로 정리가 되고 내용이 모호한거보다 딱 떨어지는게…"(12)

**N3. 영양제 — 무엇을, 언제, 같이 먹어도 되나, 내 약과 함께 (질문 1위 묶음)**

**N5. "하지 마라"보다 "대신 이렇게" — 숫자로 따라 할 방법**

**N6. 나와 같은 사람의 경험**
- 근거: 자기 이야기 146개(2,836) — 해보니 좋아짐 26(705), 알면서도 어려움·걱정 25(387), 가족 걱정 13.

### 3-3. 싫었던 것 (적게 나왔지만 구체적)

- **숫자는 바로 검증된다**: "EGFR 은 60이 아니라 90 이상이 정상입니다 의사라고 다 맞는말만…"(1, 작은 채널) · "황태채가 … 100g 먹으려면 어마어마한 양을 먹어야 하더라고요"(62) → 기준은 원문 그대로, 양은 한 끼·하루처럼 현실 단위로 (출처·숫자 규칙 유지).

## 8. 갱신 방법

1. 새 수집이 끝나면 (`tools/outlier_research.py`, API 키) `result/outliers/`의 `summary.md`·`candidates.csv`·사례 폴더로 1번 표와 1-4 공통점을 다시 쓴다. 엄격 기준 통과가 10개를 넘으면 넓힌 묶음 A는 지운다.
2. 사례 폴더의 썸네일을 직접 열어 2-4 표를 다시 센다. 자막이 있으면 2-3에 첫 30초·말 속도를 적는다.
3. 댓글(`audience_comments.csv`, 사례 폴더 `comments.csv`)로 3-1 표를 다시 센다 — 규칙 분류 뒤 좋아요 상위와 질문은 직접 읽고 고친다. 니즈 순위가 바뀐 것만 4번 표로 규칙에 반영한다.
4. 결론이 바뀐 규칙 파일마다 변경 이력에 "data_insights vX.Y 반영"을 남긴다.
5. 우리 영상 성과(스튜디오 수치, "테스트 및 비교")가 쌓이면 6번 6항을 이 파일의 새 절로 옮긴다.
