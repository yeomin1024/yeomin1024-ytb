# 주식 — YouTube 분석 결과 요약 (지시사항 근거)

버전: v2.0 — 2026-10-12 — 사용자 지시: 작은 채널·최근 성공 사례와 댓글의 시청자 니즈 중심으로 다시 ("구독자수 별로 없지만 조회수가 잘 나오는 영상에 무엇이 들어 있고, 댓글에서 시청자의 니즈가 뭔지 파악해서 지시사항에 반영") (v1.1 — 2026-10-12 — 10번 우리 영상 성과; v1.0 — 2026-10-09 — 분석기 실행 `20261009_204204` 정리)

대본·제목·썸네일·업로드 지시사항이 "분석 근거"라고 적은 숫자는 모두 이 파일에서 온다.
이번 판의 중심은 **작은 채널(구독자 5만 이하)이 최근 1년 안에 올린 롱폼 중 조회수가 구독자의 3배 넘게 나온 영상**과 **그 영상의 댓글**이다.
지난 판(v1.1)의 분석기 통계는 쇼츠·큰 채널이 섞여 있어 7번 "분석기 통계(참고)"로 옮겼다.

> **다른 문서가 가리키는 옛 번호:** 2번(말 속도) → 이번 판 2-5 · 5번(성공 영상 도입부) → 2-4 · 6번(썸네일) → 2-6 · 9번(갱신 방법)·10번(우리 영상 성과)은 번호 그대로.

> ⚠️ **읽을 때 주의**
> - 상관이지 인과가 아니다. 성공 사례는 30개, 댓글을 읽은 영상은 11개다. 차이는 **방향**으로만 쓰고 단정하지 않는다.
> - 댓글 분류(3번)는 Claude가 748개를 한 개씩 읽고 나눈 것이다. 사람마다 경계가 조금 다를 수 있다.
> - 자료가 얇은 곳은 규칙을 조금만 바꿨다. 크게 바꿀 일은 4-2 "사용자 결정 필요"에 적었다.

부의 스케치 「노후 자금 10년 묻어두려던 ETF…」(9분 23초)의 순서:
1. **역설로 시작** — "지수 ETF로 돈을 잃는 건 거의 불가능… 그런데 현실은 어떤 줄 아세요?" + 통계 한 줄 + "심리 과정을 파헤치고 현실적이고 물리적인 해결책까지" 약속.
2. **실패의 단계를 순서대로** — 평화로운 적립 → 동료의 한마디·비교 → "의지가 약해서가 아니라 시스템이 흔들리게 만든다" → 소액 타협 → 초심자의 행운 → **"혹시 지금 뜨끔하신 분 계신가요? 저도 그랬습니다"** → 레버리지·음의 복리 → 하락·공포 → 대출·몰빵.
3. **"마음을 비우세요 같은 뻔한 조언은 도움이 안 된다"** → 물리적 장치: 주식 수에 집중, 계좌를 증권사째 9:1로 나누기, 월급날 자동 매수.
4. 마무리 + 구독 부탁.

댓글 반응: "뜨끔"(11)·"내 이야긴데?"(8) 같은 자기 인식, "계좌분리 원칙은 좋다고 봄"(48), 장치를 묻는 질문 1개. 다른 성공 사례는 자막이 없어 도입부를 확인하지 못했다 → 6번.

## 9. 갱신 방법

1. **작은 채널 성공 사례:** `python3 tools/outlier_research.py stock` (API 키, 6번) → `result/outliers/` 가 새로 바뀌면 1·2번 표를 고친다. 썸네일은 사례 폴더의 `thumbnail.jpg` 를 직접 보고 2-6 표를 다시 센다.
2. **댓글:** 사례 폴더 `comments.csv` 와 `result/data/audience_comments.csv` 를 모두 읽고 3-0 분류(경험·원칙·칭찬·비판·질문·요청·기타)로 다시 센다. 결론이 바뀐 니즈만 3-8 표를 고친다.
3. **분석기:** `python youtube_topic_analyzer.py --config stock/analyzer_config.toml` 결과는 7번 참고 숫자만 바꾼다.
4. 결론이 바뀐 항목만 4-1 표의 규칙 파일에 반영하고, 각 파일 변경 이력에 "data_insights vX.Y 반영"으로 남긴다. 사용자 규칙과 부딪히면 바꾸지 말고 4-2에 적는다.
5. YouTube 스튜디오 "테스트 및 비교"로 썸네일·제목 결과가 나오면 `source/<영상ID>/titles.md`·`thumbnails/` 결과 칸에 적고, 쌓이면 여기에 요약한다.
